# Tool Models

These STL files are generated placeholder tool models for CNEXT-CAM simulation display.
They are sized in millimeters and normalized so the lowest Z point is the tool tip.

Current models:
- `end_mill_D3.stl`
- `end_mill_D6.stl`
- `end_mill_D10.stl`
- `drill_D3.stl`
- `drill_D6.stl`
- `spot_drill_D4_90deg.stl`
- `tap_M6.stl`
- `chamfer_mill_D10_90deg.stl`
- `face_mill_D50.stl`

These models are for visual simulation only. They are not manufacturer-accurate cutting geometry.
