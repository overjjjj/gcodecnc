# CNEXT-CAM 项目需求说明书

> 版本：1.0　　日期：2026-05-19

---

## 1. 项目背景与目标

### 1.1 背景

工业级 CAM 软件（以 Mastercam 为代表）功能强大，但学习曲线极陡：
- 界面密度高，Ribbon 工具栏 + 特征树 + 参数面板同时展示数百个选项；
- 每道工序参数多达数十项，专业术语多，新手难以辨别哪些必填、哪些可忽略；
- CAD 与 CAM 工作区分离，导入模型后需要多步手动设置才能进入加工流程；
- 多轴、车铣复合等高级模块与日常 2.5D 加工功能混杂，干扰初学者。

### 1.2 产品目标

> **让一名初中生能在一天内完成从导入零件模型到输出可上机 G 代码的全流程，同时保证 CNC 加工精度与正确性。**

具体衡量标准：
| 指标 | 目标值 |
|------|--------|
| 新用户首次完成开孔加工的操作步骤数 | ≤ 8 步 |
| 从导入 STEP 到输出 G 代码的最短时间 | ≤ 3 分钟 |
| 关键参数（刀具直径、转速、进给）自动填充率 | ≥ 80% |
| G 代码经后处理验证通过率（Siemens 840D 语法） | 100% |

### 1.3 适用范围

- **目标用户**：职业院校学生、工厂新手操作员、小型制造企业技术人员。
- **目标机床控制器**：Siemens 840D（首期），后续扩展 Fanuc 0i/30i、Heidenhain iTNC 530。
- **目标工件**：中等复杂度棱柱类零件，以孔、槽、型腔、平面为主，含 2.5D 轮廓加工。

## 2. 功能需求

### 2.1 模型导入与特征识别

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F-01 | 支持导入 STEP（AP214/AP242）格式三维模型 | 必须 |
| F-02 | 自动识别孔（通孔/盲孔/沉头孔/螺纹孔）、槽、型腔、平面、凸台、倒角、圆角特征 | 必须 |
| F-03 | 识别结果按正面/侧面/反面分组，在特征树中展示 | 必须 |
| F-04 | 点击特征树条目，三维视图高亮对应面组 | 必须 |
| F-05 | 点击三维模型面，自动选中最近匹配特征并高亮 | 必须 |
| F-06 | 特征勾选确认机制，明确标记待加工特征 | 必须 |

### 2.2 刀具库

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F-10 | 内置常用钻头（中心钻、麻花钻、铰刀、丝锥）和铣刀（立铣刀、面铣刀）默认型号 | 必须 |
| F-11 | 按孔径自动推荐最接近的钻头直径 | 必须 |
| F-12 | 支持新增、编辑、删除刀具，持久化保存 | 应该 |
| F-13 | 刀具与策略的兼容性提示（如铰刀直径须接近孔径） | 应该 |

### 2.3 加工策略——开孔

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F-20 | 点钻（中心钻定位，输出 CYCLE81/CYCLE82） | 必须 |
| F-21 | 排屑钻（啄钻，输出 CYCLE83） | 必须 |
| F-22 | 深孔钻（小步距啄钻，输出 CYCLE83） | 必须 |
| F-23 | 攻丝（输出 CYCLE84，螺距匹配校验） | 必须 |
| F-24 | 铰孔（输出 CYCLE85，直径匹配校验） | 必须 |
| F-25 | 倒角钻 | 应该 |
| F-26 | 圆插补铣孔（立铣刀扩孔至成品孔径） | 应该 |
| F-27 | 多孔批量生成（同策略+同刀具合并为一个 MCALL 块） | 必须 |
| F-28 | 按深径比自动选择策略（深孔优先啄钻，螺纹孔优先攻丝） | 必须 |

### 2.4 加工策略——铣削

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F-30 | 平面铣（面铣刀行切，输出多行 G1 直线段） | 必须 |
| F-31 | 型腔开粗（行切清腔，分层切深，自动根据型腔形状裁剪刀路） | 必须 |
| F-32 | 轮廓精加工（G41/G42 刀补，直线引入/引出） | 必须 |
| F-33 | 铣圆（圆插补，G02/G03） | 应该 |
| F-34 | 曲面精加工（等高线或光栅法，初期占位，后续完善） | 可选 |

### 2.5 G 代码生成与后处理

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F-40 | 策略输出中间元数据（`CNEXT_HOLE_CYCLE`），后处理器转换为目标控制器语法 | 必须 |
| F-41 | Siemens 840D 后处理：MCALL CYCLE83/84/85，程序头/尾格式 | 必须 |
| F-42 | Fanuc 0i 后处理：G83/G84/G85 固定循环（后续扩展） | 应该 |
| F-43 | G 代码编辑器，支持查看和手动修改输出代码 | 必须 |
| F-44 | 一键导出 `.mpf` 文件（Siemens 840D 程序文件格式） | 应该 |

### 2.6 仿真与验证

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F-50 | 三维刀路可视化：G0 快速段红色，G1/G2/G3 进给段绿色 | 必须 |
| F-51 | 解析 MCALL CYCLE83/82/81 并展开为仿真路径 | 必须 |
| F-52 | 仿真速度调节（0.25x ~ 10x） | 必须 |
| F-53 | 材料去除仿真（后续阶段） | 可选 |

### 2.7 工序管理

| 编号 | 需求 | 优先级 |
|------|------|--------|
| F-60 | 工序列表，显示策略名、刀具、加工特征 | 必须 |
| F-61 | 支持手动调整工序顺序 | 应该 |
| F-62 | 批量生成所有工序 G 代码，合并同类工序 | 必须 |

## 3. 非功能需求

### 3.1 易用性（核心差异化目标）

- **渐进式参数展示**：只显示"必填"参数（刀具、深度、进给），其余折叠为"高级选项"。
- **智能默认值**：根据孔径/材料自动填充转速、进给、每刀步距，用户无需从零输入。
- **步骤引导**：主工作流设计为 导入 → 识别 → 选特征 → 选策略 → 生成，无需在多个窗口之间跳转。
- **即时反馈**：生成 G 代码后立即在三维视口显示刀路，无需手动刷新。

### 3.2 精度与正确性

- 所有坐标计算精度不低于 0.001 mm（3位小数输出）。
- 通孔自动追加 1 mm 穿透余量，避免孔底未穿透。
- 铰孔/攻丝刀具与孔径不匹配时，生成前强制报错，不允许输出错误 G 代码。
- 后处理输出的 G 代码须通过 Siemens 840D 语法验证（人工或模拟器验证）。

### 3.3 技术约束

- **完全自包含**：不依赖任何外部 CAM 算法库（OpenCAMLib 等），所有刀路算法自行实现。
- **构建工具链**：Qt5 + qmake + mingw32-make（Windows）。
- **目标平台**：Windows 10 64-bit，无需安装 Siemens 840D 软件即可运行。
- **开发语言**：C++14 + Qt5 Widgets。

### 3.4 性能

- 导入中等复杂度 STEP 文件（< 5000 面）特征识别时间 < 5 秒。
- G 代码生成（< 100 孔）时间 < 1 秒。
- 三维视口帧率不低于 30 fps（软件渲染模式）。

---

## 4. 不在范围内（当前版本）

- 4/5 轴联动加工
- 车削、车铣复合
- 多坐标系（WCS G54-G59）自动切换（计划后续支持）
- 与 CAD 软件实时参数联动（参数化 STEP）
- 云端协作与版本管理

---

## 5. 验收标准

1. 用户能在不阅读任何文档的情况下，完成从导入 STEP 到输出孔加工 G 代码的全流程。
2. 输出的 G 代码在 Siemens 840D 仿真模拟环境中无语法报错。
3. 孔底深度、孔口坐标与 STEP 模型一致，误差 < 0.01 mm。
4. 多孔批量加工输出的刀路路径顺序经最近邻优化，不出现不必要的长距离空走。
