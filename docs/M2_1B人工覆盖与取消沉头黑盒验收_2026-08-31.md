# M2.1-B 人工覆盖与取消沉头黑盒验收（2026-08-31）

## 1. 验收边界

每项仅观察不可变调和输入/输出、步骤集合、人工覆盖、状态、错误码、字段路径和正式工序数。默认夹具具有同一几何、同一资料版本、合法 `EffectivePlan`、完整唯一解析视图和正式工序数 0；所有用例后正式工序数必须仍为 0。

## 3. 完成门

1. 29 个用例均自动化为黑盒合同；每条覆盖 M21-BB-013–026、041/042 都有对应项。
2. 结构错误、旧目录不可解析、计划/沉头映射变化与目标不可用按 `M21B-IF-PRIORITY-001` 的唯一顺序返回。
3. 取消沉头不改变任何剩余步骤值；`Conflict/Stale` 不混合新旧快照；任何路径没有正式工序或冷却副作用。
4. selector 等价、跨版本迁移、人工重处理授权和确认事务仍未获确认，必须保持阻断。
