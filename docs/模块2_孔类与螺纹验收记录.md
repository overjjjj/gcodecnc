# 模块 2：孔类与螺纹验收记录

日期：2026-08-24

## 当前结论

状态：**半成品**。

已完成并可从工序模型走到最终代码与预览的范围：现有 G81/G83、打点、孔倒角、攻牙、铰孔和圆插补铣孔；本轮新增 G73、G86，以及安全受限的内螺纹单齿铣牙。内牙现支持锥度、图形直径负修正、XY 粗加工趟数、精加工余量以及独立精铣转速/进给。

未完成范围：G76；外螺纹铣牙；多齿换层抬刀；切线/圆弧进刀参数。

- `peckDrillG73`：已接入 `hole_peck_g73`，包含单次深度和循环退刀量。
- `boreHoleG86`：已接入 `hole_bore_g86`，要求显式镗刀杆，保留孔底停留参数。
- `millWhorl`：已接入 `hole_thread_mill` 的内牙/单齿安全子集，支持左/右旋、上到下/下到上、锥度及 XY 粗精分层。
- `boreHoleG76`：未接入。DTM 要求的镗孔偏移、退刀轴和退刀方向尚无可靠 Setup/控制器合同，因此最终代码校验继续拒绝 G76。

## 遗留风险

- G76 若在没有主轴定向偏移和退刀轴/方向合同的情况下输出，可能导致镗刀刮碰孔壁，因此必须继续阻止生成。
- 外螺纹缺少已确认的外圆毛坯边界，不能证明进退刀及刀具中心路径不碰撞。
- 多齿螺纹铣刀的换层抬刀语义尚未从 DTM 恢复代码形成可验证合同，当前只允许单齿刀。
- 正直径修正会让刀具包络越过选定内圆柱边界，因此当前仅允许不越界的零值或负修正。
- 当前内牙以离散 G1 螺旋输出以保持最终代码与预览完全一致；控制器圆弧压缩留待后处理边界单独验证。
- 冷却字段仅保持原有兼容行为，本模块未修改冷却代码或行为。
