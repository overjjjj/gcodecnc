# CNEXT-CAM 设计功能复刻矩阵

> 基准：`D:\yanggao\gcodecnc\untitled` 独立 PC 软件。本文中的“复刻”指实现等价的设计与编程能力，不复制参考软件品牌、素材、控制器专有参数或自动决策规则。

## 1. 参考范围

- 《加工中心控制系统用户使用手册》：第 7 章设计界面中的文件与零件、孔类、牙类、铣平面、槽类、外形铣、斜面与圆角、模块、辅助功能、便捷功能、属性和工序。
- 《ARMaster 源胜免编程数控系统 CAM 使用说明》：工艺栏、图形路径、刀具列表、工艺列表、原点、材质配速、刀具库、坐标系、NC 转档及 15 类常用工艺。

## 2. 实现原则

1. 识别只产生候选特征，不能自动成为正式工序。
2. 模板只负责填充建议参数，应用前后均可人工检查和修改。
3. 最终 G 代码必须继续经过快照、安全校验和最终代码仿真。
4. 只实现毫米单位和首期三轴单 Setup；四五轴、夹钳自动避让及现场辅助设备暂不冒充可用。
5. CQ8 负责实时裁决；设计功能不得直接绕过程序验证或机床运行状态机。

## 4. 建设顺序

### P0：孔槽稳定闭环与最终模型验收

1. 加工对象分类筛选已完成，继续补齐按特征类型的批量工序确认；
2. Setup 原点、矩形毛坯和模型尺寸属性已完成；
3. 孔分类和组级批量工序确认已完成；
4. 槽、型腔稳定分组、组级选择、型腔下刀方式人工确认，以及轮廓起点/方向/刀补人工确认和模型视图预览已完成；
5. 刀具与工序基础适配差异预览、风险确认及硬阻断已完成；后续补刀柄/伸出量和材料配速；
6. 最终程序、安全校验和仿真闭环；
7. `WH250852` 模型端到端验收。

### P1：模板、材料和测量

1. 材料-刀具-策略配速表；
2. 工艺模板的保存、预览和人工应用；
3. 两点、圆、面和边界测量；
4. 毛坯可视化与加工余量；
5. 工序启用、复制和统一撤销/重做。

### P2：高级专用工艺

镗孔、铣牙、环形槽、孤岛、动态铣、外形倒角、清角、刻字、斜面、圆角和受控 CAD 编辑，按验收模型与甲方工艺优先级逐项进入。
