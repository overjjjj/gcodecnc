# DTM 工艺规划洁净规格（2026-08-28）

## 1. 文档地位与洁净边界

本文是 DTM 工艺规划行为的洁净规格层，不是 DTM 实现说明，也不证明 CNEXT-CAM 已实现本文全部能力。它只规定可由独立实现线程编码和黑盒验证的领域行为。

- DTM 说明书、Excel 和界面资料用于回答“输入、建议、顺序和拒绝应是什么”。
- 恢复/反编译资料只用于确认功能入口存在；本文不含伪代码、地址、类型布局、局部变量组合、调用控制流或控制器文本拼接方法。
- CNEXT-CAM 现有公共头文件、ADR、文档和测试只用于确定接入边界与现状，不把 DTM 私有对象模型移植进产品。
- 原始 Excel、二进制、PDB、汇编、恢复 C++ 和测试软件不进入仓库或产品构建。
- 本批不修改生产代码、测试、冷却代码或冷却行为。

每条规范使用稳定 ID，并在末尾标注证据类型。允许的证据类型只有：`说明书`、`Excel`、`截图`、`反编译入口`、`推断`。具体来源、定位和置信度见《DTM 工艺规划证据追溯矩阵（2026-08-28）》；涉及当前产品的事实另列“CNEXT-CAM 现状校验”，不冒充 DTM 证据。

## 2. 统一领域语言

| 术语 | 洁净定义 | 禁止混用 |
| --- | --- | --- |
| 识别特征 | 从模型获得、带稳定几何引用、尺寸、方向、Setup 和拒绝原因的只读加工候选对象。 | 不等于正式工序。 |
| 匹配规则 | 以特征类别、尺寸区间、材料和刀具档位为条件，选择候选方案的版本化资料。 | 不等于刀路算法。 |
| 工艺方案 | 一个有序步骤列表；每步引用白名单策略、刀具选择条件和受限参数表达式。 | 不得包含控制器程序文本。 |
| 工序建议 | 规则解析后的可编辑草稿，携带来源、版本、匹配解释和拒绝原因。 | 不得直接输出 G 代码。 |
| 正式工序 | 操作者显式确认后，由产品工序工厂一次性创建并持久化的工序。 | 不得被后续模板变化静默改写。 |
| 特征层 | 复合孔沿同一轴线、按入口到孔底排序的圆柱层或可验证圆锥沉头层。 | 不用 DTM 私有类型或内存布局表达。 |
| 刀具资料档位 | `材料 + 刀具类型/名称 + 直径区间` 对应的一组建议切削参数。 | 不代表该刀具一定可加工当前几何。 |
| 制式 | 公制、英制或美制螺纹规格空间。 | 同名规格不得跨制式匹配。 |
| 阻断 | 保留原因且不产生任何正式工序、控制器输出或部分结果。 | 不得用默认值静默降级。 |

## 3. 工艺规划公共合同

### 3.1 输入

`DTM-CLN-COMMON-001` 工艺规划输入至少包含：版本化资料集、材料标识、可用刀具快照、已确认 Setup、一个或多个识别特征，以及允许的人工覆盖。尺寸统一使用 mm，进给使用 mm/min，转速使用 r/min，角度使用 deg，百分比以 0–100 表示。`[证据类型：说明书 + Excel]`

`DTM-CLN-COMMON-002` 每个识别特征必须提供稳定几何引用、加工方向、入口/参考面、可验证深度和特征专用尺寸；缺任一安全关键字段时只能产生拒绝结果。`[证据类型：说明书 + 推断]`

### 3.2 输出

`DTM-CLN-COMMON-003` 规划器输出只能是以下二者之一：

1. 零个或多个工序建议，包含方案 ID/版本、按顺序排列的步骤、解析后的参数、参数来源、匹配解释和警告；
2. 带稳定拒绝码和面向操作者说明的拒绝结果。

规划器不得创建正式工序或控制器文本。`[证据类型：说明书 + 推断]`

`DTM-CLN-COMMON-004` 自动规划状态机为：

```text
Recognized → Draft → Selected → Validated → Confirmed
                 ↘ Conflict
                 ↘ Stale
                 ↘ Rejected
```

`Recognized` 只含几何证据；`Draft` 已附候选方案；`Selected` 已由操作者选择方案；`Validated` 表示整链预校验通过；只有显式确认可进入 `Confirmed`。特征、资料版本或刀具快照变化后，已编辑草稿转为 `Conflict` 或 `Stale`，不得自动确认。`Rejected` 为终态，但可在输入变化后重新规划。`[证据类型：说明书 + 推断]`

### 3.3 参数来源与事务

`DTM-CLN-COMMON-005` 参数覆盖优先级固定为：系统默认值 < 材料模板 < 刀具类型模板 < 模块/匹配规则 < 人工覆盖。输出必须保留每个最终值的来源。`[证据类型：说明书]`

`DTM-CLN-COMMON-006` 确认必须是整条方案的原子事务：先解析全部表达式并校验全部刀具、几何和参数，再一次性创建完整正式工序链；任一步失败时正式工序数为零。`[证据类型：说明书 + 推断]`

`DTM-CLN-COMMON-007` 已确认工序保存最终参数、资料引用和版本快照。模板或材料资料变化只影响新建议；旧工序只能通过显式重新规划和再次确认改变。`[证据类型：说明书]`

`DTM-CLN-COMMON-008` Excel 单元格中的表达式是业务字符串，不是 Excel 公式或脚本。运行时只允许版本化 JSON 和白名单 schema；业务表达式只允许已声明变量、正数、括号和四则运算。未知变量、脚本语法、除零、非有限值、负深度或越界结果必须拒绝。`[证据类型：Excel + 推断]`

`DTM-CLN-COMMON-009` 冷却值仅可作为来源资料的兼容字段保存、显示和追溯。本规格不定义冷却选择、状态转移或控制器输出行为。`[证据类型：Excel + 推断]`

## 4. 通用参数字典

| 参数 | 类型 / 单位 | 基本约束 | 来源与语义 |
| --- | --- | --- | --- |
| `materialId` | string | 必填且能解析到资料版本 | 刀具与切削档位匹配键。 |
| `setupId` / `workOffset` | string / enum | Setup 已确认；当前公共边界限 G54–G59 | 工序坐标与加工方向依据。 |
| `toolId` | integer/reference | 刀具存在且在快照中可用 | 确认后的实际刀具。 |
| `toolType` | enum | 与策略兼容 | 规则可建议，确认时以刀具快照为准。 |
| `toolDiameter` | number / mm | `> 0` | 刀径匹配和包络校验。 |
| `fluteLength` / `totalLength` | number / mm | 未知不得伪装为已验证；已知时覆盖目标深度并保留安全余量 | 刀具可达性。 |
| `safeHeight` | number / mm | 不低于下刀高度及已知模型、毛坯、夹具安全面 | 快移安全门。 |
| `plungeHeight` | number / mm | 不高于安全高度，不低于目标切深 | 下刀起始面。 |
| `referenceHeight` | number / mm | 有明确坐标语义 | 深度的基准面。 |
| `depth` / `stepDown` | number / mm | `> 0`；分层不越过特征底 | 总深与轴向分层。 |
| `stepOver` | number / mm | `> 0` 且不大于刀径；还须满足特征包络 | 横向步距。 |
| `feedRate` / `plungeRate` / `retractRate` | number / mm/min | `> 0`，不超刀具与机床限值 | 模板只给建议。 |
| `spindleSpeed` | number / r/min | `> 0`，不超刀具与机床限值 | 模板只给建议。 |
| `allowance` | number / mm | `>= 0`，不得产生负剩余材料 | 平面/侧壁/精加工余量。 |
| `pitch` | number / mm/rev | `> 0` 且与制式、刀具相容 | 攻丝或内螺纹铣。 |

`DTM-CLN-PARAM-001` 表内的范围是确认前的最低合同，不替代机床、刀具供应商或制造工艺批准值。模板中的极端占位值、零进给或不合理上限不得自动转成可加工参数。`[证据类型：Excel + 推断]`

## 5. 孔、多层孔与沉头孔

### 5.1 输入与前置条件

`DTM-CLN-HOLE-001` 单孔输入为入口点、轴线、孔径、入口 Z、终止 Z、盲/通属性、稳定几何引用和 Setup。复合孔还必须提供按入口到孔底排序的层：每层为圆柱或可验证圆锥沉头，包含直径、起止 Z 和通孔标志。`[证据类型：说明书 + Excel]`

`DTM-CLN-HOLE-002` 可规划的复合孔必须同轴、层序连续、深度为正且不重叠；只有最深层可标记贯穿。侧面/斜轴、相交孔、破孔、密封槽、缺失层深或不可验证圆锥均阻断。`[证据类型：说明书 + 推断]`

### 5.2 规则匹配与步骤

`DTM-CLN-HOLE-003` 孔规则按“孔类别 + 每层直径区间 + 层数量/形态”匹配。区间边界必须在规范化资料中显式声明为开/闭，禁止延续 Excel 表头中含糊的 `min=<d<=max` 文本而不作迁移决定。`[证据类型：Excel + 推断]`

`DTM-CLN-HOLE-004` 孔方案是最多 11 个槽位折叠成的非空有序步骤列表；空槽跳过但不得改变其余步骤相对顺序。每步至少含稳定步骤 ID、白名单策略 ID、刀具选择条件、起点表达式、深度表达式、目标层索引和可选沉头标志。`[证据类型：Excel]`

`DTM-CLN-HOLE-005` 受限表达式变量：`Hn` 表示第 n 层的已确认高度/深度语义，`Dn` 表示第 n 层直径，`Tn` 表示已声明刀具尺寸变量，`AT` 表示只允许作用于最深通孔层的正贯穿余量。每个符号的坐标方向必须在 JSON schema 中唯一规定。`[证据类型：Excel + 推断]`

`DTM-CLN-HOLE-006` 沉头孔默认可建议“内孔后外层沉头”的有序链；操作者可明确取消沉头步骤，但取消不得改变内孔目标深度或把外层几何并入内孔。`[证据类型：说明书 + Excel]`

### 5.3 拒绝条件

以下任一条件阻断整链：无匹配规则或多条同优先级规则；方案未选择；未知策略；表达式失败；刀具不存在或类型不匹配；钻头超过目标孔安全上限；铰刀/丝锥规格不匹配；刀刃/总长不足；Q/单次深度非正或越底；R/下刀面无效；沉头刀几何无法验证；通孔余量用于非最深层。`[证据类型：说明书 + Excel + 推断]`

## 6. 框、槽与型腔

`DTM-CLN-FRAME-001` 框/槽识别输入至少含：稳定几何引用、Setup、正面轴向、底面与侧壁证据、外边界、深度、开闭状态、自由端、孤岛/保护区、置信和拒绝原因。`[证据类型：Excel + 反编译入口 + 推断]`

`DTM-CLN-FRAME-002` V1 可匹配范围仅为正面 Z 向、平底直壁、闭合矩形/可验证凸多边形型腔，以及具有两个可解释自由端的简单开放槽。斜面、曲面底、非流形、相交、侧面/背面 Setup、不可重建开放边证据均阻断。`[证据类型：推断]`

`DTM-CLN-FRAME-003` 框规则可使用框类别、槽宽、框大小、通框加深、接底 R 和 R/BK 角作为匹配条件，但字段存在不代表对应路径已开放。规则命中斜面、插角、密封槽或不可验证 R 角时必须返回“能力未开放”。`[证据类型：Excel + 推断]`

`DTM-CLN-FRAME-004` 框方案按表中最多 8 个项目的顺序形成步骤链，语义包括开粗、中粗、粗清角、光底、清角、精轮廓和倒角。实现只能选择 CNEXT-CAM 已验证策略；缺失中间步骤允许跳过，但不允许把后续步骤提前。`[证据类型：Excel]`

`DTM-CLN-FRAME-005` 保护环必须闭合、位于外环内部、不触碰或穿越外环/其他保护环，并留有“刀具直径 + 双侧余量”所需通道。开放槽带保护环、参考刀具不可解析、插角为真、刀具直径不小于有效通道、刃长/总长不足、`stepOver > toolDiameter` 或 `stepDown > depth` 时整链阻断。`[证据类型：Excel + 推断]`

## 7. 深孔分阶段规划

`DTM-CLN-DEEP-001` 深孔资料以“材料 + 刀名称/类型 + 直径区间”为键，候选值分为正常加工、引导、慢速进刀、破孔减速、回退、中间过渡、啄钻和无级变速八组。转速为 r/min，进给为 mm/min，位置/分段为 mm，比例为 %。`[证据类型：Excel]`

`DTM-CLN-DEEP-002` 阶段顺序为：可选引导 → 可选慢速进入 → 正常加工（可按啄钻分段）→ 仅在可证明孔底/破孔位置时可选破孔减速 → 可选受支持回退。中间过渡只限制阶段之间的移动，不得创建跨孔低位快移。`[证据类型：Excel + 推断]`

`DTM-CLN-DEEP-003` 引导和慢速区间必须位于确认孔深内且起止有序；速度百分比在 `(0,100]`；啄钻最大/最小分段均 `> 0` 且最大值不小于最小值，每段不越盲孔底；转速/进给在任何阶段都必须保持正值。`[证据类型：Excel + 推断]`

`DTM-CLN-DEEP-004` 回退方向、阶段冷却、无级变速或控制器专用阶段若没有独立后处理合同、最终代码安全校验和最终代码仿真，必须阻断该方案而不是近似成普通 G81/G83。`[证据类型：Excel + 推断]`

## 8. 吊环孔、攻丝与内螺纹铣

`DTM-CLN-THREAD-001` 吊环孔规格键为“制式 + 规格”，输出底孔直径、螺距、螺纹直径，以及可选钻孔、扩孔/铣孔、沉头、倒角、攻丝或内螺纹铣建议。公制、英制、美制不得交叉回退。`[证据类型：Excel]`

`DTM-CLN-THREAD-002` 标准步骤顺序为：钻底孔 → 大规格时可选分级钻/铣孔 → 可选沉头 → 可选孔口倒角 → 攻丝或受限内螺纹铣。攻丝与铣牙是互斥的最终成牙方案，除非另有经人工批准的工艺规则。`[证据类型：Excel + 推断]`

`DTM-CLN-THREAD-003` 攻丝要求目标螺距已确认且丝锥螺距相容；内螺纹铣要求内牙、刀具尺寸可进入底孔、螺距相容、方向和深度明确。外螺纹、G76、多齿换层及未验证 3D 螺纹路径不在本规格开放范围。`[证据类型：说明书 + Excel + 推断]`

`DTM-CLN-THREAD-004` 第二版吊环孔表新增的 XY 分层、粗/精次数和每次余量只产生二维内螺纹铣建议；布尔开关为空或假时不得自动启用，启用时次数为非负整数、余量非负，且仍需刀具中心包络与现有策略合同。`[证据类型：Excel + 推断]`

`DTM-CLN-THREAD-005` 两版吊环孔表对部分规格的孔深、刀具直径和螺距存在差异；没有人工指定资料版本和生效日期时必须报告版本冲突，不得按“较新文件名”静默覆盖。`[证据类型：Excel + 推断]`

## 9. 刀具与材料档位

`DTM-CLN-TOOL-001` 刀具资料档位必须版本化，并以材料、刀具规范类型和不重叠直径区间匹配。输出是建议参数及匹配解释，不是工序许可。`[证据类型：Excel + 推断]`

`DTM-CLN-TOOL-002` 同一材料/刀具类型的区间不得重叠；边界开闭必须显式；无匹配、多个同优先级匹配、材料占位符或不合理参数值均返回资料错误。`[证据类型：Excel + 推断]`

`DTM-CLN-TOOL-003` 模板刀具名称只能作为选择条件，确认时必须解析为当前刀库的唯一刀具，并重新验证类型、直径、螺距、刀角、有效刃长、总长、额定转速和机床限制。`[证据类型：说明书 + Excel + 推断]`

## 10. 容差来源与优先级

`DTM-CLN-TOL-001` 容差必须按来源分层保存，禁止把识别容差、制造规格公差和测试比较容差混成一个全局数值。`[证据类型：推断]`

| 容差类别 | 权威来源 | 用途 | 本规格决定 |
| --- | --- | --- | --- |
| CAD/拓扑识别容差 | STEP/OCC 导入与识别合同 | 同轴、连续、闭合、相交判断 | 沿用现有内核/识别器合同；不得从 Excel 推导。 |
| 资料匹配区间 | 版本化 Excel→JSON 迁移结果 | 选择规则和刀具档位 | 迁移时显式开/闭边界；歧义阻断。 |
| 螺纹/刀具制造公差 | 经批准标准、图纸或刀具供应商数据 | 底孔、螺距、刀具适配 | 当前五份 Excel 没有给出制造公差权威来源，需人工补齐。 |
| 产品安全门容差 | CNEXT-CAM 现有生成服务合同 | 防止钻头过大、铰刀/丝锥不匹配、刀长不足 | 作为兼容基线，不反向宣称为 DTM 事实。 |
| 黑盒断言容差 | 测试夹具明确声明 | 数值比较与最终轨迹检查 | 只用于测试，不进入工艺资料。 |

当前 CNEXT-CAM 已有兼容基线包括：钻/铰目标直径比较使用 `max(0.05 mm, 目标直径×1%)`，丝锥/铣牙螺距比较使用 `max(0.01 mm, 目标螺距×2%)`，已知刃长/总长比较保留 0.01 mm 安全余量。它们必须由 CNC/工艺负责人确认是否继续作为生产规则；本文不改变这些数值。`[证据类型：推断]`

## 11. 黑盒示例

### 11.1 可接受：两层沉头孔

输入：正面 +Z、已确认 Setup、连续同轴的外层圆锥沉头与内层圆柱孔；方案含“钻内孔→沉头”；所需刀具唯一且长度充足。输出：`Draft` 候选，明确两步顺序和来源。操作者选择并确认后一次性得到两道正式工序。`[证据类型：说明书 + Excel + 推断]`

### 11.2 可接受：取消沉头

在 11.1 候选上显式取消沉头。输出只保留内孔步骤，内孔几何、深度和刀具校验不变；不得返回空方案或把外层深度用于内孔。`[证据类型：说明书 + 推断]`

### 11.3 拒绝：方案后段缺刀具

前三步可解析、第四步刀具不存在。输出：原子失败，错误定位到方案与步骤 ID，正式工序列表为空。`[证据类型：Excel + 推断]`

### 11.4 可接受：闭合凸型腔

输入：正面平底直壁闭合凸外环、一个完整保护环、通道满足刀径和双侧余量。输出：只使用已验证型腔策略的有序建议；确认后正式工序保留外环、保护环和稳定几何引用。`[证据类型：Excel + 推断]`

### 11.5 拒绝：框规则要求插角

输入几何本身可加工，但命中的资料步骤 `是否插角=true`。输出：`CAPABILITY_NOT_OPEN: corner_insertion`，不自动改成普通清角，不创建部分工序。`[证据类型：Excel + 推断]`

### 11.6 拒绝：深孔破孔位置未知

输入为盲孔或识别结果无法证明破孔面，但资料包含破孔减速阶段。输出：拒绝该方案；不得按总深度猜测破孔位置。`[证据类型：Excel + 推断]`

### 11.7 拒绝：吊环孔版本冲突

同一制式/规格在两版资料中得到不同钻孔深度或刀具。未指定资料版本时输出版本冲突和差异字段，不产生建议。`[证据类型：Excel + 推断]`

## 13. 高级动态铣与 3D 缺口

`DTM-CLN-ADV-001` 动态铣只记录为缺口：在能证明连续绕行、径向吃刀、进刀圆弧、刀具中心边界、剩余材料和最终代码安全之前，不生成建议。`dynamicMilling` 入口存在只能证明功能名存在。`[证据类型：说明书 + 反编译入口 + 推断]`

`DTM-CLN-ADV-002` 3D 斜面、3D 倒角、自由曲面接触、侧面/3+2 和多轴只记录为缺口：必须先有专用 Setup、旋转顺序/单位、机床轴限位、可靠曲面求交/刀具接触、碰撞与代表性机床验收。相关入口存在不构成算法或安全证据。`[证据类型：说明书 + 反编译入口 + 推断]`

## 15. 给实现线程的无反编译代码接口清单

以下是可直接编码的合同，不是实现代码。

### 15.1 资料层 DTO

- `AutomationCatalog`：`schemaVersion`、`catalogId`、`catalogVersion`、`effectiveDate`、`sourceDigest`、`materials[]`、`toolCuttingBands[]`、`holeRules[]`、`frameRules[]`、`deepHoleProfiles[]`、`threadSpecifications[]`。
- `ToolCuttingBand`：材料键、规范化刀具类型、直径区间及边界开闭、建议转速/进给/进退刀/步距/余量、来源定位。
- `FeatureRule`：稳定 ID/版本、优先级、特征条件、方案引用、启用状态和明确的能力要求。
- `PlanStep`：稳定步骤 ID、白名单策略 ID、刀具选择条件、受限起点/深度表达式、目标层、可选能力标志；不含控制器文本。
- `DeepHoleProfile`：八个阶段组的规范化可选字段和单位。
- `ThreadSpecification`：制式、规格、底孔、螺距、螺纹直径、候选刀具和有序步骤。

### 15.2 服务边界

- 资料加载：输入版本化 JSON；输出完整 catalog 或字段级错误。禁止部分加载、宏、Excel 运行时读取和动态求值。
- 刀具资料匹配：输入材料、规范化刀具类型、目标直径、catalog 版本；输出唯一档位及解释，或无匹配/歧义错误。
- 孔规则匹配：输入 `CompoundHoleFeature`、catalog 和刀具快照；输出 `AutoHoleCandidate` 兼容草稿及拒绝原因。
- 框规则匹配：输入 `SlotFrameFeature`、catalog 和刀具快照；输出多步骤工序建议及保护边界，不创建工序。
- 深孔规划：输入确认孔深、材料、刀具和阶段资料；输出 controller-neutral 阶段建议或阻断。
- 吊环孔规划：输入制式、规格、几何和刀具；输出钻/沉头/倒角/攻丝或内螺纹铣候选链。
- 确认适配：把已验证建议映射到现有 `OperationProposal` / `OperationParameterLayers`，由 `OperationFactory` 原子创建；失败结果的正式工序列表必须为空。

### 15.3 稳定错误码最小集合

`SCHEMA_VERSION_UNSUPPORTED`、`UNIT_MISSING`、`RANGE_AMBIGUOUS`、`RULE_NOT_FOUND`、`RULE_AMBIGUOUS`、`CATALOG_VERSION_CONFLICT`、`GEOMETRY_UNSUPPORTED`、`CAPABILITY_NOT_OPEN`、`FORMULA_REJECTED`、`TOOL_NOT_FOUND`、`TOOL_INCOMPATIBLE`、`TOOL_REACH_INSUFFICIENT`、`SETUP_UNCONFIRMED`、`PARAMETER_OUT_OF_RANGE`、`ATOMIC_CONFIRMATION_FAILED`。

## 16. 给实现线程的测试清单

### 16.1 资料与解析

- JSON schema：未知版本、缺单位、重复 ID、重叠档位、含糊边界、非有限数、占位材料、未知字段策略。
- 安全输入：证明不读取 Excel、不执行公式/宏/脚本/命令；受限表达式覆盖合法变量、括号、四则运算、未知变量、除零、负值和结果上限。
- 版本：两版资料并存、显式选择、差异报告、旧正式工序快照不被新资料改写。

### 16.2 孔与复合孔

- 单层盲孔、最深层通孔、两层台阶孔、圆锥沉头、取消沉头、多步骤顺序。
- 侧面/斜轴、层间隙/重叠、非最深层贯穿、密封槽、破孔/相交、缺层深拒绝。
- 后段缺刀具、非法表达式、刀长不足、R/Q 无效时整链原子失败。
- 重识别保持人工覆盖；规则/资料变化后转 `Conflict` 或 `Stale`。

### 16.3 框/槽

- 闭合矩形、凸多边形、一个保护环、简单开放槽及步骤顺序。
- 保护环碰边/越界、窄通道、异常自由端、非流形、曲面底、相交、侧面 Setup 拒绝。
- 插角、斜面、密封槽和未开放 R 角均返回稳定 `CAPABILITY_NOT_OPEN`。

### 16.4 深孔

- 材料/刀径档位唯一匹配，正常/引导/慢速/啄钻阶段顺序与单位。
- 阶段区间反转、百分比为 0 或大于 100、最大分段小于最小分段、盲孔越底拒绝。
- 破孔位置未知、回退/无级变速无后处理合同、跨孔低位快移意图拒绝。

### 16.5 吊环孔/螺纹

- 公制、英制、美制同名规格隔离；底孔/螺距/刀具匹配；攻丝与内螺纹铣互斥选择。
- 两版深度/刀具/螺距差异必须报告冲突。
- XY 分层开关、次数和余量边界；外螺纹、G76、多齿换层、3D 拒绝。

### 16.6 端到端验收

- 每个已开放方案均走“候选 → 显式确认 → `OperationFactory` → controller-neutral 路径 → CQ8/Fanuc/Siemens（适用）→ `GCodeSafetyValidator` → 最终代码仿真”。
- 验证工序顺序、模板来源/版本快照、保存重开、几何/Setup/刀具变化导致失效。
- 任何失败均不得留下部分正式工序或旧程序被误判为有效。
- 冷却输出应与变更前基线逐字节/语义等价；本实现线程不得修改冷却行为。
