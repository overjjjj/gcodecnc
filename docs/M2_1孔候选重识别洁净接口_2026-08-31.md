# M2.1 孔候选重识别与人工覆盖洁净接口（2026-08-31）

## 1. 目的、范围与证据

本文为 M2 的候选重识别、人工覆盖和沉头取消收敛一份可编码的领域合同。它只消费已提交的 DTM 洁净规格、M2 接口/黑盒规格以及项目公开领域接口。

- 服务输入为当前不可变孔快照及可选的 `previousCandidate` 快照；输出只为候选状态、差异解释和稳定原因，绝不创建正式工序。
- 不接 UI、`OperationFactory`、刀路、后处理、控制器、G-code、安全校验、仿真或冷却；不修改其中任何行为。
- 所有“相同”比较使用版本化 DTO 已提供的稳定标识作精确比较；本合同不以名称、显示文本、列表顺序、当前最新版本或近似尺寸推断相同。
- 沿用上位洁净规格的证据分类；其中 `推断` 是可评审合同，不是已确认的业务事实。

本文不取代 M2 的规则匹配、表达式、刀具可行性或人工确认合同；只规定它们在重识别时如何产生可解释的候选状态。

## 2. 统一术语

| 术语 | 唯一定义 | 不等同于 |
| --- | --- | --- |
| 候选快照 | 某次识别与匹配结果的不可变、可比较记录。 | 可写的 UI 编辑模型或正式工序。 |
| 当前观测 | 本次识别、匹配和资料解析取得的不可变输入。 | 对旧候选的就地更新。 |
| 身份维度 | `geometryRef`、`geometryRevision`、`layerSignature` 和全部被引用资料版本。 | 显示名称、更新时间或规则行序。 |
| 同一几何 | `geometryRef`、`geometryRevision`、`layerSignature` 三者均精确相同。 | 仅 `geometryRef` 相同。 |
| 同一可复用方案 | 同一几何，且规则、计划、模板、材料、机床和刀具目录版本均精确相同。 | 有相似步骤或同名方案。 |
| 人工覆盖 | 操作者明确保存的进给、转速、刀具或方案选择；每项须定位到稳定目标。 | 匹配服务猜测的默认参数。 |
| 保留 | 在同一可复用方案上原样携带一个可定位且仍可解析的人工覆盖。 | 静默重算、换刀或改值。 |
| 冲突 | 输入/资料仍可解析，但旧快照与当前观测或人工覆盖不兼容，须人工处理。 | 可由服务选择一方解决的普通差异。 |
| 过期 | 比较所需的旧引用版本、旧几何或资料目录无法解析。 | 有一个更新版本可用。 |

`M21-IF-TERM-001` “取消沉头”是针对候选计划中 `countersinkStep=true` 的显式人工覆盖，不是改变孔层几何或对所有外层步骤的泛化删除。`[上位规范：M2-IF-STATE-005、DTM-CLN-HOLE-006；证据类型：说明书 + Excel + 推断]`

| DTO | 字段 | 合同 | 上位规范 / 证据类型 |
| --- | --- | --- | --- |
| `FeatureIdentity` | `geometryRef` | 稳定引用的精确字符串；缺失不能比较。 | `M2-IF-INPUT-001` / 说明书 + 推断 |
| `FeatureIdentity` | `geometryRevision` | 来自识别层的版本/digest；不可用当前时间替代。 | `M2-IF-INPUT-001` / 推断 |
| `FeatureIdentity` | `layerSignature` | 上游提供的、涵盖层序、类型、直径、起止平面、盲/通的稳定值。 | `M2-IF-INPUT-001`、`M2-IF-STATE-002` / 说明书 + 推断 |
| `CandidateProvenance` | `ruleRef`、`planRef`、`templateRef` | 均为 `id + version` 的精确引用。 | `M2-IF-OUTPUT-001`、`DTM-CLN-COMMON-007` / 说明书 + 推断 |

`M21-IF-IDENTITY-001` 三个几何字段只有全部精确相同才为“同一几何”。`geometryRef` 相同但 `geometryRevision` 或 `layerSignature` 不同，结果必须记录可比较差异并转 `Conflict`，不能套用旧候选。`[上位规范：M2-IF-INPUT-001、M2-IF-STATE-002；证据类型：说明书 + 推断]`

`M21-IF-IDENTITY-002` 对“同一几何”再要求全部 `CandidateProvenance` 引用精确相同，才可复用人工覆盖和取消沉头标志。任何仍可解析的规则、方案、模板、材料、机床或刀具目录版本差异为 `Conflict`，不能按名称、最新版本或相近刀具自动对齐。`[上位规范：M2-IF-STATE-001、M2-IF-STATE-003、M2-IF-STATE-005；证据类型：说明书 + 推断]`

## 4. 比较、解析与状态机

### 4.1 判定顺序

1. 校验请求快照完备性与调和合同版本；字段缺失则 `Rejected`。
2. 解析旧候选和当前观测必需的几何与资料版本。任一比较必需旧引用为 `Missing` 或 `Withdrawn`，则 `Stale`；不寻找替代版本。
3. 无 `previousCandidate` 时，返回当前观测的 `Draft` 或其已有 `Rejected`/`Conflict` 状态，不声称人工覆盖被保留。
4. 比较几何三元组；任一差异为 `Conflict`。
5. 比较全部资料版本；任一可解析差异为 `Conflict`。
6. 在同一可复用方案上，逐项验证人工覆盖目标与刀具选择；无法保留者为 `Conflict`，其余明确为 `Preserved`。
7. 处理 `cancelCountersink`；只按有效计划步骤的布尔标志过滤，并对剩余链完成 M2 已有校验。
8. 仅当所有必要比较相同且有效覆盖均已保留时，返回旧的可编辑状态（`Draft` 或 `Selected`）及 `manualEditDisposition=Preserved`；没有人工覆盖时为 `None`。

`M21-IF-STATE-001` 解析失败优先于差异比较：服务不能证明旧版本内容时，必须 `Stale`，而非猜测 `Conflict` 或自动采用当前版本。`[上位规范：M2-IF-STATE-003、M2-BB-024、M2-BB-030；证据类型：说明书 + 推断]`

`M21-IF-STATE-002` 解析成功后的不一致优先于保留：几何、方案或任何资料版本改变，以及覆盖目标失效，均为 `Conflict`；`Conflict` 不清除旧候选、覆盖、选择或取消标志。`[上位规范：M2-IF-STATE-002、M2-IF-STATE-004、M2-BB-027、M2-BB-029、M2-BB-042；证据类型：说明书 + Excel + 推断]`

### 4.2 可观察状态机

```text
无 previousCandidate ──────→ Draft / Rejected / Conflict（采用当前观测）

Draft 或 Selected
  ├─ 比较引用不可解析 ────→ Stale
  ├─ 几何或可解析资料变化 ─→ Conflict
  ├─ 同一方案、覆盖可定位 ─→ 原状态 + Preserved
  └─ 取消沉头后空链 ──────→ Rejected

Conflict ──新的完全相同且人工重新处理──→ Draft 或 Selected
Stale    ──旧引用重新可解析且重评估通过──→ Draft 或 Selected
Rejected ──新的完整有效观测──────────────→ Draft
```

`M21-IF-STATE-003` `Selected` 仅表示候选内已显式选择方案；M2.1 既不验证确认事务，也不转换为 `Validated` 或 `Confirmed`。`[上位规范：M2-IF-STATE-001、M2-IF-OUTPUT-002；证据类型：说明书 + 推断]`

`M21-IF-STATE-004` 对无人工覆盖的 `Draft`，同一可复用方案重识别保持 `Draft`、`manualEditDisposition=None`；不得伪称 `Preserved`。`[上位规范：M2-IF-STATE-001、M2-BB-026；证据类型：推断]`

## 5. 取消沉头合同

`M21-IF-CANCEL-001` `cancelCountersink=true` 只移除当前有效计划中 `countersinkStep=true` 的步骤；不得改变剩余步骤的 `stepId`、顺序、层引用、深度表达式、进给、转速或刀具选择。`[上位规范：M2-IF-STATE-005、M2-BB-013；证据类型：说明书 + Excel + 推断]`

`M21-IF-CANCEL-002` 过滤后无步骤时返回 `Rejected / CANDIDATE_STEP_CHAIN_EMPTY`，差异解释必须包含被过滤步骤；不产生空 `Draft` 或正式工序。`[上位规范：M2-BB-014、DTM-CLN-HOLE-004、DTM-CLN-HOLE-006；证据类型：Excel + 推断]`

`M21-IF-CANCEL-003` 旧候选取消过沉头时，只有同一几何且同一可复用方案才可保留该标志；沉头层、计划版本或 `countersinkStep` 分配变化且仍可解析时为 `Conflict`，不得悄然清除或迁移该标志。`[上位规范：M2-IF-STATE-005、M2-BB-041、M2-BB-042；证据类型：说明书 + Excel + 推断]`

## 6. 输出、错误和差异解释

### 6.1 `CandidateReconciliationResult`

| 字段 | 类型 | 合同 | 上位规范 / 证据类型 |
| --- | --- | --- | --- |
| `state` | `Draft` / `Selected` / `Conflict` / `Stale` / `Rejected` | 候选状态；不含正式工序状态。 | `M21-IF-STATE-003` / 说明书 + 推断 |

## 7. 明确阻断项

下列问题在现有证据中不能唯一确定；相应功能必须阻断，不能由 M2.1 补默认：

| 阻断项 | 未确认前要求 | 证据类型 |
| --- | --- | --- |
| `layerSignature` 的跨序列化规范、哈希算法与兼容版本 | 仅比较上游已提供的稳定值；缺失或不同格式不作语义归一化，返回 `Rejected/CANDIDATE_SNAPSHOT_INVALID` 或由上游拒绝。 | 推断 |
| 刀具 selector 的等价关系 | 不把同名、同直径或相似刀具视为同一把；需要唯一版本引用，否则 `Conflict`。 | 说明书 + Excel + 推断 |
| 人工进给/转速覆盖与新方案步骤的迁移规则 | 不跨 `stepId`、策略或方案版本迁移；目标不存在即 `Conflict`。 | 推断 |
| 重识别对已 `Conflict`/`Stale` 覆盖的“人工重新处理”动作语义 | M2.1 只报告状态；如何写入新快照需独立业务命令合同。 | 推断 |
| 从 `Conflict`/`Stale` 到可编辑态的授权、审计和事务 | 不接 UI 或确认事务；需业务批准的命令/审计模型。 | 推断 |
| 任何创建/回滚正式工序的事务语义 | M2.1 不调用 `OperationFactory`；维持 M2 原子确认边界。 | 说明书 + 推断 |

`M21-IF-BLOCK-001` 阻断项存在时服务只能输出稳定拒绝或冲突/过期解释，不能通过自动 selector 选择、参数迁移、版本替换、空步骤补齐或事务猜测得到可确认候选。`[上位规范：M2-IF-BOUNDARY-001、M2-IF-OUTPUT-002；证据类型：说明书 + 推断]`

## 8. 公共边界与禁止事项

| 公共边界 | M2.1 可做 | M2.1 禁止做 |
| --- | --- | --- |
| M0 版本化 DTO | 读取稳定身份、资料版本和解析结果。 | 读取 Excel、推断最新版本或改写 catalog。 |
| `AutoHolePlanningService` 公开候选边界 | 输入/输出兼容候选快照，供其重识别流程适配。 | 修改服务、确认语义或内部候选集合。 |
| `OperationFactory` | 仅在说明中标注其处于人工确认边界之外。 | 调用、创建、删除或回滚正式工序。 |
| UI、策略、刀路、后处理、控制器、冷却 | 无。 | 直接依赖、修改或产生任何副作用。 |

`M21-IF-BOUNDARY-001` M2.1 完成定义是“把当前观测与旧候选确定性调和为可解释的候选状态”，不是自动确认、自动换刀、自动迁移人工参数或生成加工结果。`[上位规范：DTM-CLN-COMMON-003、DTM-CLN-COMMON-004、M2-IF-OUTPUT-002；证据类型：说明书 + 推断]`
