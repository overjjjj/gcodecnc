# M2.1-B 人工覆盖与取消沉头洁净接口（2026-08-31）

## 1. 范围与洁净边界

本文把 M2.1 已冻结的候选调和合同细化为“有效计划、人工覆盖、取消沉头”可编码接口。它只消费 M2/M2.1 已提交规格和公开 DTO；输出为不可变候选状态、差异说明或拒绝原因。

- 不创建正式工序，不调用 `OperationFactory`，不接 UI、刀路、后处理、控制器或冷却；任何本接口调用前后正式工序数不变。
- 不修改输入快照。`Conflict`/`Stale` 只能复制旧候选，当前计划和解析证据只进入 `explanation`。
- 术语 `AutomationMachiningPlanStep` 在本合同是优先兼容适配目标：公开接口已可见 `AutoHolePlanStep` 和 `MachiningPlanStepDefinition`，但本批未证实前者名称已作为统一 DTO 发布。因此实现前必须建立一对一字段映射；不能映射的字段保持阻断，禁止按名称或显示文本猜测。
- 证据类型沿用上位洁净规格；`推断` 是待评审合同，不是业务确认事实。

## 2. 术语

| 术语 | 唯一定义 | 不等同于 |
| --- | --- | --- |
| 有效计划 | 本次候选可应用的不可变有序步骤集合，带计划和层/沉头指纹。 | 可编辑 UI 列表或正式工序链。 |
| 基线参数快照 | 匹配出的某步骤参数及来源版本，不含人工覆盖。 | `StrategyParams` 的可写容器。 |
| 覆盖键 | `(kind, target)`；同一候选中唯一。 | `overrideId` 或列表位置。 |
| 目标解析视图 | 仅验证覆盖所指步骤、方案和刀具的不可变事实视图。 | selector 评分器、刀库搜索或替换策略。 |
| 计划指纹 | 计划引用和全部有效步骤的有序结构记录。 | 未定义的哈希算法。 |
| 沉头映射指纹 | 层签名、计划引用与每步沉头标志的有序结构记录。 | 仅 `cancelCountersink` 布尔值。 |

`M21B-IF-TERM-001` 同名、同直径或相近刀具不是相同 `toolRef`；本接口没有 selector 等价规则。`[上位规范：M21-IF-BLOCK-001、M2-IF-STATE-004；证据类型：说明书 + Excel + 推断]`

### 3.1 `ManualOverrideReconciliationRequest`

| `observedState` | `Draft` | 是 | M2.1-B 只调和当前唯一匹配候选；非 `Draft` 应由 M2.1 原样传播，不能进入本接口。 | `M21-IF-OBSERVED-001` / 说明书 + 推断 |
| `observedPlan` | `EffectivePlan` | 是 | 当前唯一匹配候选的有效计划；只允许 `Draft` 观测。 | `M21-IF-OBSERVED-001` / 说明书 + 推断 |
| `observedLayerSignature` | stable string | 是 | 当前识别层签名；与旧候选精确比较。 | `M21-IF-IDENTITY-001` / 说明书 + 推断 |
| `catalogResolution` | M2.1 `ResolutionView` subset | 是 | 解析旧/当前刀具目录与计划资料版本；不选最新版本。 | `M21-IF-RESOLUTION-001`、`M21-IF-RESOLUTION-002` / 说明书 + 推断 |
| `overrideTargetResolutionView` | immutable `OverrideTargetResolutionEntry` set | 是 | 专门解析人工覆盖目标与精确刀具引用。 | `M21B-IF-RESOLUTION-001` / 推断 |

`M21B-IF-INPUT-001` 输入及其中的计划、覆盖、解析条目均为值快照。服务只能构造新结果快照；不得就地改 `manualOverrides`、`cancelCountersink`、步骤参数、刀具或选择方案。`[上位规范：M21-IF-INPUT-001、M21-IF-OUTPUT-001；证据类型：说明书 + 推断]`

## 4. 有效计划与指纹

### 4.1 `EffectivePlan` 与 `EffectivePlanStep`

`EffectivePlanStep` 是 `AutomationMachiningPlanStep` 的最小兼容形状。实现优先把公开 `AutoHolePlanStep` / `MachiningPlanStepDefinition` 显式适配为该形状；不得为适配而改写公开 DTO 或补造缺字段。

| 字段 | 类型 / 单位 | 必填 | 合同 | 上位规范 / 证据类型 |
| --- | --- | --- | --- | --- |
| `planRef` | exact `id + version` | 是 | 计划稳定身份。 | `M2-IF-OUTPUT-001` / 说明书 + 推断 |
| `steps` | ordered `EffectivePlanStep` list | 是 | 1–11 步；按 `sequence` 连续且唯一。 | `M2-IF-STEP-001` / Excel + 推断 |
| `planFingerprint` | ordered record | 是 | 见 4.2；不规定 hash。 | `M21B-IF-PLAN-001` / 推断 |
| `countersinkMappingFingerprint` | ordered record | 是 | 见 4.2；比较沉头映射变化。 | `M21B-IF-CANCEL-003` / 推断 |
| `stepId` | stable string | 是 | 计划内唯一，不按序号或名称匹配。 | `M2-IF-STEP-001` / Excel + 推断 |
| `sequence` | integer `1..N` | 是 | 连续、唯一，定义执行相对顺序。 | `M2-IF-STEP-001` / Excel + 推断 |
| `layerOrdinal` | positive integer | 是 | 引用存在孔层。 | `M2-IF-STEP-001` / Excel + 推断 |
| `countersinkStep` | boolean | 是 | 仅此字段决定取消沉头时是否过滤。 | `M2-IF-STATE-005` / 说明书 + Excel + 推断 |
| `strategyRef` | approved stable reference | 是 | 精确策略身份；不是策略显示名。 | `M2-IF-STEP-001` / 说明书 + 推断 |
| `parameterSnapshot` | immutable typed parameters | 是 | 含基线数值、单位、来源/版本；不含手工覆盖。 | `DTM-CLN-COMMON-005`、`M2-IF-OUTPUT-001` / 说明书 + 推断 |
| `toolSnapshot` | `toolRef + toolCatalogRef` | 是 | 匹配出的精确刀具及目录版本。 | `DTM-CLN-TOOL-003`、`M2-IF-INPUT-002` / 说明书 + Excel + 推断 |

`M21B-IF-PLAN-001` `planFingerprint` 是 `(planRef, steps 按 sequence 的 [stepId, sequence, layerOrdinal, strategyRef, parameterSnapshot identity, toolSnapshot identity, countersinkStep])` 的有序记录；任一字段差异即计划变化。它不得由未确认哈希、步骤名称或重排后的列表替代。`[上位规范：M2-IF-STEP-001、M21-IF-IDENTITY-002；证据类型：Excel + 推断]`

`M21B-IF-PLAN-002` `countersinkMappingFingerprint` 是 `(observedLayerSignature, planRef, steps 按 sequence 的 [stepId, layerOrdinal, countersinkStep])` 的有序记录。层签名、计划引用、步骤 ID/层序或任一沉头标志变化时为 `Conflict/CANCEL_COUNTERSINK_MAPPING_CHANGED`，不能迁移取消标志。`[上位规范：M21-IF-CANCEL-003、M2-BB-041、M2-BB-042；证据类型：说明书 + Excel + 推断]`

## 5. `ManualOverride` 的互斥类型与重复规则

每个覆盖包含 `overrideId`、`kind`、`target`、`value`、`recordedAgainst`、`source=Operator`。`kind` 精确决定 `target` 与 `value` 的唯一形状：

| `kind` | `target` | `value` | 单位/额外约束 | 上位规范 / 证据类型 |
| --- | --- | --- | --- | --- |
| `Feed` | `{ stepId }` | `{ value }` | 有限且 `>0`，单位固定 `mm/min`。 | `DTM-CLN-PARAM-001`、`M2-BB-013` / Excel + 推断 |
| `SpindleSpeed` | `{ stepId }` | `{ value }` | 有限且 `>0`，单位固定 `r/min`。 | `DTM-CLN-PARAM-001`、`M2-BB-014` / Excel + 推断 |
| `Tool` | `{ stepId }` | `{ toolRef }` | 精确版本引用；不得使用名称、直径或 selector 文本。 | `DTM-CLN-TOOL-003`、`M2-BB-015` / 说明书 + Excel + 推断 |
| `PlanSelection` | `{ candidateId }` | `{ planRef }` | 值必须精确等于有效计划 `planRef`。 | `M2-BB-020`、`M2-BB-038` / 说明书 + 推断 |

`recordedAgainst` 必须含保存覆盖时的 `featureIdentity`、`CandidateProvenance`、`planFingerprint` 和（对取消沉头有关候选）`countersinkMappingFingerprint`；任一字段缺失为 `Rejected/MANUAL_OVERRIDE_INVALID`。`[上位规范：M21-IF-OVERRIDE-001、M21B-IF-PLAN-001；证据类型：说明书 + 推断]`

`M21B-IF-OVERRIDE-001` `kind`、`target`、`value` 必须是上述恰好一种组合；多类型 value、附加未声明字段、错误单位、非有限/非正数、错误目标形状或 `source != Operator` 均为 `Rejected/MANUAL_OVERRIDE_INVALID`。`[上位规范：M21-IF-OVERRIDE-001、DTM-CLN-PARAM-001；证据类型：说明书 + Excel + 推断]`

`M21B-IF-OVERRIDE-002` 覆盖键为 `(kind,target)`。同一请求中键重复（即使值相同）、`overrideId` 重复或 `PlanSelection` 多于一项均为 `Rejected/MANUAL_OVERRIDE_DUPLICATE`；服务不采用“最后一项获胜”或合并规则。不同 `kind` 指向同一 `stepId` 可以并存。`[上位规范：M21-IF-OVERRIDE-001、DTM-CLN-COMMON-003；证据类型：推断]`

## 6. 独立目标解析视图与判定顺序

### 6.1 `OverrideTargetResolutionEntry`

条目键为 `(overrideId, referencePath, referenceIdentity)`，集合无序且键唯一。

| 覆盖类型 | 必需路径与允许状态 | 合同 |
| --- | --- | --- |
| `Feed` / `SpindleSpeed` | `/target/stepId`：`Exists` 或 `Missing` | 证明目标步骤是否仍在当前计划。 |
| `Tool` | `/target/stepId`：`Exists` 或 `Missing`；`/value/toolRef`：`Exists`、`Missing` 或 `Incompatible` | `Exists` 表示精确 `toolRef` 在已解析当前目录中且兼容；不比较名称/直径。 |
| `PlanSelection` | `/target/candidateId`：`Exists`；`/value/planRef`：`Exists` 或 `Missing` | 计划值须为当前精确 `planRef`。 |

`M21B-IF-RESOLUTION-001` 每个覆盖必须恰有所有所需条目，条目身份必须精确等于覆盖字段；缺条目、重复键、路径不允许、状态不允许或身份不等均为 `Rejected/OVERRIDE_RESOLUTION_VIEW_INVALID`，优先于 `Stale` 与 `Conflict`。`[上位规范：M21-IF-RESOLUTION-001、M21-IF-STATE-001；证据类型：推断]`

`M21B-IF-RESOLUTION-002` 旧 `toolCatalogRef` 在 `catalogResolution` 中为 `Missing` 或 `Withdrawn` 时为 `Stale/CANDIDATE_REFERENCE_UNRESOLVED`，优先于 `OverrideTargetResolutionEntry` 的工具 `Missing`/`Incompatible`。目录可解析后，步骤/方案目标 `Missing`、工具 `Missing` 或 `Incompatible` 为 `Conflict`；都不得自动换成同名、同直径或 selector 近似项。`[上位规范：M21-IF-RESOLUTION-002、M21-IF-OVERRIDE-002、M2-BB-016、M2-BB-018；证据类型：说明书 + Excel + 推断]`

### 6.2 唯一判定顺序

1. 校验请求不可变快照、有效计划形状/指纹、覆盖互斥形状、`recordedAgainst` 和目标解析视图结构；失败为 `Rejected`。
2. 按 M2.1 解析旧目录、计划及资料引用；旧必需引用不可解析/撤回为 `Stale`。
3. 比较 `planFingerprint`；差异为 `Conflict/OVERRIDE_PLAN_CHANGED`。
4. 比较 `countersinkMappingFingerprint`（仅旧候选已取消沉头时）；差异为 `Conflict/CANCEL_COUNTERSINK_MAPPING_CHANGED`。
5. 在计划相同且目录可解析时应用目标解析视图：目标/工具缺失或不兼容为 `Conflict`。
6. 只有所有覆盖可定位且精确解析时，原样保留覆盖和取消标志；不得转换数值、换刀、迁移到新步骤或创建工序。

`M21B-IF-PRIORITY-001` 结构错误 → 旧目录不可解析 → 计划变化 → 沉头映射变化 → 覆盖目标/工具不可用 → 保留，是本接口唯一优先级。因而目录不可解析为 `Stale`，即使当前工具条目显示 `Missing`；有效目录下的 `Missing` 才是 `Conflict`。`[上位规范：M21-IF-STATE-001、M21-IF-OVERRIDE-002；证据类型：说明书 + Excel + 推断]`

## 7. 取消沉头与输出合同

`M21B-IF-CANCEL-001` `cancelCountersink=true` 只过滤 `countersinkStep=true` 的有效计划步骤。剩余步骤保持原始相对 `sequence` 及全部 `stepId`、层序、策略、基线参数、人工进给/转速/刀具覆盖和刀具快照；不得重算、压缩字段或改变值。`[上位规范：M21-IF-CANCEL-001、M2-BB-013；证据类型：说明书 + Excel + 推断]`

`M21B-IF-CANCEL-002` 过滤后没有剩余步骤时，返回 `Rejected/CANDIDATE_STEP_CHAIN_EMPTY`，在 `explanation.filteredStepIds` 记录所有已过滤步骤；不输出空计划，不创建正式工序。`[上位规范：M21-IF-CANCEL-002、M2-BB-014；证据类型：Excel + 推断]`

`M21B-IF-OUTPUT-001` `Conflict` 或 `Stale` 结果的 `candidate` 必须是旧候选业务内容的不可变完整复制，附新 `snapshotRevision`、结果状态和 `baseSnapshotRef`；当前计划、目标解析条目和差异只能出现在 `explanation/differences`。`Draft`/`Selected` 保留结果才以当前计划为内容。禁止合并两套步骤、就地修改旧快照或把当前值塞进旧覆盖。`[上位规范：M21-IF-OUTPUT-001、M2-BB-041、M2-BB-042；证据类型：说明书 + 推断]`

### 7.1 稳定错误码与最小路径

| 错误码 | 最小字段路径 | 结果 | 上位规范 / 证据类型 |
| --- | --- | --- | --- |

| `MANUAL_OVERRIDE_INVALID` | `/previousCandidate/manualOverrides/{overrideId}` | `Rejected` | `M21B-IF-OVERRIDE-001` / 推断 |
| `MANUAL_OVERRIDE_DUPLICATE` | 对应重复覆盖键或 ID | `Rejected` | `M21B-IF-OVERRIDE-002` / 推断 |

| `CANDIDATE_REFERENCE_UNRESOLVED` | `/previousCandidate/provenance/toolCatalogRef` | `Stale` | `M21B-IF-RESOLUTION-002` / 说明书 + 推断 |

## 8. 阻断项与公共边界

| 阻断项 | 未确认前行为 | 证据类型 |
| --- | --- | --- |
| selector 等价与替代刀规则 | 只接受精确 `toolRef`；同名/同径/近似均不等价。 | 说明书 + Excel + 推断 |
| 跨版本、跨计划或跨 `stepId` 的人工覆盖迁移 | 计划/目标变化即 `Conflict`，不迁移。 | 推断 |
| 人工重处理、冲突解决授权与审计命令 | M2.1-B 只报告，不写入新人工决定。 | 推断 |
| 正式工序确认/回滚事务 | 不调用 `OperationFactory`；保持 M2 既有确认边界。 | 说明书 + 推断 |
| 不可证明的 `AutomationMachiningPlanStep` 映射 | 不启用适配，返回 `EFFECTIVE_PLAN_INVALID`。 | 推断 |

`M21B-IF-BOUNDARY-001` 完成边界是“可解释地保留或拒绝候选内人工覆盖与沉头取消”，不是 UI 编辑、自动选刀、参数重算、刀路、控制器输出或正式工序创建。`[上位规范：M21-IF-BOUNDARY-001、M2-IF-OUTPUT-002；证据类型：说明书 + 推断]`
