# 工艺设置界面功能需求确认清单

> 基线资料：《加工中心控制系统用户使用手册 manual_zh_CN》第七章设计模块，重点为 7.2 至 7.7 的工艺参数、刀路与自动工艺配置。
>
> 范围：本期只确认“工艺设置”功能；二维绘图、视图操作、文件管理、仿真动画和机床控制界面暂不展开。
>
> 使用方式：后续每张参考软件截图按“编号”补入截图/证据列；每个条目需确认采用“复刻、等价实现、暂缓或不做”。

## 1. 确认口径与界面结构

| 项目 | 需求说明 | 确认结论 | 截图/证据 |
|---|---|---|---|
| 入口 | 用户从设计/CAM 界面选择几何对象后，进入相应工艺参数页；支持先选工艺后选几何，也支持先选几何后创建工艺。 | 待确认 |  |
| 参数分组 | 每个工艺页至少分为：加工对象、工艺/刀具、坐标与高度、切削参数、路径策略、余量与分层、进退刀、输出预览。无适用项时明确禁用并说明原因。 | 待确认 |  |
| 单位与校验 | 长度使用 mm、角度使用 °、速度使用 mm/min、主轴使用 r/min；输入即时校验范围、正负号和关联约束，并在保存前阻止危险或无效组合。 | 待确认 |  |
| 参数继承 | 新建工序可读取材料、刀具和工艺模板默认值；用户修改后仅影响当前工序，支持另存为模板。 | 待确认 |  |
| 工序树 | 每次确认生成可编辑的工序节点，保存几何选择、参数快照、刀具及坐标系；支持排序、复制、启用/禁用、删除与重新计算。 | 待确认 |  |
| 预览与追溯 | 参数变更后可预览选中几何、加工方向、起刀点、层数和路径；工序树可回显全部参数及引用的模板版本。 | 待确认 |  |

| P-13 | 抬刀与连接 | 配置加工点/层间抬刀、连接方式及过切控制。 | 抬刀段应回到指定安全逻辑；连接路径不得越过禁加工区域。 | 待确认 |  |

## 13. 开发思路与后续开发方案

### 13.1 总体开发思路

采用“**特征识别 → 工艺参数 → 刀路计算 → 程序输出 → 仿真/验收**”的闭环开发方式。每新增一个工艺，不只增加菜单或参数页，必须同时具备对象选择、参数校验、刀路、工序保存、后处理输出和测试样例。

| 原则 | 实施方式 |
|---|---|
| 先保证加工闭环 | 优先开发高频工艺，使其从模型选择到 G 代码输出完整可用；不把仅有界面或仅保存参数的功能算作完成。 |
| 参数统一管理 | 公共参数放入统一参数模型，工艺专用参数由策略扩展；坐标系、冷却、深度模式改为枚举控件，不继续以数字文本输入。 |
| 策略独立实现 | 每个工艺保留独立策略类：默认参数、适用刀具、几何校验、路径生成、时间估算和后处理所需信息在同一处维护。 |
| 先二维后曲面 | 先完成孔、槽、型腔、轮廓等二维/2.5D 工艺，再进入斜面、圆角、三维倒角和复杂曲面。 |
| 测试先行 | 每个策略先增加参数校验与典型模型测试，再接入界面；完成后增加刀路/G 代码快照测试和人工仿真检查。 |
| 状态真实可见 | “已完成”必须能生成并验证程序；尚未接入刀路的字段在界面和文档中明确标为“工艺记录”，避免误用。 |

### 13.5 近期建议的执行顺序

1. 先完成阶段 0：将已显示的坐标系、冷却和深度模式接入后处理，并将数字枚举改为可读控件。
2. 接着完成 G81/G83/G73 与孔位四种选择方式，形成完整孔加工闭环。
3. 再完善型腔岛屿、路径方式及轮廓过切/起刀点，让现有半成品策略达到可交付水平。
4. 然后补螺纹铣、外轮廓倒角和清角，覆盖常用精加工。
5. 最后进入曲面和自动化功能，避免在基础刀路尚未稳定时过早扩大范围。

## 14. 第七章 7.8 模块深化：自动工艺

> 7.8 的目标不是单纯识别特征，而是将“模型识别 → 规则匹配 → 工艺建议 → 人工复核 → 批量生成工序”做成可追溯闭环。自动生成的每项工序都必须允许人工修改，且修改后不应被下一次重算静默覆盖。

## 15. 整体方案功能实现总览

### 15.1 目标闭环

模型导入与编辑 → Setup/毛坯/坐标系 → 特征识别与人工选择 → 工艺参数与刀具 → 刀路生成 → 工序复核 → 后处理 G 代码 → 仿真、安全检查、机床验收。

任何模块只有同时满足“可配置、可生成、可复核、可输出、可测试”才标记为已完成；仅有菜单、参数或局部路径的模块统一标记为半成品。

### 16.7 本轮需求确认结论

1. 参考软件的核心差异不只在于工艺参数数量，更在于“选择—排序—预览—撤销—确认”的完整编辑会话；该能力应优先作为公共组件建设。
2. 孔类工艺与轮廓类工艺分别使用对象表选择器和串连选择器，两者需要共享撤销、恢复、确认、取消和画布同步机制。
3. 截图确认了参考软件的页面与按钮布局，但未展示全部参数页；具体数值范围、默认值及后处理规则仍以第 7 章说明书和后续截图为准。
4. 本项目状态为“半成品”或“待核验”的条目，必须完成代码核验、路径预览和 G 代码/仿真验证后才能更新为“已完成”。

### 17.5 本轮合并后的实施顺序

1. 先完成 `GeometryScene + SelectionChainController`：稳定图元 ID、命中/高亮、对象表、串连、排序、撤销与确认。
2. 再完成 `ParameterSchema + OperationFactory`：参数来源、人工覆盖、工序快照、过期状态和统一校验。
3. 选 G81、铣平面、挖槽、铣形作为代表工艺，完整验证“选择—参数—刀路—工序树—仿真/后处理”纵向闭环。
4. 在闭环稳定后扩展其余孔类、牙类和二维工艺；曲面类与自动模块依赖同一工序和参数模型。
5. 特征孔、智能倒角、自动孔和自动框只负责识别、规则匹配和批量创建草稿工序，不复制底层刀路与后处理逻辑。
