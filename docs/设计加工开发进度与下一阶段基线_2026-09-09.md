# 设计加工开发进度与下一阶段基线

日期：2026-09-09。用途：统一当前进度、人员责任和下一批开发顺序。本文是准备与调度基线，不表示本轮实施或测试了业务代码。

## 1. 当前目标

围绕用户提供的 52 页《测试文档》，先完善 CNEXT-CAM 设计加工工作区的常用操作：选择对象、刀具和策略、设置参数、确认工序、编辑/排序/删除/启停、生成并查看结果、修改后重算、保存重开。

先使用已有正面固定刀轴三轴能力。普通孔、槽、平面、轮廓先形成闭环，复杂三维策略、自动工艺、多 Setup、多轴和实机通信后置。现有后处理、预览及持久化继续提供必要支持，不扩大为新的平台开发。

主线程只负责梳理、下发、审阅与进度协调。协助开发人员负责 H01-H04 的界面和设计加工业务接入；项目侧开发任务负责共享服务、算法和输出校验。人员姓名及交付日期尚未确定，不将建议分工计为已有人开工。

## 2. 进度如何认定

- 资料完成：存在可交付文档或文件包。
- 已有实现：在当前工作区找到代码或接线；不等于通过验收。
- 待接入：存在实现或测试，但生产调用/工程注册未完整接入。
- 历史验证：旧日志或报告有验证记录，不自动覆盖之后的工作区改动。
- 待复测：已有修复迹象，但本轮没有运行覆盖该改动的测试。
- 待开发/待核实：没有足够当前完成证据，需实施或进一步检查。
- 阻塞：缺少资料或前置能力；不计入完成。

不按文件数、按钮数、线程创建请求或旧测试通过率推算整体完成百分比。开发台账与验收台账分别维护。
