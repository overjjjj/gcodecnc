# 工艺功能总体开发方案（2026-08-31）

## 1. 目的、范围与证据边界

本方案把已提交的安全能力收敛为可交付的工艺路线图，而不是扩大当前可加工声明。依据仅限仓库中的需求、洁净规格、验收记录和公开接口；不读取、不复制 DTM 反编译源码、源码整理或伪代码。

本轮覆盖全工艺公共基础、孔类、牙类（攻牙/铣牙）、槽类/型腔、二维与三维倒角/清角、刻字，以及作为后续能力的斜面/圆角/复杂三维。首期优先级固定为：孔闭环、牙类、二维倒角、槽/型腔、二维刻字。复杂三维、侧面多轴、动态铣、Hn/AT 和生产容差仍不进入实现承诺。

冷却的代码与既有行为冻结。资料中的 `coolantCompat` 只能随候选、参数或刀具快照保存，不能成为改变冷却指令、默认冷却选择或机床动作的依据。

## 2. 统一术语与状态边界

| 术语 | 本方案中的唯一含义 | 不包含的含义 |
| --- | --- | --- |
| `RecognizedFeature` | 识别层输出的、带 Setup/几何版本/证据的加工特征候选。 | 自动可加工结论或正式工序。 |
| `RuleMatch` | 对版本化规则的资格过滤、唯一命中或冲突/拒绝解释。 | 评分器、近似匹配或默认补值。 |
| `OperationProposal` | 可供人工选择的加工建议及其来源快照。 | 已写入工序仓储的对象。 |
| 参数与刀具快照 | 明确版本、单位、来源和兼容冷却字段的不可变建议。 | 插值、别名、单位换算或静默换刀。 |
| 人工确认 | 操作者在可审计输入上选定方案、刀具和覆盖的显式动作。 | `Conflict`/`Stale` 的隐式恢复授权。 |
| 正式工序 | 仅由 `OperationFactory` 原子创建的 `MachiningOperation`。 | 识别或规则服务的副作用。 |
| 阻断 | 信息、语义或安全边界不足，返回稳定拒绝/冲突/过期。 | 用启发式补齐后继续加工。 |

候选生命周期统一使用 `Draft`、`Selected`、`Conflict`、`Stale`、`Rejected`。`Validated` 与 `Confirmed` 只属于人工确认之后的事务边界；候选匹配和 M2.1 调和不得自行跨越该边界。

## 3. 冻结公共架构链

```text
RecognizedFeature
  → OperationProposal / RuleMatch
  → 参数与刀具快照
  → 人工确认
  → OperationFactory
  → 策略刀路
  → 安全检查
  → 仿真
  → 后处理
```

上图是产品与审计链。最终控制器代码需要由后处理器产生，因此代码级验收另保持既有顺序：`OperationFactory → Strategy → PostProcessor → GCodeSafetyValidator → final-code Simulation`。两种表述都不允许规则服务直接创建工序、调用策略或写控制器文本。

| 可复用资产 | 当前可复用范围 | 不可假定的能力 |
| --- | --- | --- |
| M0 `AutomationTemplateDocument` 与 JSON 白名单 | 版本、来源、生效期、参数集、受限表达式、拒绝未知字段/版本/非法范围。 | Excel 运行时读取、Hn/AT 数值语义、生产容差默认值。 |
| M1 `ToolCuttingParameterService` | 按材料、刀具类型、可选精确名称和显式端点唯一匹配；返回参数、来源和冷却兼容快照。 | 材料别名、单位换算、插值、外推或自动选第一条。 |
| M2 `AutoHoleRuleMatchingService` | 孔规则资格过滤、逐层开闭区间、唯一最高优先级、解释和安全拒绝。 | 真实 selector 解析、重识别迁移、确认事务。 |
| M2.1 洁净规格（16 条 `M21-IF-*`、34 个黑盒用例） | 下一批孔候选重识别、人工覆盖保留、沉头取消和 `Conflict/Stale` 调和的冻结输入。 | selector 等价、跨版本覆盖迁移、人工重处理授权、正式工序事务。 |
| 既有公开边界 | `OperationProposal`、`OperationFactory`、`AutoHolePlanningService`、`SlotFramePlanningService`、策略、后处理、安全校验和最终代码仿真。 | 绕过人工确认、多轴坐标变换或改变冷却。 |

## 4. 全工艺公共基础

- **当前状态：半成品。** M0/M1 已提供版本化参数和严格刀具资料匹配；M2 提供孔候选匹配；既有 `OperationFactory`、参数层、策略和最终代码验收可用。跨特征候选存储、统一重识别命令、selector 解析、人工授权审计尚未完成。

- **首期安全子集：** 仅版本化 JSON、稳定引用、精确单位、只读匹配、候选状态与人工确认前后明确分界；所有候选保留来源、资料版本和拒绝解释。

- **输入参数：** Setup/几何版本、材料、机床配置、版本化模板/规则/刀具目录、受限表达式、人工覆盖及显式确认意图。

- **输出 DTO/正式工序边界：** 输出 `RecognizedFeature`、`RuleMatch`、候选快照、`OperationProposal` 或稳定拒绝；只有确认适配器能调用 `OperationFactory`，且必须原子成功或零工序。

- **几何识别、规则匹配/选刀：** 识别层生成稳定 `geometryRef`、`geometryRevision`、`setupRef` 和证据；规则按版本/资格/显式优先级；刀具资料只用 M1 的精确匹配。

- **刀路算法：** 公共层不生成刀路；策略层仅消费已确认的工序与快照。

- **仿真/安全/G-code 验收：** 每个新策略必须经过 Setup、刀具尺寸/刃长/总长、安全高度、最终 G-code 安全检查和最终代码仿真；按后处理器分别保留 CQ8、Fanuc、Siemens 回归。

- **错误/拒绝：** 未知 JSON 字段/版本、缺稳定引用、无效单位或范围、资料歧义、过期引用、未确认表达式一律稳定拒绝；不降级为自由文本或默认值。

- **依赖：** M0、M1、`RestrictedFormulaEvaluator`、`OperationProposal`/`OperationFactory`、项目快照和 G-code 验收基线。

- **测试矩阵：** JSON round-trip/未知字段拒绝、端点、歧义、输入不变、候选状态机、确认原子性、旧项目兼容、最终代码安全和仿真。

- **完成定义：** 所有自动规划模块复用同一候选/来源/确认边界；无模块直接创建工序或改变冷却；每一条失败都有稳定码和字段路径。

## 5. 孔类

- **当前状态：半成品。** 已有正面 Z 向孔识别、人工确认孔工序、固定循环、复合孔候选和 M2 只读规则匹配；M2 已安全阻断 Hn/AT、非可证明起点和不连续层。M2.1 仅有洁净规格，尚未实现。

- **首期安全子集：** 正面 +Z、可验证连续同轴层的通孔/盲孔/沉孔/沉头；显式材料、机床、规则版本和唯一最高优先级；人工确认后使用既有中心钻、钻削、扩孔、铰孔、沉头和攻丝工序。深孔阶段仅在参考面、控制器支持和参数语义均获确认后开放。

- **输入参数：** `setupRef`、`geometryRef`/revision、层签名、材料、机床、规则/计划/模板版本、刀具目录、日期、已识别容差来源、人工沉头取消与覆盖快照。

- **输出 DTO/正式工序边界：** M2 输出 `Draft/Conflict/Stale/Rejected` 孔候选、规则解释、计划及刀具/参数快照；M2.1 后续输出调和结果。确认适配器才把完整通过校验的候选转换为 `OperationProposal` 并原子调用 `OperationFactory`。

- **几何识别、规则匹配/选刀：** 复用孔层证据与严格相邻层共面合同；M2 用显式开闭区间、资格过滤和唯一优先级。M1 只读服务匹配参数；实际 selector 到刀库实体的映射尚未批准，必须阻断。

- **刀路算法：** 复用已验证的固定循环/孔策略；新规则层不得写刀路。起点表达式除可证明零入口外保持 `FORMULA_REJECTED`。

- **仿真/安全/G-code 验收：** 覆盖多层孔、沉头取消、缺刀、R/Q/刃长/总长、Setup、CQ8/Fanuc/Siemens 最终代码、安全校验和仿真；确认失败后正式工序数必须为零。

- **错误/拒绝：** 非 Z 向/侧面、层断裂或重叠、缺证据、规则歧义、资料过期、selector 未解析、Hn/AT、深孔参考面/控制器未确认均拒绝或冲突。

- **依赖：** M0/M1/M2、M2.1 冻结规格、`AutoHolePlanningService`、`OperationFactory` 和现有孔策略。

- **测试矩阵：** M2 44 项黑盒、M2.1 34 项黑盒、区间端点、版本调和、覆盖保留/冲突、沉头取消空链、确认事务零副作用、真实 STEP 到最终代码仿真。

- **完成定义：** M2.1 全部 34 项自动化后，已批准 selector/授权/事务合同也具备测试；一个确认的正面孔候选可端到端产生可追溯正式工序和最终代码，其余状态绝不产生工序。

## 6. 牙类：攻牙与铣牙

- **当前状态：半成品。** 既有攻丝和螺纹铣策略、刀具类型/螺距生成安全门及人工确认路径存在；版本化螺纹规格、牙类规则匹配和吊环孔双版本合同尚未实现。

- **首期安全子集：** 正面 +Z 的内螺纹，显式公制规格、螺距、底孔、深度、丝锥或螺纹铣刀；操作者确认策略。外螺纹、锥管牙、未知制式和控制器专有循环不自动规划。

- **输入参数：** 经确认的孔几何、螺纹规格/版本、螺距、底孔、目标深度、材料、机床、刀具精确引用、进给/转速来源、Setup 与安全高度。

- **输出 DTO/正式工序边界：** 输出 `ThreadSpecification`、牙类 `OperationProposal`、参数/刀具来源快照和拒绝解释；确认后才创建攻丝或螺纹铣正式工序。

- **几何识别、规则匹配/选刀：** 识别只报告可验证的孔尺寸与已有螺纹证据，不从普通圆柱推断螺距；规格和刀具用精确版本/名称匹配，资料歧义即冲突。

- **刀路算法：** 复用攻丝固定循环和已验证螺纹铣策略；新首期不增加 controller-specific 宏、G76 或同步控制逻辑。

- **仿真/安全/G-code 验收：** 断言底孔、螺距、方向、深度、刀具类型、G80 取消、M5/M9 收尾、最终代码安全和仿真；三种后处理器各自黄金测试。

- **错误/拒绝：** 缺螺距/底孔/规格版本、丝锥不匹配、非正面 Setup、有效刃长/总长不足、控制器循环不支持或双版本吊环孔语义不明均拒绝。

- **依赖：** M0 `ThreadSpecification`、M1、孔确认边界、既有攻丝/螺纹铣策略、后处理能力矩阵。

- **测试矩阵：** 公制内牙攻丝、内牙铣削、规格/螺距/底孔拒绝、刀具类型、旧项目兼容、三后处理器、安全与仿真。

- **完成定义：** 只在资料/几何/刀具/控制器均可证明时生成一条人工确认的内螺纹工序；不能证明时保留候选与拒绝，不把牙类解释为普通孔。

## 7. 槽类与型腔

- **当前状态：半成品。** `SlotFrameRecognizer`、`SlotFramePlanningService`、槽/型腔策略与二维几何安全子集已存在；自动槽框 UI 和通用规则/选刀层未完成。

- **首期安全子集：** 正面 +Z、平底直壁、矩形或凸多边形闭合型腔，以及已保存自由端证据的简单开放槽；无曲面底、非流形、窄通道、相交候选和未确认孤岛。

- **输入参数：** 外环/保护环、自由端、底面和侧壁引用、Setup/几何 revision、深度、材料、端铣刀、余量、step-over/step-down、安全高度与参数来源。

- **输出 DTO/正式工序边界：** 输出 `SlotFrameFeature`、`ContourFeature`、规则/选刀候选与解释；人工确认后通过 `SlotFramePlanningService`/`OperationFactory` 创建单个正式槽或型腔工序。

- **几何识别、规则匹配/选刀：** 复用稳定环、保护区、孤岛和自由端证据；后续规则只允许版本化尺寸/材料/机床条件与 M1 精确刀具数据，不能从投影或未持久化拓扑补全。

- **刀路算法：** 复用 `SlotMillingStrategy`、`PocketRoughingStrategy` 与二维区域内核；凹多边形、多解偏置、自交修剪、动态铣明确不进入首期。

- **仿真/安全/G-code 验收：** 覆盖刀径/通道/保护区、深度、余量、刀长、正面 Setup、CQ8/Fanuc/Siemens、安全检查与最终代码仿真。

- **错误/拒绝：** 侧面/背面、曲面底、边界触碰、孤岛/保护区不完整、通道不足、自由端证据未持久化、动态铣请求均拒绝。

- **依赖：** `ToolpathGeometry2D`、槽框识别与规划服务、M1、`OperationFactory`、既有槽/型腔策略。

- **测试矩阵：** 矩形/凸多边形、开放槽证据、保护区与孤岛、刀具包络、旋转矩形、错误 Setup、最终代码三后处理器和仿真。

- **完成定义：** 首期几何可重开、候选可追溯、人工确认原子创建，且任何不在二维安全子集内的槽/腔无法输出刀路。

## 8. 二维与三维倒角、清角

- **当前状态：二维外轮廓倒角已完成安全子集；二维清内角半成品且 UI 禁用；三维倒角阻断。**

- **首期安全子集：** 正面平面、无孤岛、凸闭合外轮廓的二维外倒角；清内角仅限已粗加工、同一几何的正面轴对齐矩形型腔四角，且前序刀具与当前刀具关系可证明。

- **输入参数：** 平面轮廓/型腔证据、Setup、倒角宽度、刀具包含角/刀尖圆角、前序工序几何和刀具、深度/余量、安全高度。

- **输出 DTO/正式工序边界：** 输出倒角/清角 `OperationProposal` 与工具/参数快照；经人工确认创建轮廓类正式工序。三维输入只能输出明确阻断。

- **几何识别、规则匹配/选刀：** 复用可验证的平面凸环和矩形余角；按精确刀具角度/直径/有效刃长匹配。凹环、孤岛、曲面边界或不完整前序证据不做推测。

- **刀路算法：** 复用二维偏置和已验证轮廓倒角；清角复用四角残料路径。三维曲面偏置、自动插角、动态铣均不实现。

- **仿真/安全/G-code 验收：** 验证无过切、刀具包络、深度、前序关联、Setup、最终代码安全与仿真；三后处理器保持一致的安全拒绝。

- **错误/拒绝：** 非凸/自交/孤岛、非平面、3D 边界不足、前序工序不匹配、刀具角度或长度不足、插角/动态铣请求一律拒绝。

- **依赖：** `ToolpathGeometry2D`、轮廓策略、M1、前序工序追溯、`OperationFactory`。

- **测试矩阵：** 凸闭环、矩形四角、倒角尺寸和刀具角、保护/孤岛拒绝、前序不一致、G-code 安全与仿真；3D 请求必须稳定阻断。

- **完成定义：** 二维首期所有路径有几何包络和最终代码验收；清角在持久化前序证据和 UI 审核到位前仍不开放；三维倒角不作为交付能力。

## 9. 二维刻字

- **当前状态：未开始。** 缺字形轮廓来源、字体许可/版本、字符几何追溯、刀具与策略合同。

- **首期安全子集：** 正面平面上的单线或经批准、版本化的二维轮廓字体；只做显式文字、位置、尺寸、深度和刀具的人工确认刻字。曲面包覆、自动排版、图片矢量化和控制器宏不进入首期。

- **输入参数：** 文本 Unicode、经批准字体/轮廓版本、定位基准、2D 变换、深度、材料、刀具、进给/转速、安全高度、Setup。

- **输出 DTO/正式工序边界：** 输出 `EngravingFeature`、轮廓来源快照和 `OperationProposal`；人工确认后创建单一二维刻字工序，不把文本直接拼入 G-code。

- **几何识别、规则匹配/选刀：** 首期由人工输入或批准轮廓生成稳定 feature，不从模型猜文字；刀具以精确引用和最小线宽/刀径包络校验。

- **刀路算法：** 新建 controller-neutral 二维轮廓跟随安全子集，复用安全抬刀/进退刀，不引入字体 hinting、填充或三维投影。

- **仿真/安全/G-code 验收：** 字符轮廓闭合/方向、最小半径、深度、越界、刀具包络、安全代码与最终仿真；不同后处理器的文本不应改变语义。

- **错误/拒绝：** 未批准字体/许可、缺轮廓版本、自交/零长轮廓、曲面/侧面、线宽不足、文本无法编码或超出边界均拒绝。

- **依赖：** 字体/轮廓供应与许可决策、`ToolpathGeometry2D`、`OperationFactory`、轮廓策略、安全/仿真链。

- **测试矩阵：** 受控字体字符、定位/缩放、最小半径、非法 Unicode/字体、边界/Setup、最终代码和仿真。

- **完成定义：** 每个字符可由版本化轮廓追溯，人工确认后在正面二维平面安全加工；没有字体证据或超出子集时零工序。

## 10. 斜面、圆角与复杂三维

- **当前状态：二维矩形平面斜面安全子集完成；圆角识别只具几何发现能力；一般斜面、圆角和复杂三维阻断。**

- **首期安全子集：** 仅已验收的正面、矩形、单一平面斜面与球头刀；它作为既有能力维护，不扩展为通用三维。圆角、曲面倒角、多面/侧面和多轴不列入近期计划。

- **输入参数：** 已确认的平面边界、法向、Setup、球头刀精确数据、深度/余量/安全高度；复杂三维须额外具备曲面 UV、修剪边界、连续法向和机床运动学合同才可评审。

- **输出 DTO/正式工序边界：** 平面子集沿用已有 proposal/正式工序；复杂三维只输出 `Rejected` 与缺失证据，不能创建占位工序。

- **几何识别、规则匹配/选刀：** 只认可平面矩形投影边界；圆角不能凭半径发现就推导切削边界。选刀必须满足球头/包络/长度，不能从“相似曲率”推荐。

- **刀路算法：** 仅维护已验证二维斜面往复路径；曲面等距、五轴、侧刃、动态铣、插角不实现。

- **仿真/安全/G-code 验收：** 维护平面斜面最终代码与仿真；复杂三维需先建立碰撞、剩余、姿态、机床运动学和控制器能力验收，未具备前无 G-code。

- **错误/拒绝：** 非平面、非矩形、法向/边界不足、侧面/多轴、圆角修剪边界缺失、动态铣/Hn/AT/生产容差未批准均阻断。

- **依赖：** BRep 曲面/拓扑合同、三维刀具包络、碰撞仿真、机床运动学、后处理器能力矩阵和业务容差批准。

- **测试矩阵：** 既有平面斜面黄金测试；未来三维先做拒绝测试与几何合同测试，之后才做无碰撞仿真和机床验证。

- **完成定义：** 在完整几何、运动学、仿真和控制器合同获批准前，不把“可识别圆角/斜面”展示为“可加工复杂 3D”。
