# M2.1-A 孔候选调和核心合同 RED 记录（2026-08-31）

## 范围

本批严格停在 RED：新增独立黑盒测试 `untitled/tests/hole_candidate_reconciliation_service_test.cpp`，未创建生产头文件或实现，未注册工程或测试入口，未修改 `OperationFactory`、UI、策略、后处理、控制器、冷却或正式工序存储。

测试期望的唯一公开入口为：

```cpp
HoleCandidateReconciliationService::Reconcile(
    const CandidateReconciliationRequest &request)
```

期望输入/输出 DTO 名称直接对应 M2.1 洁净接口：`CandidateSnapshot`、`CandidateReconciliationResolutionView`、`CandidateReconciliationResult`、`CandidateReconciliationState`、`CandidateManualEditDisposition` 和带稳定 `code`/`fieldPath` 的 `CandidateReconciliationIssue`。该声明只存在于测试的期望 API 使用处；本批没有创建对应生产声明。

## 已冻结的 RED 场景

| 测试场景 | 洁净规格依据 | 期望结果 |
| --- | --- | --- |
| 无 `previousCandidate` | `M21-BB-001` | `Draft`、`manualEditDisposition=None`、仅候选结果。 |
| 相同 `Draft` 且无覆盖 | `M21-BB-002`、`M21-IF-STATE-004` | 保持 `Draft/None`，无差异。 |
| 相同 `Selected` | `M21-BB-003`、`M21-IF-STATE-003` | 保持 `Selected` 与精确选中方案引用。 |
| `geometryRevision` / `layerSignature` 不同 | `M21-BB-004`、`M21-BB-005` | `Conflict/GEOMETRY_IDENTITY_CHANGED` 与字段路径。 |
| 规则、计划、模板、材料、机床、刀具目录的可解析版本不同 | `M21-BB-006` 至 `M21-BB-008`、`M21-IF-IDENTITY-002` | `Conflict/CANDIDATE_PROVENANCE_CHANGED`，不按新版替换。 |
| 旧规则 `Missing` 或 `Withdrawn`，同时当前存在新版 | `M21-BB-009`、`M21-BB-012`、`M21-IF-STATE-001` | `Stale/CANDIDATE_REFERENCE_UNRESOLVED` 优先于版本差异。 |
| 快照或调和 policy 缺失 | `M21-BB-027`、`M21-BB-028` | `Rejected/CANDIDATE_SNAPSHOT_INVALID` 或 `RECONCILIATION_POLICY_UNRESOLVED`。 |
| 旧状态为 `Conflict` 且没有批准重处理命令 | `M21-BB-029`、`M21-IF-BLOCK-001` | 保持 `Conflict`，保留可审计候选。 |
| 输入不变与零工序边界 | `M21-IF-INPUT-001`、`M21-BB-034`、`M21-IF-BOUNDARY-001` | 输入快照/policy 不变；测试只依赖调和候选 API，不提供或调用 `OperationFactory` 入口。 |

“零正式工序”在当前公开仓储边界没有可查询的事务计数 API；因此本批将其锁为服务表面合同：测试只构造不可变候选请求并观察候选结果，既不包含 `OperationFactory` 依赖，也不引入测试专用工序计数接口。GREEN 前若确认事务需要可观察的集成断言，必须由独立确认事务合同提供，不得为本服务猜造仓储 API。

## 明确未写入本批的场景

- `Stale → Draft/Selected` 恢复：需要“重新可解析且重评估通过”的可观察命令/授权语义。
- 人工进给、转速、刀具和方案覆盖保留/冲突：需要最终 `ManualOverride` DTO 与目标解析合同。
- `cancelCountersink` 过滤：需要有效计划步骤、`countersinkStep` 和确认前计划校验 DTO。
- selector 等价、跨版本覆盖迁移、`Conflict/Stale` 人工重处理授权、确认事务：继续按 M2.1 阻断表拒绝推测。
