# Process templates copy values into operation proposals

The first CAM acceptance includes user-selected, versioned Process Templates keyed by material, machining strategy, and compatible tool range. Applying a template copies suggested spindle, feed, entry, depth, stepover, coolant, and clearance values into an Operation Proposal for review and editing; confirmation stores the final values in the Machining Operation and Program Snapshot, so later template changes cannot silently alter previously confirmed work.
