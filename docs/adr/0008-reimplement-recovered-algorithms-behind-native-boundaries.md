# Reimplement recovered DTM algorithms behind CNEXT-CAM boundaries

DTM recovered pseudocode is used as behavioral evidence for parameters, topology checks, algorithm stages, and edge cases, but it is not compiled or copied into CNEXT-CAM. Each accepted capability is reimplemented behind CNEXT-CAM's Recognized Feature, Machining Geometry, strategy, postprocessor, safety, and final-output simulation boundaries because direct recovery would preserve lost types, unsafe ownership, UI coupling, and controller assumptions that cannot be verified.
