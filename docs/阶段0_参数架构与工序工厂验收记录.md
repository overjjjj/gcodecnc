## 参数语义

- `depth` 表示正的加工深度量。
- 最终目标 Z 按 `referenceHeight - depth` 计算；例如基准 0、深度 35 的目标为 -35。
- `safeHeight >= plungeHeight >= targetHeight`，违反时阻止创建工序。
- `stepOver`、`stepDown`、切削进给、下刀进给和主轴转速必须大于 0。
