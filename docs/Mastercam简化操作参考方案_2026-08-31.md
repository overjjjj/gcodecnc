# Mastercam 简化操作参考方案（2026-08-31）

## 1. 目的、范围与非复制声明

产品交互目标是**简化 Mastercam 式 CAM 操作心智**：减少重复输入、让当前步骤可见、让推荐和预览可解释，同时不隐藏安全确认。目标不是复制 Mastercam 的 UI、图标、商标、术语体系、私有实现、文件格式、算法或宣称任何功能等价/兼容性。

本方案只参考其官方公开页面所表达的工作流原则：孔的“Geometry Selection / Hole Style / Advanced”三段式、统一步骤式工具路径配置、即时可视反馈、图形化参数解释、以及路径预览—材料验证—机床仿真的分层验证。任何引用均只作为产品研究证据，不是代码、算法或接口来源。

首期边界不变：仅 Front `+Z`、稳定拓扑引用、明确闭环或已证据化自由端；冷却冻结；正式工序必须人工确认并经 `OperationFactory`；安全检查、最终控制器代码和最终代码仿真仍是强制边界。

> **参考边界：** 第七章说明书是功能名、参数和安全语义的最高依据；目标软件截图仅补充实际界面状态；当前代码/测试只说明完成度。Mastercam 资料只能优化我方已确认能力的流程和心智，不能填补说明书缺失的工艺语义。冲突处理与逐功能模板见 `docs/工艺功能参考依据与实现原则_2026-09-01.md`。

## 3. 统一的简化流程

```text
Model / Setup
  → 选特征或自动识别
  → 选择 / 推荐工艺
  → 工具和关键参数
  → 生成 / 重生成
  → 路径预览
  → 材料 / 碰撞验证
  → 后处理输出
```

1. **Model / Setup：** 显示当前毛坯、Front `+Z` Setup、坐标/几何版本和安全高度状态；无有效 Setup 不允许进入生成。
2. **选特征或自动识别：** `SelectionSession` 或 `RecognizedFeature` 只生成稳定 `GeometryRef/Loop`、证据和候选状态；自动结果必须给出来源、匹配/拒绝解释。
3. **选择 / 推荐工艺：** 推荐输出 `OperationProposal/RuleMatch`，可编辑、可撤销、可拒绝；歧义、`Conflict`、`Stale`、未解析 selector 或超出安全子集只显示原因。
4. **工具和关键参数：** 先显示会影响安全和路径的刀具、深度、余量、`stepOver/stepDown`、高度、进退刀；高级字段折叠但不删除，错误必须在确认前可见。
5. **生成 / 重生成：** 仅在人工确认后由 `OperationFactory` 原子创建/重算；几何、Setup、刀具、毛坯或规则快照变化使结果失效，不能静默沿用旧路径。
6. **路径预览：** 显示最终策略产生的中立路径、选区、保护区、起点、方向和连接意图；不是材料去除、碰撞或机床仿真结论。
7. **材料 / 碰撞验证：** 在有毛坯、刀具/刀柄和夹具/保护几何证据时检查材料去除和干涉；证据不足必须显示“未验证”。
8. **后处理输出：** 先生成 CQ8/Fanuc/Siemens 最终代码，再运行 `GCodeSafetyValidator` 与由最终代码驱动的仿真；未通过不导出为可执行程序。

## 4. 三层验证的明确区分

| 层 | 回答的问题 | 输入 | 输出与限制 |
| --- | --- | --- | --- |
| 路径预览 | “策略将要走哪里？” | 已确认几何、参数、Toolpath Result。 | 显示路径/边界/高度/方向；不代表材料去除、碰撞或机床运动学。 |
| 材料去除验证 | “会去除什么材料、刀具/刀柄是否碰到毛坯或夹具？” | 毛坯、刀具/刀柄、夹具/保护区、路径。 | 材料/干涉结论；缺任一输入即未验证，不用预览替代。 |
| 机床 / 最终代码仿真 | “最终控制器代码在目标机床语义下是否可安全执行？” | 最终后处理代码、机床/控制器资料、可用仿真模型。 | 最终代码驱动的验证；当前没有可靠机床运动学/控制器资料时明确未验证。 |

## 5. 孔的简化界面

孔界面采用自有的三段式，不使用对方视觉或名称：

| 段 | 首屏内容 | 折叠/高级内容 | 强制安全门 |
| --- | --- | --- | --- |
| **选择对象** | 孔特征/面/体选择、识别层签名、Setup、候选状态、几何版本。 | 层证据、识别容差来源、重识别差异。 | 非 `+Z`、层重叠/断裂、缺稳定引用、`Conflict/Stale/Rejected` 阻断。 |
| **工艺建议** | 可解释的规则命中、候选步骤、来源版本、沉头处理开关（仅已实现后）。 | 规则过滤解释、版本差异、人工覆盖记录。 | 规则歧义、未确认 `Hn/AT`、深孔语义未确认、selector 未解析阻断。 |
| **关键参数** | 工具、转速/进给、目标深度、R 平面、安全高度、Q/单次深度。 | 周期专用字段、余量、进退刀、高级资料。 | 刀径/刃长/总长、深度、R/Q、安全高度、控制器能力必须通过。 |

**操作步数目标：≤5 个主要动作。**

1. 选择孔或运行识别；2. 查看并选择/接受一条可解释建议；3. 核对工具和关键深度/安全参数；4. 生成预览并通过验证；5. 显式确认创建正式工序。安全拒绝、风险提示和高级字段展开不计为“多余步骤”，也不允许被隐藏。

验收场景：单层盲孔、贯穿孔、两层台阶、沉头候选取消、规则歧义、缺刀、`Hn/AT`、未确认深孔、几何变更、人工覆盖冲突；所有成功场景都需 CQ8/Fanuc/Siemens 最终代码、安全检查和最终代码仿真。

## 6. 型腔与槽的一致结构

型腔和槽采用同一页面骨架，避免每类策略重新学习参数组织：

| 段 | 型腔 | 槽 | 首期安全边界 |
| --- | --- | --- | --- |
| **选择区域** | 闭合外环、底/侧壁、单孤岛/保护区。 | 直/矩形槽或证据化开放链、端部/自由端、底/侧壁。 | Front `+Z`、稳定引用；型腔需闭环，槽开放端需证据。 |
| **加工方式** | 粗加工、侧精加工、底精加工建议。 | 槽加工/盲槽建议。 | 仅既有安全策略；不开放动态铣、T 槽、燕尾。 |
| **刀具与步距** | 刀具、`stepOver`、`stepDown`、侧/底余量。 | 刀具、宽/深/长、`stepOver`、`stepDown`、余量。 | 刀具中心包络、通道/宽度、刃长/总长必须可证明。 |
| **进退刀** | 仅可证明斜坡/螺旋，否则安全高度垂直进给。 | 安全端部进给或安全高度垂直进给。 | 不可证明即拒绝该进刀方式；跨区域 G0 先抬刀。 |
| **高度与深度** | 安全高度、顶面、目标深度、底余量。 | 安全高度、顶面、槽深、底余量。 | 顺序/符号、毛坯/Setup、保护区一致性校验。 |
| **验证** | 路径、材料/碰撞（有证据时）、最终代码仿真。 | 同左。 | 未验证层不得显示为已安全。 |

**操作步数目标：型腔/槽各≤6 个主要动作。**

1. 选择区域或运行识别；2. 确认加工方式；3. 选择/核对刀具与步距；4. 核对进退刀；5. 核对高度与深度；6. 预览、验证并显式确认。用户可展开高级参数；不安全或未支持选项默认折叠或阻断，而非伪装可用。

验收场景：矩形/凸闭环型腔、单孤岛、直槽、矩形盲槽、证据化开放槽、窄通道、保护区碰撞、不可证明进刀、错误 Setup、几何失效、保存重开；成功场景均走三后处理器安全/仿真链。

## 7. 工序树与推荐交互

- 保留类似“工序管理器”的自有工序树心智：状态、顺序、启停、复制、编辑、重生成、失效原因和预览入口；不复制任何对方树控件、视觉或命名。
- 推荐永远是可解释、可撤销、可编辑的 `OperationProposal`；不能唯一匹配时显示冲突/拒绝，不能静默选择第一条。
- 复制产生草稿副本和来源快照；编辑/重生成会重新校验 Setup、几何、工具、毛坯、规则和安全参数。已确认工序不会被模板/推荐静默回写。
- 排序只对启用且 valid 的正式工序生效；当前排序容差/图标模式语义未确认，继续不进入自动排序算法。

## 8. 信息层级与默认行为

1. 首屏只展示当前步骤所需的对象、建议、关键参数和阻断原因。
2. 高级参数、原始规则解释、资料版本和不安全能力收在可展开区域；高级不等于可绕过校验。
3. 使用中立的状态文本和图形标记解释选区、避让区、起点、方向、连接/安全高度；标记不是实际刀具运动或验证结论。
4. 自动识别/推荐只生成候选；“确认创建”必须始终明显可见且只在安全门通过时启用。
5. 3+1/3+2、侧面/多轴、一般斜面/圆角、动态铣、复杂偏置和 3D 功能默认不可用或仅候选说明；不能因简化流程而降低安全门。

## 9. 产品验收与不做范围

| 验收主题 | 通过条件 |
| --- | --- |
| 少步骤 | 孔常用成功流程不超过 5 个主要动作；型腔/槽不超过 6 个主要动作；统计不排除必要的安全确认。 |
| 可解释 | 每个推荐显示几何、规则、刀具、版本和拒绝/冲突解释；撤销/编辑不改写历史快照。 |
| 一致性 | 孔、型腔、槽均按“选择→建议/方式→关键参数→生成→预览→验证→确认”组织。 |
| 安全 | 未确认候选、无效 Setup、不可达刀具、未验证材料/机床模型、最终代码安全失败均不能导出可执行程序。 |
| 学习成本 | 新手可从状态提示理解当前缺什么；高级用户可展开完整参数和证据，无需在多个不相关页面反复跳转。 |

不做：Mastercam UI/商标/文件兼容、自动接受推荐、绕过 `OperationFactory`、直接编辑控制器文本、以路径预览替代材料/机床验证、3+1/3+2 或多轴加工承诺、冷却行为变更。

所有简化流程条目仍须采用“说明书编号 → 功能目的 → 入口与操作步骤 → 输入参数/单位/默认值来源 → 选择/错误状态 → 输出 DTO → 服务/刀路边界 → 预览/仿真 → 黑盒验收 → 当前状态”的落地模板；未获得说明书定义的字段只能标为待确认/阻断。
