# M1 刀具切削参数匹配服务验收（2026-08-28）

## 范围与结论

本批新增 `ToolCuttingParameterService`，只读取
`AutomationTemplateDocument::toolCuttingParameterSets`，将已冻结的版本化
刀具切削参数资料转换为一个确定性的建议参数快照或稳定拒绝结果。

服务不读取 DTM 反编译源码或原始伪代码；不写 `ProcessTemplateLibrary`、
不创建 `MachiningOperation`，不接 UI、后处理、仿真或刀路策略。冷却字段仅随
命中的 `ToolCuttingParameterSet` 副本返回，未连接或改变既有冷却行为。

## 冻结接口

`ToolCuttingParameterService::Match(const AutomationTemplateDocument&,
const ToolCuttingParameterMatchRequest&)` 的输入为：

- `material`：必填，精确字符串匹配；
- `toolType`：必填，精确字符串匹配；
- `toolName`：可选；非空时必须精确字符串匹配；
- `toolDiameterMm`：有限且严格大于零的毫米值。

成功结果仅在唯一记录命中时返回 `matched=true`，并提供：

- `parameterSet`：资料记录副本，包含兼容冷却值；
- `source.documentId`、`source.documentVersion`、
  `source.effectiveDate`：版本追溯快照；
- `explanation`：包含选中资料 ID 的稳定解释。

失败结果 `matched=false`，按 `ToolCuttingParameterMatchError` 和
`ToolCuttingParameterMatchErrorCode()` 返回稳定错误码：

| 条件 | 错误码 |
| --- | --- |
| 缺少材料 | `TOOLING_MATERIAL_REQUIRED` |
| 缺少刀具类型 | `TOOLING_TOOL_TYPE_REQUIRED` |
| 直径非有限或非正 | `TOOLING_DIAMETER_INVALID` |
| 没有满足全部条件的记录 | `TOOLING_PARAMETER_NOT_FOUND` |
| 两条或更多记录满足全部条件 | `TOOLING_PARAMETER_AMBIGUOUS` |

直径严格按 M0 每条记录的 `minimumInclusive` 与 `maximumInclusive` 判断；
没有默认闭区间、插值、外推、材料别名、大小写折叠、空白归一化或单位换算。

## 后续边界

M2/M4/M5 可只读消费成功结果的参数快照与资料来源，但在确认工序前仍须复验
真实刀具类型、直径、额定值、刀角、刃长、总长和机床限制。以下项保持未覆盖，
不得由本服务猜测：

- 材料别名/分组和刀具名称归一化；
- 单位换算；
- 直径区间间隙的插值、外推或“最近档位”；
- M0 待确认的异常哨兵阈值与生产制造容差。
