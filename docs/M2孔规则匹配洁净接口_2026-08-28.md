# M2 孔规则匹配洁净接口（2026-08-28）

## 1. 目的、范围与证据规则

本文把《DTM 工艺规划洁净规格（2026-08-28）》收敛为 M2“孔规则匹配与多步骤计划”的可编码合同。本文只描述领域 DTO、匹配、状态、错误和冻结依赖，不提供实现代码。

- 输出止于 `Operation Proposal / AutoHoleCandidate`、匹配解释或拒绝原因；不得创建正式工序、刀路或控制器文本。
- DTM 恢复资料只证明自动孔等入口存在；本文没有伪代码、地址、类型布局、变量组合、调用控制流或控制器拼接。
- 原始 Excel 不是运行时输入；M2 只消费 M0 已校验、版本化、单位明确的 DTO。
- 冷却只保留兼容字段，不执行、不解释、不影响匹配优先级，也不修改现有冷却行为。
- 本批不修改生产代码、测试或冷却逻辑。

每条接口规则标注其上位规范 ID 和证据类型。证据类型限定为 `说明书`、`Excel`、`截图`、`反编译入口`、`推断`；`推断`不得当作已获业务确认的事实。

## 2. 统一术语

| 术语 | 唯一定义 | 不等同于 |
| --- | --- | --- |
| 孔特征输入 | M2 某次规划使用的不可变几何快照，含稳定引用、方向和有序层。 | DTM 私有对象、正式工序。 |
| 层签名 | 按层序组合的层类型、直径、起止平面和盲/通属性，用于重识别比较。 | `GeometryRef`；引用相同不代表层未变化。 |
| 规则资格 | 规则版本、生效日期、材料/机床/资料版本和特征条件均满足。 | 规则最终胜出。 |
| 规则优先级 | 规则内显式整数；数值越大优先级越高。 | 置信度或动态评分。 |
| 顶级匹配集合 | 所有合格匹配中具有最大优先级的集合。 | 所有命中规则。 |
| 匹配冲突 | 顶级匹配集合多于一条，或保留的人工选择/覆盖与新输入不相容。 | 可静默选第一条的普通情况。 |
| 过期 | 候选引用的几何、模板、材料、机床或刀具资料版本无法再解析。 | “存在更新版本”；旧版本仍可解析时不自动过期。 |
| 拒绝 | 当前输入无可行建议，且保留稳定拒绝码。 | 确认失败后留下部分正式工序。 |

`M2-IF-TERM-001` M2 不引入权重、相似度或多字段评分器。规则选择只有“资格过滤 → 最大显式优先级 → 唯一胜出或冲突”三步。`[上位规范：DTM-CLN-HOLE-003、DTM-CLN-COMMON-003；证据类型：Excel + 推断]`

### 4.3 唯一选择算法合同

1. 校验请求和全部引用版本；失败则 `Rejected` 或对既有候选标记 `Stale`。
2. 过滤未启用、未生效、材料/机床不符、类别/层数不符或任一层区间不命中的规则。
3. 无合格规则：`Rejected / RULE_NOT_FOUND`。
4. 取最大显式 `priority` 的全部合格规则。
5. 顶级集合只有一条：生成 `Draft` 候选与完整匹配解释。
6. 顶级集合多于一条：`Conflict / RULE_AMBIGUOUS`，列出全部顶级规则引用；不得按文件顺序、名称、首条或最近日期自动选择。

`M2-IF-RULE-003` 不同优先级的重叠规则由最高整数优先级唯一胜出；同最高优先级多匹配立即冲突，不继续评分。`[上位规范：DTM-CLN-HOLE-003、DTM-CLN-COMMON-003；证据类型：Excel + 推断]`

## 6. `Hn` / `AT` 未确认语义门

`Hn` 和 `AT` 在现有 DTM 表中存在，但以下业务问题尚未解决：

1. `Hn` 是层入口绝对 Z、相对参考面的有符号高度、层终止平面，还是层深？
2. `n` 按模型入口到孔底、孔底到入口，还是 DTM 表的显示顺序编号？
3. 正/负方向和零平面由 Setup、工件表面还是各层入口决定？
4. `Hn` 用于 `startExpression` 与 `depthExpression` 时是否具有相同含义？
5. `AT` 是轴向贯穿余量、刀尖补偿、毛坯余量还是其他工艺量？
6. `AT` 的单位、允许范围、默认值、上限和批准来源是什么？
7. `AT` 是否只允许最深通孔层，以及对盲孔/沉头步骤是否一律禁用？
8. 表达式结果是目标平面、相对深度还是有符号坐标，如何转换为现有正 `depth` 参数？

### 6.1 结构化占位符

M0 可保存但 M2 不得解析猜测的占位结构：

| 字段 | 含义 |
| --- | --- |
| `symbol` | 原符号族：`H` 或 `AT`。 |
| `layerOrdinal` | `Hn` 的 n；`AT` 为空。 |
| `semanticVersion` | 业务语义版本；未确认时为空。 |
| `datumRef` / `direction` / `unit` | 参考面、正方向和单位；未确认时为空。 |
| `resolutionState` | `Unconfirmed` 或 `Confirmed`。 |
| `approvalRef` | 业务批准记录；未确认时为空。 |

`M2-IF-EXPR-001` 任一步表达式引用 `resolutionState != Confirmed` 的 `Hn` 或 `AT` 时，所属规则必须 `enabled=false`，返回 `SEMANTIC_VARIABLE_UNCONFIRMED`；不得通过固定常数、层深猜测或当前代码行为补义。`[上位规范：DTM-CLN-HOLE-005、DTM-CLN-COMMON-008；证据类型：Excel + 推断]`

`M2-IF-EXPR-002` 只有批准的语义版本可将结构化几何量绑定为受限表达式变量；批准后仍须执行未知变量、除零、非有限、负深度和几何越界检查。`[上位规范：DTM-CLN-COMMON-008、DTM-CLN-HOLE-005；证据类型：Excel + 推断]`

| `reasons` | stable error list | 非 `Draft` 必须非空。 | `DTM-CLN-COMMON-003` / 说明书 + 推断 |
| `manualEditDisposition` | enum | `None`、`Preserved`、`Conflict`、`Stale`。 | `DTM-CLN-COMMON-004` / 说明书 + 推断 |

`M2-IF-OUTPUT-001` `Draft` 候选至少携带 `geometryRef + geometryRevision + layerSignature`、规则/方案/模板/材料/机床/刀具资料版本、标准化步骤、参数来源、匹配解释、人工覆盖和取消沉头标志。`[上位规范：DTM-CLN-COMMON-003、DTM-CLN-COMMON-005、DTM-CLN-COMMON-007；证据类型：说明书 + 推断]`

`M2-IF-OUTPUT-002` M2 不调用 `OperationFactory` 创建正式工序。只有独立人工确认入口在整链预校验成功后，才可把每步适配为现有 `OperationProposal` 并调用 `OperationFactory::CreateConfirmed`。`[上位规范：DTM-CLN-COMMON-003、DTM-CLN-COMMON-006；证据类型：说明书 + 推断]`

## 8. 状态机与重识别

```text
Recognized
  ├─ 唯一匹配 ───────────────→ Draft
  ├─ 顶级多匹配 ─────────────→ Conflict
  └─ 输入/规则不可用 ────────→ Rejected

Draft ──操作者选方案/编辑────→ Selected（候选内部状态）
Selected ──整链预校验通过────→ Validated（确认入口内部状态）
Validated ──显式人工确认──────→ OperationFactory（M2 边界之外）

任一候选 ──引用版本不可解析──→ Stale
已编辑候选 ──层签名/匹配改变──→ Conflict
```

`M2-IF-STATE-001` 相同 `GeometryRef`、相同几何修订/层签名、相同规则与方案版本重新识别时，保留人工覆盖、已选方案和取消沉头标志。`[上位规范：DTM-CLN-COMMON-004、DTM-CLN-HOLE-006；证据类型：说明书 + 推断]`

`M2-IF-STATE-002` `GeometryRef` 仍存在但层序、类型、直径、起止平面或盲/通属性变化时，保留人工数据供比较并转 `Conflict`，不得自动套用旧方案。`[上位规范：DTM-CLN-COMMON-004、DTM-CLN-HOLE-002；证据类型：说明书 + 推断]`

`M2-IF-STATE-003` 原 `GeometryRef` 消失，或候选引用的规则/模板/材料/机床/刀具资料版本无法解析时转 `Stale`。仅存在更新版本但旧版本仍可解析，不得自动变更或标记过期。`[上位规范：DTM-CLN-COMMON-004、DTM-CLN-COMMON-007；证据类型：说明书 + 推断]`

`M2-IF-STATE-004` 新规划缺刀具时为 `Rejected / TOOL_NOT_FOUND`；已人工编辑候选的选中步骤因同一刀具资料版本内刀具消失或不兼容时转 `Conflict` 并保留人工编辑；整个刀具资料版本不可解析时转 `Stale`。`[上位规范：DTM-CLN-TOOL-003、DTM-CLN-COMMON-004；证据类型：说明书 + Excel + 推断]`

`M2-IF-STATE-005` 取消沉头是显式人工覆盖：只移除 `countersinkStep=true` 的步骤，再对剩余链完整校验。重识别仍为相同沉头特征和方案时保留该标志；沉头层消失或方案变化时转 `Conflict`，不得静默清除。`[上位规范：DTM-CLN-HOLE-006、DTM-CLN-COMMON-004；证据类型：说明书 + Excel + 推断]`

## 10. 冻结依赖与禁止修改边界

### 10.1 M2 允许依赖

| 依赖 | 允许用途 | 冻结要求 |
| --- | --- | --- |
| M0 版本化 DTO / JSON schema | 读取已校验的 catalog、规则、模板、参数来源和版本引用 | M2 不自行读取 Excel、不扩展任意表达式、不绕过 M0 校验。 |
| `AutoHolePlanningService` | 接入识别后的孔特征、生成兼容候选、处理重识别状态和整链预校验 | 保持现有公开候选/确认语义；新增规则匹配应通过独立 DTO/服务适配。 |
| `OperationFactory` | 仅供边界外的人工确认适配器原子创建正式工序 | 匹配服务不得调用；不能绕过显式人工确认。 |
| 现有只读孔/刀具/Setup 快照 DTO | 提供 `CompoundHoleFeature` 等经过上游确认的数据 | 不修改全局刀库、项目或 Setup。 |

### 10.2 禁止修改或直接依赖

- 不修改 `untitled/src`、现有测试、冷却代码或冷却行为（本规格批次）。
- 后续 M2 实现不得把匹配器放入 UI、策略、后处理、G-code、安全校验或仿真层。
- 不直接拼 CQ8/Fanuc/Siemens 文本，不调用控制器通信，不生成刀路。
- 不修改 `OperationFactory` 的人工确认语义，不直接写 `MachiningOperation`，不部分提交多步骤链。
- 不运行时读取 Excel，不执行宏、公式、脚本或命令，不复制 DTM 恢复代码。
- 不为解决 `Hn/AT`、区间开闭或异常模板值而猜默认值；保持规则禁用并返回明确原因。

`M2-IF-BOUNDARY-001` M2 的完成边界是“确定性规则匹配 + 可解释候选/冲突/拒绝 + 可供既有确认链消费的标准化步骤”，不是“自动生成可执行加工”。`[上位规范：DTM-CLN-COMMON-003、DTM-CLN-COMMON-006；证据类型：说明书 + 推断]`
