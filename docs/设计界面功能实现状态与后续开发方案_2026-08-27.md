# 设计界面功能实现状态与后续开发方案

日期：2026-08-27

## 1. 状态口径

- **已完成**：具备真实几何或确认的加工边界、参数校验、刀路、最终代码、安全检查、仿真和保存重开证据。
- **安全子集已完成**：只支持已明确列出的简单几何，其余情况会拒绝生成。
- **半成品**：已有识别、参数、界面或部分刀路，但尚未形成完整闭环。
- **未完成/安全阻断**：缺少可靠几何或算法，界面禁用或生成入口拒绝，不能用于生产加工。

当前大部分新增实现位于独立工作树 `D:\codex\home\worktrees\c86d\gcodecnc`，尚需完成全量回归、变更审查和正式合入，不能把“工作树已实现”直接等同于主分支已交付。

## 3. 各功能详细状态

### 3.1 全工艺通用设置

**已完成**

- 工艺类型、G54-G59、刀具引用、刀径、进给、下刀进给和主轴转速。
- 安全高度、下刀高度、基准面、加工深度、步距和分层。
- 平面/深度余量、进退刀公共字段和跨字段校验。
- 参数来源优先级：系统默认 < 材料模板 < 刀具模板 < 自动规则 < 人工修改。
- 模板版本、参数来源、几何引用、工序状态保存与重开。
- 工序 empty/calculating/valid/stale/error 状态以及依赖变化后的失效。

**待完善**

- 材料牌号和完整切削数据库管理。
- 所有历史策略完全迁移到独立专用 Schema。
- 冷却设置单独立项验证。

### 3.2 选择、坐标与工序编辑

**已完成或安全子集完成**

- 孔位选择、直径/X/Y/最近邻排序、序号显示、撤销和恢复。
- 串联选择的数据模型：几何源、选择方式、内/外/混合、坐标系、闭合、起点、反向、分支和排序。
- 工序启停、排序、编辑参数、重算、失效和只生成启用且有效的工序。
- 毛坯、WCS、刀具或几何变化后关联刀路变为 stale。

**半成品**

- 串联控制器与所有工艺入口尚未完全统一。
- 开放槽 OCC 自由端证据和复杂分支交互尚未完全持久化。
- 清内角缺少可靠的前工序选择界面，因此正式入口仍禁用。

### 3.3 孔类与螺纹工艺

**已完成**

- 打点、G81、G83、G73、G86、孔倒角、攻牙、铰孔和圆插补铣孔。
- G73/G86 的策略参数、后处理映射、安全检查和最终代码仿真。
- 内螺纹单齿铣的安全子集：旋向、加工方向、锥度、负直径修正、粗精分层和独立精铣参数。
- 自动孔单层盲孔、两层同轴台阶孔、锥形沉头孔和受控贯穿余量安全子集。
- 多层公式 Hn/Dn/Tn/AT 的受限表达式解析，候选方案需人工确认后原子创建工序链。

**半成品或未完成**

- STEP 复合孔识别尚未用足够多的生产模型覆盖。
- G76 缺少可靠的主轴定向偏移、退刀轴和方向合同。
- 外螺纹、多齿换层、切线/圆弧进刀未完成。
- 侧面/斜轴孔、相交孔、破孔和密封槽继续阻断。

### 3.4 平面、槽与型腔

**已完成或安全子集完成**

- 矩形/圆形平面的真实往复刀路。
- 开口槽、盲槽、斜底槽和规则型腔开粗。
- 同心圆环形铣和唯一同心圆孤岛。
- 正面平底直壁槽框识别：闭合矩形、一般凸多边形、一个孤岛/保护区和简单开放槽服务合同。
- 真实 OCC EDGE→FACE、VERTEX→EDGE 邻接，外环、自由边、底面和保护区域检查。

**半成品或未完成**

- 铣平面的加工线角度、连接方式、外接矩形等参数未全部改变最终刀路。
- 通用单向、环切、一刀过和完整保边模式不完整。
- 偏心环、异形环、多孤岛、凹槽框、曲面底和三维保护体未完成。
- 动态铣尚未开放。

### 3.5 轮廓、倒角、清角、刻字与空间曲线

**已完成或安全子集完成**

- 开放/闭合二维轮廓的起点、反向、刀补、Z 分层、深度余量、闭合过切和安全退刀。
- 二维凸闭合外形倒角：倒角宽度、刀角、刀尖半径/补偿、侧面间隙、重叠和分层反算。
- 轴对齐矩形型腔清内角：显式前开粗工序依赖、前后刀径、刀具中心包络、分层和逐角安全退刀。

**半成品或未完成**

- 开放轮廓弓字策略和 XY 粗精分层未完成。
- 一般凹轮廓、圆角、孤岛和异形清内角未完成。
- 3D 倒角、刻字字体轮廓和空间曲线刀路未完成。

### 3.6 斜面、圆角和曲面

**已完成的安全子集**

- 二维矩形单坡面：坡度、XY 宽度、球头刀包络、保边、分层和安全退刀。

**半成品或未完成**

- 圆角特征已有部分识别，但没有真实修剪边界和可达角区间刀路。
- 3D 斜面、3D 倒角、斜面倒角和自由曲面加工继续阻断。
- SurfaceFinish 只能处理可验证的平面矩形，不能算作三维曲面加工。

### 3.7 自动工艺、规则表和刀具资料

**已完成或安全子集完成**

- 版本化参数模板、工艺方案、显式应用和恢复模板值。
- 自动孔草稿、方案选择、刀具与公式校验、人工确认和正式工序创建。
- 重新识别通过稳定几何 ID 关联人工修改，变化时标记冲突或过期。
- 自动工艺不会绕过 OperationFactory。

**半成品或未完成**

- 特征孔和智能倒角目前主要是候选与过滤能力。
- 完整材料/刀具推荐数据库未完成。
- 自动框保持实验/禁用。

### 3.8 工程、后处理与仿真

**已完成基础能力**

- 项目保存重开，保存参数来源、模板、几何引用、依赖和刀路状态。
- CQ8、Fanuc 和 Siemens 后处理边界。
- 程序生成服务拒绝禁用、过期、错误和未重算工序。
- 最终代码经过 GCodeSafetyValidator 后交给 SimulationController，显示与输出同源。

**当前已知基线问题**

- 正式全量测试曾停在侧面型腔未确认专用 Setup；这是安全阻断，不应通过放宽 Setup 检查解决。
- OpenCAMLib 源缺失警告仍存在，当前相关能力保持禁用或使用现有安全实现。

## 4. 后续开发方案

### P0：收口、合入与可演示版本

1. 等二维几何内核全量回归结束，修复本批真实回归，保留安全基线阻断。
2. 审查独立工作树改动，按架构基础、孔类、槽框、二维内核分批提交并合入主工作区。
3. 建立一个正面三轴验收模型集合：孔、台阶/沉头孔、平面、槽、型腔、孤岛、轮廓、倒角、坡面。
4. 制作可演示流程：导入 STEP → Setup → 选择/识别 → 参数 → 工序 → 重算 → 最终代码仿真 → 保存重开。
5. 修复或明确隔离全量测试脚本中的历史配置和基线失败。

### P1：完成二维几何与常用工艺

1. 完成二维几何内核的凹轮廓偏置、自交修剪、多孤岛和窄通道处理。
2. 将新内核逐步迁移到平面、型腔、轮廓、孤岛、倒角和清角策略。
3. 完成铣平面的单向/环形/一刀过、加工角度、连接方式和外接矩形。
4. 完成开放轮廓弓字、XY 粗精分层和一般二维清内角。
5. 开放清内角前工序选择 UI，并验证编辑、删除、排序后的依赖失效。

### P2：动态铣与高级槽型腔

1. 先实现圆槽阿基米德螺旋安全子集。
2. 校验最小路径半径、径向吃刀、stepOver、stepDown、进刀角和每层深度。
3. 再扩展一般型腔连续绕行、偏心环、多孤岛和保护区域连接。
4. 所有 G0 跨区域移动必须在安全高度，最终代码仿真不得越界。

### P3：智能倒角与自动槽框

1. 完善相邻面、宽度、角度、深度、长度和直径过滤。
2. 建立“候选 → 过滤 → 人工确认 → 刀路”四阶段工作台。
3. 先把可靠二维/解析曲面候选接到现有倒角策略。
4. 自动槽框先输出可审计候选，再复用已验证的槽/型腔策略；不复制刀路算法。

### P4：孔和螺纹遗留

1. 在机床主轴定向和退刀合同明确后实现 G76。
2. 建立外圆毛坯边界后实现外螺纹。
3. 补多齿换层抬刀、切线/圆弧进刀和控制器差异验证。
4. 扩充复合孔生产 STEP 数据集，覆盖多级台阶、沉孔、沉头和贯穿组合。

### P5：多面与三维加工

1. 实现并验证 G68.2 ZXZ 欧拉角、IJK 姿态、多解选择和机床轴限位。
2. 建立世界坐标、Setup、倾斜平面和机床坐标的可逆变换。
3. 完成 SurfaceContactSolver，并以解析平面、圆柱、球面和受控 B-Spline 验证。
4. 按 3D 斜面 → 圆角 → 3D 倒角 → 空间曲线 → 自由曲面的顺序开放。

### P6：资料库、生产化与机床联调

1. 完整材料、刀具、刀柄和切削参数数据库。
2. 模板版本迁移、规则审计、参数来源对比和批量同步。
3. 夹具避让、碰撞检查、加工时间估算和程序包追溯。
4. 冷却、机床专用 M 指令和 CQ8 通信单独立项，在仿真控制器和真实机床上验证。

## 6. 发布建议

近期版本应定位为“正面三轴、人工确认、最终代码可仿真的 CAM 安全版本”。所有半成品入口继续灰置并显示缺失条件。等二维内核、生产 STEP 验收集和工作树合入完成后，再发布给现场试用；三维曲面、动态铣、自动框和冷却不要混入首个可用版本。
