## 1. 确认规则与边界

### 1.1 确认状态

每一项由需求方选择一个结论，并在“截图/证据”填写后续提供的软件截图编号、视频或现场记录。

| 结论 | 含义 |
|---|---|
| 待确认 | 当前尚未确认是否纳入项目 |
| 需要复刻 | 作为目标产品需求；另行定义验收标准 |
| 等价实现 | 不复制原界面或专有名词，但实现同等工作结果 |
| 不在本期 | 已知存在，但不进入本期范围 |
| 仅保留接口 | 当前不实现；仅保留数据、UI 或通信边界 |

### 1.2 产品边界

| 范畴 | 说明 | 本文处理方式 |
|---|---|---|
| 机床硬件与电气 | 接线、伺服、I/O、刀库、急停及安全链 | 完整列出，须由机床/控制器专项确认 |
