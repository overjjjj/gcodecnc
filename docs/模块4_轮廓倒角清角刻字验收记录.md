## 强制安全条件

- 轮廓点列必须连续、无零长度边；闭合策略必须有至少三个有效点，开放策略至少两个点。
- `safeHeight` 必须高于进刀平面；刀补启停必须在有足够长度的线性引入/引出段完成。
- 外形倒角只在刀具角度、刀尖几何、倒角宽度和轮廓边界都可验证时生成；反算深度不得超过刀具刃长或侧面间隙。
- 清内角必须引用明确前工序及其刀径；只加工前刀无法到达且小刀可达的凹角区域。
- 3D 倒角、刻字和空间曲线在缺少真实几何绑定时保持不可用。

## 实施证据

- `cutter_compensation_strategy_test`：验证开放/闭合轮廓安全高度、零长度边、机床刀补与余量冲突、深度余量和闭合过切。
- `selection_chain_operation_contract_test`：验证选择链经 `OperationFactory` 保留，并要求外形倒角明确绑定“外侧 + 闭合 + 无孤岛”边界。
- `contour_machining_choice_test`：验证轮廓和外形倒角必须经过人工起点、方向及选择链确认。
- `outer_contour_chamfer_strategy_test`：验证宽度/角度/刀尖补偿反算、三层深度、重叠、安全退刀，以及元数据缺失、刀具包络不足、凹轮廓、自交轮廓、非平面轮廓和不安全高度阻断。
- `outer_contour_chamfer_cq8_integration_test`：走通 `OperationFactory → Strategy → ProgramGenerationService → CQ8 → GCodeSafetyValidator → SimulationController`；最终仿真到达 `Z-1.083` 并沿真实矩形边界切削，侧面轮廓无专用 Setup 时阻断。
- `inner_corner_cleanup_strategy_test`：验证矩形工具中心包络、层深、步距、逐角安全退刀，以及前刀过小、边界不完整、含孤岛和高度不安全时阻断。
- `inner_corner_cleanup_cq8_integration_test`：验证显式前工序、同几何约束、最终 CQ8/Fanuc/Siemens、安全检查和最终代码仿真。
- `tool_operation_compatibility_test`、`standalone_ui_contract_test`：验证倒角刀类型、二维入口开放，以及 3D 倒角/清内角/刻字/空间曲线入口独立灰置。
- 工程构建：`qmake` + `Makefile.Debug` 完整构建通过，生成 `debug/CNEXT-CAM.exe`。
- 完整测试链：本模块测试均通过；测试链最终仍只停在既有 `acceptance_step_model_test` 侧面型腔 Setup 未确认基线。

## 遗留风险与下一步

- `millOutLine` 仍缺非闭合单向/弓字、XY 粗精分层及更一般的 CAM 偏置几何。
- `millChamfer` 当前只覆盖二维凸闭合外边界；凹轮廓、孤岛和 3D 面保持阻断。
- 清内角下一步是补可审计的前工序选择 UI，并在可靠布尔/偏置基础上扩展一般残料包络；当前入口继续禁用。
- 模块 5 若继续，应先为斜面/圆角曲面建立模型几何绑定与不可行几何测试；不得复用二维点列冒充 3D 路径。
