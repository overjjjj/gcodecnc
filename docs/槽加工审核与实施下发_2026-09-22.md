## 第七章摘要与目标操作流程

第七章覆盖文件导入与工程保存、孔/牙类、铣平面与公共串联、槽类、外形、斜面圆角、自动模块、坐标/刀库/模板/仿真、辅助绘图及工序管理。

槽加工的目标流程为：

1. 导入模型，核对摆正、加工面、原点、坐标系、材料与毛坯。
2. 选择挖槽，选实体边或面形成完整加工区域；检查起点、方向、加工侧、顺序。取消不能新增工序。
3. 设置刀具、转速、切削/下刀速度、基准面、切深、安全/下刀高度、XY/Z步距和余量。
4. 独立选择路径方式与下刀方式。手册的“螺旋铣”（先到底再外扩）不同于“螺旋下刀”（进入材料的方式），不能以一个开关代表两者。
5. 检查刀具可达性与整个刀具扫掠范围，人工确认，失败时整批零新增。
6. 由已确认工序生成最终控制器程序，核查最终代码路径、快移和粗/底/壁精加工阶段。
7. 支持查看与修改工序、重选几何、启停、排序、重算和保存重开；修改使旧程序失效。

手册7.5包括挖槽、环形铣、铣孤岛、动态铣；现有开口槽/盲槽/斜底槽分类不等于这四类已完成。手册93页将动态铣限定于圆槽，测试27页写“封闭腔体”，首批不得据此自动扩大到任意封闭腔体。环/岛能力另行验收。

## 当前可追溯操作链

导入与Setup → 选择已识别槽/同类槽组 → 选择槽策略与刀具参数 → 点击确认并加入工序 → 每个候选弹出公共几何选择 → 人工确认与Setup检查 → 最终几何整批预生成 → 一次加入工序 → 最终后处理与安全检查。

与手册的主要差异：几何确认发生在参数填写之后；公共选择接入的是已有候选，不是完整模型边分支拾取；确认后缺少参数重编辑入口。选择证据和最终几何已有持久化，不派发重复重写。

## 审核发现

### S1 / P1：旋转盲槽螺旋圆心未旋转

`untitled/src/strategies/mill/BlindSlotMillingStrategy.cpp:437` 起点经过 slotToWorld 旋转，`:442` 却固定输出 `I=-helixRadius J0`。

推导案例：中心(0,0)，L40/W12/D4，刀径6，angle=90°，helixRadius=3。起点(0,3)，输出形如 `G2 X0 Y3 I-3 J0 Z...`，圆心变成(-3,3)。刀具X扫掠可到-9，槽壁X=-6，越界3。修正圆心增量的旋转，并验证螺旋包络满足每个深度层的真实边界、余量和斜壁；只改I/J不足以证明整体安全。

### S2 / P1：缩小真实斜壁以容纳刀具

同文件`:134` clampSlopePair 及`:274`调用，按刀径将斜坡值等比例缩小，随后以修改后的几何生成粗精刀路。

推导案例：W12，刀径6，stock=.1，两个侧斜壁宽各4，真实底宽4，刀具不应通过。代码把两侧各改为2.15，改变了零件几何。应保留识别几何并拒绝不可加工组合，不能静默改小坡长。验证每层、槽底、入刀与精加工边界。

### S3 / P1：斜底槽空可达集合恢复为整槽

`untitled/src/strategies/mill/TaperedSlotMillingStrategy.cpp:235` roughReachForLayer 默认返回整槽，仅found时收缩；没有合格采样点时保留整槽。

推导案例：L40/W12/D4，刀径6，stock=.1，slopeStartLength=10，slopeEndLength=0，stepDown=1；Z=-3时无合格采样，却留下U[-16.9,16.9]。应空区间/明确失败，不能切穿未许可区域。还需检查双端坡导致的多个不连通区间，不能用最小/最大端点把禁切中段连起来。

### S4 / P1：精加工直连端点跨过坡面转折

同文件`:378`–`:391` 对分段wedgeZAtU只取两端Z，输出一条cutXYZ。

推导案例：L40/D4、刀径6、finishStock=.05、首尾坡长各10，两端U=±16.95、Z=-2.78，而函数中U=0要求Z=0；直线会切过中心。须以真实坡面语义和刀具包络建立分段路径。语义无法证明时阻断该非零坡长模式，不能静默退回普通槽，更不能把有缺口的加工报告为成功。

### U1 / P2：选择设置没有传入槽刀路

`SelectionChainDialog.cpp:50,79,86`公开反向、加工侧、起点；`MainWindow.cpp:4400`仅保存selectionEvidence，`:4401`只有手工轮廓策略回写点列；`ProgramGenerationService.cpp:631`槽生成使用feature/tool/params。因此槽起点/方向设置不会改变其几何输出。

第一批只开放真实支持的槽选择项，明确固定内侧/由策略决定入口等当前限制，不能静默接受不支持的意图。保持其他策略不受影响。完整起点/方向与拓扑串联作为后续独立批次。

### U2 / P2：工序描述的槽尺寸错误

`OperationListPanel.cpp:303`附近addConfirmedOperations从已被清除的slotLength/slotWidth参数取值，回退radius*2/radius；应使用最终contourFeature.length/width（仅合法旧数据才考虑兼容）。表格operationLabel已使用真实长宽，导致详情/保存的featureRef可能与表格矛盾。

### U3 / 能力缺口：模型串联与编辑闭环

`MainWindow.cpp:4338`附近为已有槽构造候选（缺点列时合成矩形），无模型分支输入/viewport拾取闭环；不能宣称任意边分支串联完成。`OperationListPanel.cpp:198,213`提供排序、删除、换刀、重算，但无现有工序的参数编辑入口。当前只能删除重建；重新确认参数会新增工序。后续需保留工序ID、原子替换参数、使刀路/快照失效，几何变更重新确认选择证据。
