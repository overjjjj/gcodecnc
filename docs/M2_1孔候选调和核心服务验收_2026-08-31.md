# M2.1-A 孔候选调和核心服务验收（2026-08-31）

## 已交付边界

`HoleCandidateReconciliationService::Reconcile()` 只处理不可变历史/当前候选快照、解析视图和调和政策。它不包含 `ManualOverride`、取消沉头、selector 等价、跨版本迁移、人工重处理命令或确认事务；也不依赖 `OperationFactory`、UI、策略、后处理、控制器、仿真或冷却。

核心 DTO 分开表达 `PreviousCandidateSnapshot` 与 `ObservedCandidateSnapshot`。解析视图使用 `Previous`、`Observed`、`Request` 三侧、JSON Pointer 路径和精确身份；结果只有状态、候选快照、解释和稳定 issue，不产生正式工序。

## M2.1-B 阻断
