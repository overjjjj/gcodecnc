# 孔、二维平底型腔与简单槽优先开发方案（2026-08-31）

> **依据优先级：** 第七章说明书优先，目标软件截图补充界面状态，当前代码/测试确认完成度；Mastercam 公开资料只辅助简化流程。统一模板、冲突处理与待确认规则见 `docs/工艺功能参考依据与实现原则_2026-09-01.md`。

## 1. 目标与冻结边界

本文件把已提交的 M0–M2.1 规格、总体路线图和仓库公开实现收敛为下一阶段的交付顺序：**孔闭环 → 二维平底型腔 → 简单槽**。它是规划与验收清单，不合入 M2.1-A 代码，不扩大当前已验证加工声明。

冷却代码和行为冻结；`coolantCompat` 只能在候选、模板和来源快照中原样携带，不能驱动任何冷却指令或默认行为变化。

所有模块只能使用以下公共链，任何箭头不得跳过：

```text
RecognizedFeature
  → OperationProposal / RuleMatch
  → 参数与刀具快照
  → 人工确认
  → OperationFactory
  → 策略
  → GCodeSafetyValidator / 最终代码仿真
  → PostProcessor
```

最终代码验收的执行顺序保持为：`OperationFactory → Strategy → PostProcessor → GCodeSafetyValidator → final-code Simulation`。识别、规则、选刀和 UI 都不能直接创建正式工序、拼接控制器文本或绕开人工确认。

每个 P0–P2 功能条目按“说明书编号 → 功能目的 → 入口与操作步骤 → 输入参数/单位/默认值来源 → 选择/错误状态 → 输出 DTO → 服务/刀路边界 → 预览/仿真 → 黑盒验收 → 当前状态”登记。说明书未明确单位、默认值或精确定义时，不以 Mastercam 或当前实现补猜，标记待确认/阻断。

### 2.1 7.4 选择交互公共收口

7.4 截图补充后的公共输入不是新的策略或刀路：`SelectionSession → stable GeometryRef/Loop → direction/start/ordering snapshot → Pocket/Slot RecognizedFeature`。边缘、串联、实体面、局部串联、撤销、分支、动态起点和反向均只属于该会话；选择完成也只允许形成候选。型腔首期只接收 Front `+Z` 的稳定闭环与可证明单孤岛，槽首期只接收直/矩形或带自由端证据的开放链。

“铣斜面”“铣圆角”“最小值”“混合方向”、3+1/3+2 坐标设置、排序容差和图标模式均不得从截图推断算法或单位；它们保持 UI 候选或业务确认项。完整逐项 DTO、拒绝和验收矩阵见 `docs/7_4铣平面选择与型腔槽公共交互需求_2026-08-31.md`。

## 3. P0：孔闭环

**落地模板索引：** 说明书第七章孔类入口（精确编号待以原手册核对）；当前为半成品。入口、参数、拒绝、输出、预览和黑盒证据沿用本节各子段，新增/调整时必须补全统一模板。

### 安全子集与输入

- 仅正面 `+Z` Setup，连续同轴的单层盲/通孔、两层台阶孔和可证明锥形沉头；稳定 `geometryRef`、`geometryRevision`、`layerSignature`、入口面、层直径/深度和识别证据必填。
- 输入还包括材料、机床、规则/计划/模板/刀具目录版本、日期、显式人工覆盖和沉头取消。单位固定为 mm、mm/min、r/min；刀具直径、有效刃长、总长、R 平面、安全高度、目标深度、Q/单次深度均须为可验证正/有序值。
- `Hn/AT`、未知起点语义、参考面或控制器支持未确认的深孔阶段、非 `+Z`、层断裂/重叠、相交/破孔、缺资料或缺稳定引用均阻断。

### 识别、规则与确认

1. M2.1-A 先按 43 个黑盒用例实现不可变候选调和：`Draft/Selected/Conflict/Stale/Rejected`、解析视图、人工覆盖保留、沉头取消和稳定原因；仅产生候选结果。
2. 在独立 selector 适配器中把规则步骤的精确工具引用解析到现有刀库实体；没有唯一、兼容且长度足够的刀具即拒绝，不能替换为相似刀具。
3. 人工确认页只呈现候选、来源版本、解释、刀具和覆盖；`Conflict/Stale/Rejected` 不显示“生成工序”。
4. 确认适配器重新校验候选快照、刀具、R 平面/安全高度、层深与规则表达式后，将中心钻/钻削（G81/G83/G73/G86）、扩孔/铰孔、孔倒角或沉头步骤交给 `OperationFactory` 原子创建；任一步失败则零正式工序。

### 刀路、拒绝与验收

- 刀路只复用已验证孔策略；每层深度、Q、盲孔底/贯穿余量、跨孔快速移动与安全抬刀进入策略和最终代码检查。不得由规则服务生成 G-code。
- 进退刀：固定循环的安全位置、R 平面与回退由已验证策略/后处理决定；确认前拒绝不合法安全高度，确认后快速移动仅在安全高度。
- 回归：单层盲孔、贯穿孔、两层台阶、沉头取消、缺刀、公式错误、层错误、重识别保留/冲突/过期、原子失败；对 CQ8/Fanuc/Siemens 分别检查最终代码、`GCodeSafetyValidator` 与最终代码仿真。
- DoD：43 个 M2.1 黑盒、M2 规则回归、selector/确认原子性和上述最终代码链全部自动化通过；一个已确认孔候选可重开、重算并生成可追溯正式工序，非成功状态恒为零工序。

## 4. P1：二维平底型腔

**落地模板索引：** 说明书第七章 7.4 铣平面及其公共选择；当前为半成品。7.4 选择步骤、截图状态和未确认参数以 `docs/7_4铣平面选择与型腔槽公共交互需求_2026-08-31.md` 为准，说明书未定义项继续阻断。

### 安全子集与参数

- 仅正面 `+Z`、平底、直壁、闭合矩形或凸多边形外环；底面、侧壁、外环、Setup、几何版本和深度证据完整。单孤岛只在其闭合、完全包含、与外环不接触且保护边界可证明时开放。
- 参数：端铣刀及刃长/总长、`stepOver`、`stepDown`、侧余量、底余量、目标深度、安全高度、进退刀候选、粗/精加工开关和来源快照。`stepOver` 不得大于刀径；层深、余量、刀具中心包络与通道宽度必须可验证。
- 不做：曲面底、斜壁、侧面 Setup、凹多边形多解偏置、自交修剪、动态铣、未确认孤岛、边界/保护区接触、不可证明坡道或螺旋。

### 识别、计划与刀路

1. 从 `SlotFrameRecognizer` 输出 `RecognizedFeature`：稳定环、底/侧面、深度、保护区、孤岛和拒绝证据；识别不创建工序。
2. 规则/选刀仅使用版本化尺寸/材料/机床条件和 M1 精确匹配；无唯一刀具或刀具中心可达区域不足则拒绝。
3. 人工确认后交 `SlotFramePlanningService`/`OperationFactory` 创建粗加工、侧精加工、底精加工的有序工序；不重写 `PocketRoughingStrategy`、`PocketFinishStrategy`、`PocketFloorFinishStrategy`。
4. 粗加工采用现有二维区域内核的可达区域和保护环；逐层 `stepDown`，保留侧/底余量。精加工仅在剩余边界可证明时启用。进刀仅允许可证明不越界的斜坡或螺旋；否则从安全高度垂直进给，不假生成坡道。
5. 环间或跨区域连接一律抬到安全高度；G0 不得在切削深度横跨保护区/孤岛。

### 测试与完成定义

- 测试：矩形、凸多边形、单孤岛、窄通道、保护区碰撞、无底面/边界、错误 Setup、刀长不足、余量/分层、可/不可证明进刀、保存重开、几何变化失效；CQ8/Fanuc/Siemens 的 G0/G1/G2/G3、边界、深度、安全检查和最终仿真。
- DoD：每个成功型腔都有稳定几何/参数/刀具快照、确认原子性、刀具中心不越界的证据和最终代码仿真；子集外输入稳定拒绝，绝不降级为开放轮廓或动态铣。

## 5. P2：简单槽

**落地模板索引：** 说明书第七章 7.4 公共选择及槽类条目（精确编号待以原手册核对）；当前为半成品。中心线/边界、宽深、分层、进退刀和预览均须按统一模板留下证据。

### 安全子集与参数

- 仅正面 `+Z` 的简单直槽、矩形盲槽和已有自由端证据的开放槽；输入为中心线/外环、方向、端部类型、长度/宽度/深度、底面/侧壁、Setup、几何版本和保护区。
- 参数：刀具直径/长度、槽宽深长、方向、端部、`stepOver`/`stepDown`、侧/底余量、起点、进退刀、安全高度及快照来源。槽宽必须覆盖刀具中心包络和双侧余量。
- 暂缓：T 槽、燕尾、侧面/背面、复杂曲线槽、相交槽、曲面底、无持久化自由端或补线证据的开放轮廓。

### 识别、计划与刀路

1. `SlotFrameRecognizer` 必须区分闭合槽与开放槽；开放槽只保留可解释自由端/补线元数据，绝不擅自封闭。
2. 选择/规则仅产生候选与刀具/参数快照，人工确认后由 `SlotFramePlanningService` 和 `OperationFactory` 创建单个有序槽工序。
3. 复用 `SlotMillingStrategy`、`BlindSlotMillingStrategy` 和 `SlotMachiningGeometry`：沿槽方向分层，保留余量；只有端部与刀具中心包络可证明时做端部清根。进刀采用已证明的安全端部进给或安全高度垂直进刀；跨槽移动先抬刀。
4. 任何端部、保护区、通道、刀长、深度或 Setup 不满足时拒绝，不套用型腔路径。

### 测试与完成定义

- 测试：直槽、矩形盲槽、证据化开放槽、端部方向、窄槽、保护区、深度/余量/分层、进退刀、安全 G0、保存重开、几何失效及三后处理器最终代码仿真。
- DoD：成功槽可从稳定识别证据到确认后的正式工序和最终代码；开放槽没有自由端证据、任何 T 槽/燕尾/侧面/复杂曲线请求都稳定阻断。

## 6. 依赖、排期与集成顺序

```text
M2.1-A 候选调和
  → selector 适配 + 确认原子链
  → 孔最终代码回归
  → 型腔确认/规则薄层 + 现有策略验收
  → 简单槽确认/规则薄层 + 现有策略验收
```

| 阶段 | 单人串行（含 20% 评审缓冲） | 三人并行（含集成缓冲） | 主要输出 |
| --- | --- | --- | --- |
| 孔：M2.1-A、selector、确认、回归 | 6–8 周 | 3–4 周 | 可审计孔候选到原子正式链。 |
| 型腔：二维安全子集收口 | 5–7 周 | 3–4 周 | 正面平底凸闭环型腔端到端证据。 |
| 槽：简单槽收口 | 4–5 周 | 2–3 周 | 直/矩形/证据化开放槽。 |
| 跨模块集成与机床验收 | 2–3 周 | 2–3 周 | 三后处理器、仿真和受控机床试切。 |
| **总计** | **17–23 周** | **10–14 周** | 不含动态铣、复杂 3D、T 槽/燕尾。 |

三人建议：A 负责 M2.1-A/selector/确认合同；B 负责型腔识别与策略验收；C 负责槽及最终代码夹具；集成人维护 `untitled/untitled.pro`、`untitled/scripts/run_tests.ps1`、`OperationFactory`、后处理器和项目持久化的预约修改。单人严格按依赖图串行，不能在孔确认边界未验收前声称自动孔闭环完成。

分支/提交顺序：`codex/hole-reconciliation` → `codex/hole-confirmation` → `codex/pocket-safe-subset` → `codex/slot-safe-subset` → 集成分支。每项先失败测试、最小实现、聚焦测试、Debug 构建、`git diff --check`；小提交使用 Conventional Commits，禁止 `git add -A`。

## 7. 验收门与业务确认

| 门 | 必须证据 | 失败处置 |
| --- | --- | --- |
| 自动化 | JSON round-trip、黑盒/单元、候选无副作用、确认原子性、保存重开和失效测试。 | 稳定原因，不创建正式工序。 |
| 最终代码 | CQ8/Fanuc/Siemens 的最终后处理代码、`GCodeSafetyValidator`、最终代码仿真。 | 阻止导出/仿真展示为可加工。 |
| 机床 | 受控材料、已测刀具、独立安全高度/R 平面核对、试切记录。 | 回退到仿真通过的前一安全子集。 |
| 业务 | Hn/AT 定义、深孔参考面/控制器能力、selector 权威目录、材料/规则版本治理、生产容差、开放槽自由端证据。 | 保持相应能力阻断。 |

已知 `acceptance_step_model_test` 的侧面型腔缺专用 Setup 基线不得删除或放宽；它不是本计划功能通过的替代证据。动态铣、凹多边形/多解偏置、曲面底、复杂 3D、T 槽、燕尾和未确认孤岛必须继续显示为不支持或安全阻断。

螺纹/牙类、倒角和刻字继续为后续模块，不能抢占 P0 孔、P1 型腔或 P2 槽的实现与验收容量。

## 8. 简化操作产品目标

产品交互以“少步骤但不隐藏安全门”为目标，参考公开 CAM 工作流心智而不复制任何产品 UI、商标、私有实现或兼容性。孔采用“选择对象 → 工艺建议 → 关键参数”的自有三段式，常用成功流程目标不超过 5 个主要动作；型腔/槽统一为“选择区域 → 加工方式 → 刀具与步距 → 进退刀 → 高度与深度 → 验证”，目标不超过 6 个主要动作。

路径预览、材料/碰撞验证、机床/最终代码仿真必须分层显示：预览不等于碰撞验证，材料验证不等于最终控制器代码或机床运动学验证。推荐可解释、可撤销、可编辑；正式工序仍只在人工确认后通过 `OperationFactory` 创建。详细映射、验收场景和不做范围见 `docs/Mastercam简化操作参考方案_2026-08-31.md`。
