# CNEXT-CAM 需求与开发进度核对（CAM 优先基线）

> 版本：2026-08-11  
> 实现基准：`D:\yanggao\gcodecnc\untitled`（独立 PC 软件）  
> 本文用途：冻结当前 CAM 验收边界、核对实际开发进度，并列明甲方与硬件方案确定前必须关闭的事项。

> **v0.2 修正（2026-08-11）**：CQ8 首期后处理器已实现 `Oxxxx/M98 Pxxxx/M99` 和
> `#100-#199` 有限数值参数，输出主程序与 `CQ8_MACROS.NC` 宏库。安全校验与仿真仍以
> 保存的展开等价程序为权威；表达式、条件、循环、嵌套及真实 TCP 控制仍不在本期范围。

## 1. 已确认的产品边界

1. 当前唯一开发对象是独立 PC 软件 `CNEXT-CAM`；不引入、不依赖、不改造 `CNC_SYSTEM` 项目。
2. 本阶段只完成离线 CAM。CQ8 的 TCP 通信、程序下发、旋转缓冲、实时运动、PLC、IO 和安全联锁均不开发。
3. CQ8 只保留文档级接口契约和“未连接/待接口验收”界面状态；硬件方案、方言和协议冻结后才写控制代码。
4. CAM 必须保持人工工艺决策：软件识别和推荐，操作员选择工艺、刀具和参数并确认后，才能生成正式程序。
5. 首期仅支持毫米制，最终输出采用受控的通用 ISO G 代码基线。Siemens/Fanuc 后处理器只用于兼容导出和回归；CQ8 提供首期 Macro B 兼容后处理器。
6. 展开后的等价 G 代码是安全校验、仿真、审查、哈希、追溯及未来流式下发的唯一权威；CQ8 主程序与宏库是控制器导出形式。

## 2. 首期 CAM 离线验收范围

| 项目 | 已冻结范围 | 不在本阶段 |
| --- | --- | --- |
| 坐标与 Setup | 单 Setup、三轴正面加工、G21、人工确认正面/原点/毛坯、G54-G59 选择 | 多 Setup、局部坐标旋转、四五轴、RTCP |
| 加工对象 | 孔（G81-G85）、槽、矩形/圆形型腔、已验证的异形型腔开粗、最终验收模型实际需要的平面与二维轮廓 | 通用 CAD 编辑、动态铣、刻字、复杂 3D 曲面 |
| 工艺决策 | 操作员确认工艺、刀具、模板参数和特殊风险 | 静默自动建工序或自动下发机床 |
| 验收方式 | STEP 黄金用例、人工确认、最终 G 代码、安全校验、仿真、快照/哈希和自动回归 | CQ8 通信、空跑、试切、实时控制验收 |
| 参数来源 | 现场确认的材料—刀具—工艺模板；允许人工修改 | 无材料/刀具依据的自动参数推荐 |

## 4. 安全代码与程序输出规则

1. 安全起始、G80、坐标系、换刀、主轴、冷却和程序结束块由版本化 `Machine Profile` 管理。
2. 操作员可在获准的配置范围内选择或修改代码；修改后必须重新生成安全校验结果、程序快照和哈希。
3. 手工文本不得绕过单位、绝对编程、G80、低位快移、刀补取消和停机顺序等硬安全校验。
4. CQ8 方言冻结前，界面和交付物统一称为“已验证通用 ISO G 代码”；中性导出使用 `.nc`/`.tap` 等文本形式。选择 Siemens/Fanuc 后处理器时必须标注目标控制器复核要求。

## 5. CQ8 接口预留（不实现控制）

未来 CQ8 接口的输入必须由不可变 `Program Snapshot` 构成，并至少保留以下字段：

| 字段 | 作用 |
| --- | --- |
| Program Snapshot ID、创建时间、Program Hash | 唯一标识和内容一致性 |
| 来源 Operation ID、工序快照指纹 | 程序与人工确认工艺的追溯 |
| Machine Profile ID/版本 | 安全起始、代码规则和机床配置的追溯 |
| 目标方言版本、能力需求 | 将来由 CQ8 能力协商拒绝不兼容程序 |
| 最终展开 G 代码、行数、字节数 | 完整下载和未来流式传输的共同源 |
| 参数化例程元数据 | 审计与后续 CQ8 子程序映射，不能替代最终文本 |

未来接口应由 CQ8 专项设计确定：TCP 报文、鉴权、状态机、超时、分块确认、重传、环形缓冲水位、暂停恢复、报警码和能力协商。本阶段不为这些未冻结规则编写实现代码。

## 6. 甲方/现场待确认清单

### P0：阻塞最终模型 CAM 验收

1. 提供并确认最终模型“特征—工艺验收表”：加工对象、目标尺寸/公差、表面粗糙度、粗精加工要求、加工顺序和验收方法。
2. 确认材料、毛坯尺寸及六向余量、装夹方向、基准面、G54 原点和允许的安全高度。
3. 确认首期刀具清单：刀具类型、直径、刃长、总长、刀柄/伸出量、刀号与允许加工范围。
4. 确认材料—刀具—工艺模板：转速、进给、下刀、层深、步距、余量、冷却及哪些人工参数可用于验收。
5. 确认每种孔、槽、型腔、平面和轮廓是否要求精加工，以及允许采用的策略。

### P1：冻结 CQ8 前必须形成的接口资料（但暂不开发）

1. CQ8 G 代码方言版本及程序号、行号、注释、百分号、数值精度和舍入规则。
2. G80-G85、G41/G42、G43、M 代码、圆弧和子程序/参数传递的完整语义、范围和错误处理。
3. CQ8 程序文件格式、最大行长/程序大小、函数嵌套限制及能力协商返回字段。
4. PC—CQ8 TCP 协议、状态/报警模型、分块确认与重传、完整下载与旋转缓冲切换条件。
5. 机床电气、轴/主轴、刀库、辅助功能、实体面板、IO 点表和独立安全链方案。

## 7. 近期开发计划（CAM 唯一优先级）

1. 接收甲方“特征—工艺验收表”，将最终 STEP 的必需特征逐项映射为可重复黄金用例。
2. 对每个用例完成：识别 → 人工确认 → 工艺模板 → 最终 G 代码 → 安全校验 → 仿真 → 快照/哈希 → 自动回归。
3. 仅补齐黄金用例暴露的实际缺口，优先平面/二维轮廓精加工和已选型腔精加工；不扩展无关功能目录。
4. 收口通用 ISO 输出、程序编辑后的失效链和安全校验回归。
5. 硬件与 CQ8 方言、协议和安全方案书面冻结后，再单独立项 CQ8 后处理器、TCP、流式下发和实机联调。
