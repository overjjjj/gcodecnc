## 二、与手册第七章的统一业务链

```text
选择加工方式
  → 公共选择会话（边/面/串联/实体/线框/毛坯）
  → 方向、起点、分支、反向、排序
  → SelectionCandidate（不可执行）
  → 工艺参数与模板建议
  → 人工确认
  → OperationFactory 原子创建 MachiningOperation
  → 刀路重算与状态确认
  → 后处理、安全检查、最终代码仿真
  → ProgramSnapshot
```

`FaceRegion` 只作为识别提示和筛选信息。真正的放行条件是用户选择证据、当前 Setup/WCS、刀具进入方向和拓扑证据共同证明可达。无法证明时必须阻断。

## 三、3–5 人开发组下发

### A 组：领域与持久化（1 人）

- 负责 `src/core` 的 `SelectionCandidate`、稳定几何引用、SetupAccess 状态和项目序列化。
- 维护来源指纹、Setup/WCS revision、外环/孤岛/自由端证据和旧项目兼容。
- 不依赖 Qt Widgets、Strategy 或后处理实现。

### B 组：选择交互（1 人）

- 负责通用选择串联窗口和 Viewport 拾取适配。
- 将边/面/串联结果转换为 `SelectionCandidate`，通过信号或应用端口交给工作流层。
- 不创建 `MachiningOperation`，不生成 G-code，不直接调用 Strategy。

### C 组：工序工作流（1 人）

- 负责 `OperationProposal`、`OperationFactory`、人工确认事务和 UI 编排。
- 统一平面、槽、型腔、轮廓入口的候选→参数→确认流程。
- 负责 Side 标签但当前 Setup 可达、真正侧向不可达、Back/Unknown 和过期证据的状态转换。

### D 组：策略与参数（可选第 4 人）

- 负责 ParameterSchema、模板建议和二维平面/槽/型腔策略适配。
- 先补手册要求的余量、路径方式、下刀方式、连接方式和孤岛约束，再扩展复杂几何。
- 策略层只依赖领域 DTO 和 `StrategyParams`，不得引用 QWidget 或通信层。

### E 组：验证与集成（可选第 5 人）

- 负责 `run_tests.ps1`、Debug/Release 构建、CQ8/Fanuc/Siemens 回归、最终代码仿真和验收 STEP。
- 维护 G-code 安全检查清单和测试证据；不得为通过测试放宽安全门。
- 负责提交范围审查，排除反编译资料、输出物和临时目录。

## 四、组间接口与提交规则

- B→C：只传 `SelectionCandidate`，禁止传 QWidget 指针或策略实例。
- C→D：只传确认后的 `MachiningOperation`/参数 DTO，策略不读取 UI 状态。
- C→E：传已确认工序和不可变生成选项；E 只验证输出，不修改工艺意图。
- A 提供值对象和序列化版本；任何字段新增必须同时增加 round-trip 测试。
- 每个小组先提交 RED 测试，再提交最小 GREEN；不跨越尚未验收的批次。
- 集成顺序固定为：A → B → C → D → E；每批必须通过全量脚本和相关最终代码仿真。

## 五、近期迭代门禁

1. 修复测试脚本并完成当前工作区全量回归。
2. 完成公共选择候选与 SetupAccess 的 UI 接线。
3. 完成平面/挖槽/型腔的参数确认闭环，验证孤岛和余量。
4. 用验收 STEP 完成“选面/串联→参数→确认→CQ8 输出→安全检查→仿真”闭环。
5. 通过后再进入凹轮廓、多孤岛、动态铣或多面坐标，不在本批次混入实时机床通信。
