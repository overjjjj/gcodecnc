# 7.4 铣平面选择与型腔槽公共交互需求（2026-08-31）

## 1. 证据、目的与安全边界

本文件只把用户提供的 7 张《加工中心控制系统用户使用手册》7.4“铣平面”截图转写为可评审的产品交互需求。截图只证明界面上出现过的名称、选项和示例行为，**不**构成几何算法、控制器语义、单位、容差或安全参数的可执行指令；原图片不复制进仓库。

观察来源为 7 张外部截图（2026-08-31 提供）：快捷方式/选择串联总图、说明文字、坐标系新建、边缘与串联、实体面与局部串联、分支/起点/反向、排序/确认。未从图标形状推断精确功能名称；“最小值”没有可观察单位、比较方向或几何定义，保留业务确认。

首期公共链固定为：

```text
SelectionSession
  → stable GeometryRef / Loop
  → direction / start / ordering snapshot
  → Pocket / Slot RecognizedFeature
  → OperationProposal（人工确认前）
```

该链不得直接创建 `MachiningOperation`、调用策略、生成刀路或写控制器文本。确认后仍必须经既有 `OperationFactory → Strategy → PostProcessor → GCodeSafetyValidator → final-code Simulation`。冷却冻结。

首期仅支持 Front `+Z`、稳定拓扑引用、明确闭环或已证据化自由端。3+1/3+2、侧面/多轴、一般斜面/圆角加工只可保存 UI 选择/候选或明确阻断，不能据此开放加工。

## 2. 建议公共 DTO 与状态

| DTO / 状态 | 建议字段 | 合同 |
| --- | --- | --- |
| `SelectionSession` | `sessionId`、`setupRef`、`mode`、`targetKind`、`directionIntent`、`selectionRevision` | 临时、可撤销的 UI 会话；不是工序。 |
| `StableSelectionRef` | `GeometryRef`、拓扑类型、`geometryRevision`、局部命中参数、证据来源 | 实体/面/边/闭环/自由端必须可重开解析；解析失败使会话过期。 |
| `LoopSelectionSnapshot` | 有向 edge 序列、闭合性、分支记录、起点、反向、箭头可见状态 | 完整复制用于候选审计；不能由后续模型“就近补边”。 |
| `SelectionDirection` | `Inside` / `Outside` / `Mixed` / `Unspecified` | `Mixed` 只表示待解释候选，不是可加工默认。 |
| `StartAndOrderSnapshot` | 动态起点意图、显式起点、反向、排序模板 ID/版本、容差输入 | 排序必须可解释；未确认容差不能影响刀路。 |
| `CoordinateSystemDraft` | 名称、原点、X/Z 方向、绕 Z 的离散旋转、显示状态 | 仅候选 Setup 编辑数据；必须经 Setup 校验后才可引用。 |
| `PocketSlotRecognizedFeature` | `GeometryRef`、Loop、Setup、底/侧壁、自由端、保护区、拒绝证据 | 识别结果；只可转 `OperationProposal`，不能直接成工序。 |
| 会话状态 | `Editing`、`Completed`、`Cancelled`、`Rejected`、`Stale` | `Completed` 仅表示选择结束，不表示加工确认。 |

## 4. 与型腔/槽的复用规则

1. 型腔只接受 `closed=true` 的 Loop，连同底面、侧壁、保护区和可验证孤岛形成 `PocketRecognizedFeature`；`Inside` 是必需的显式/可解释方向。
2. 槽接受闭合矩形/直槽，或带自由端与补线证据的开放链形成 `SlotRecognizedFeature`；开放链不能通过“结束串联”被静默封闭。
3. `PreviousSelectionReference`、分支、动态起点、反向和排序都只修改选择/顺序快照。它们不修改刀具、深度、进退刀、`stepOver`、`stepDown`、余量、冷却或已确认工序。
4. `CoordinateSystemDraft` 必须在候选确认前转换为有效且可追溯的 Setup；选择会话不能用旋转显示掩盖侧面/多轴加工。

## 5. 未决业务确认

- “最小值”的比较对象、单位、比较方向、作用范围、默认值及是否应用于孔/型腔/槽。
- 排序“公差”的单位、几何意义、范围和零/缺省语义。
- 排序图标模式的准确名称、算法、与起点/反向/分支的交互及可否跨工序。
- “混合”方向的分类规则、人工覆盖方式与多个特征的拆分规则。
- `3+1/3+2` 坐标系编辑是否仅显示、是否允许生成候选，以及所需运动学/后处理/机床验证。
- 开放槽自由端/补线的持久化证据格式与失效策略。

在上述事项确认并拥有失败测试前，界面可以呈现相应选择，但必须标为未启用/需确认，不得生成刀路或正式工序。
