# 模块 6：自动工艺、规则表与刀具资料验收记录

日期：2026-08-25

## 当前结论

状态：**半成品（安全可验证子集已完成）**。

验收边界为“资料/规则显式选择 → 稳定几何引用候选草稿 → 人工选择方案并确认 → `OperationFactory` 正式工序 → 最终 CQ8、安全检查与仿真”。自动识别、字段填充或菜单入口均不得直接写入正式工序树。

## 首批验收测试

- 版本化材料、刀具类型、工艺模板和模块规则可持久化；显式应用遵循“系统默认 < 材料 < 刀具类型 < 模块规则 < 人工覆盖”。
- 修改资料定义后，已确认工序参数、来源和模板快照保持不变；仅用户显式重新应用或恢复时改变当前工序值。
- 受限公式只接受 `H1`、`H2`、`AT`、正数、小数、四则运算和括号；拒绝未知变量、非法字符/函数、除零、非有限结果和越界深度。
- 自动孔再次识别保留已有人工方案与参数覆盖；几何签名变化时标记冲突/过期，不静默覆盖。
- 自动孔只有在显式选择方案、刀具存在、公式可解、Setup/安全高度/目标深度合法时，才经 `OperationFactory` 创建正式工序。
- 未确认候选、智能倒角不可验证候选和自动框均不能进入正式工序树或最终程序。

## recovered DTM 源码审计结论

- `源码整理/README.md` 明确恢复文件是反编译伪代码，不能视为可直接编译实现；本模块只把入口、数据流和交互顺序作为审查依据。
- `ModuleAutoHole_recovered.cpp` 的 `WorkSchemes`、`WorkParamsList`、`WorkToollib`、表格编辑/删除及 `sigGenerateWorkParams` 表明原设计存在“识别、编辑、生成参数”的分阶段流程；当前实现进一步要求显式确认并统一经 `OperationFactory` 创建正式工序。
- 恢复代码含 Excel 模板和刀具/材料列表读取；当前实现改为项目内版本化 JSON 定义，避免外部表格变化静默改变既有工序。
- 自动框恢复代码虽包含大量几何与干涉流程，但无法从反编译结果证明边界偏置和连续安全刀路，因此入口保持禁用。

## 实施证据

- 资料模型：`ProcessTemplateLibrary` 持久化参数模板和 `MachiningPlan`，同一 `id@version` 禁止覆盖；`ProcessTemplateService` 按既有五层优先级解析。
- 受限公式：`RestrictedFormulaEvaluator` 使用递归下降 AST，仅接受 `H1/H2/AT`、正数、小数、四则运算和括号；未知变量、脚本/函数、指数、除零、非有限及过大结果均拒绝。
- 草稿合同：`AutoHolePlanningService::Recognize` 只生成带稳定几何引用的候选；重复识别保留人工覆盖，几何变化标过期，方案版本变化标冲突。
- 确认合同：`AutoHolePlanningService::Confirm` 要求草稿状态、显式方案、存在且匹配的刀具、合法 Setup、可解公式及不越界深度，之后才调用 `OperationFactory::CreateConfirmed`。
- UI：`AutoHoleCandidateDialog` 明示“候选草稿/确认创建工序”，未选择方案时按钮不可用；`ProcessTemplateLibraryDialog` 明示版本不可覆盖；主界面只在确认后写入工序树，不在识别阶段生成代码。
- 最终路径：`auto_hole_cq8_integration_test` 验证正式工序 ID 可追溯到最终 CQ8，输出含真实 G83 与安全结束，并由最终代码仿真到公式计算深度。
- 持久化：`project_manager_serialization_test` 验证模板和方案保存重开，旧项目无该字段时保持空资料库兼容。

## 遗留风险

- 自动孔目前不是完整 DTM 多层复合孔规划器；沉头、沉孔、螺纹、铰孔、镗孔的多工序组合与层间规则仍未实现。
- `H2` 可供公式使用，但当前可靠单层孔子集没有证明所有 STEP 识别结果中的 `secondaryRadius` 均代表 DTM 的第二层高度，涉及该语义的方案应保持禁用。
- 材料资料是参数模板层，不是完整材料数据库；没有自动推荐或后台静默重算。
- 智能倒角和自动框没有可靠三维偏置/干涉验证，继续只允许候选或显式拒绝，不能生成正式刀路。

## 模块 7 系统级验收计划

1. 用真实 STEP 依次验证“选几何 → 候选 → 显式方案 → 正式工序 → 重算 → 最终 CQ8 → 安全检查 → 最终代码仿真”。
2. 保存并重开项目，核对模板版本、方案引用、参数来源、人工覆盖、稳定几何引用和工序路径状态。
3. 修改几何、Setup、WCS、毛坯、刀具和资料版本，逐项核对失效、冲突或保持快照，不允许静默更新正式工序。
4. 验证工序启停、排序、编辑、撤销及最终程序 `sourceOperationIds`；最终预览只能追溯最终输出。
5. 对 DTM 各入口留存“可完成路径、拒绝原因、最终代码、仿真证据”，并单独登记既有侧面型腔 Setup 基线失败。
