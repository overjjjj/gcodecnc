## 共用的数据与职责

1. **选择层：选了什么。** 保存真实face/edge/方向、源指纹、选链顺序、起终点、闭合性；不按工艺修改源内外环身份。
2. **区域解析：能加工哪里。** 输出实际外边界、岛屿、开放边、加工平面与刀轴、经验证的深度范围、支撑几何、状态及具体失败原因。保留曲线语义；需要离散时使用明确容差。
3. **策略能力：此工艺支持什么。** 闭合/开放、区域类型、刀轴和深度要求只维护一份。未知、未支持、无效分别报告。
4. **参数应用：本次加工多少。** 将同一区域与用户刀具、深度、余量、进退刀参数转为工序输入；新建与编辑共用。明确区分用户目标深度和几何允许范围。
5. **生成与校验：刀路是否符合工序。** 重新核对源/Setup/区域和参数，生成最终NC，再验证完整轨迹约束。预览从最终NC解析。
6. **保存和重载：复用同一契约。** 保存区域与证据，证据进入快照指纹；旧记录缺少证明时要求重新解析，不自动升级为可加工。

这是现有模块职责归并，不新增第二套选择系统、第二套参数映射或通用插件框架。外部NC导入本身没有模型选区，不强行绑定区域证明；继续保持独立来源及仿真限制。

## 参考面板的统一交互

- 单边、串联、实体面、局部串联是同一选择会话的输入方式；模式切换的选区保留/清理行为需明确并测试。
- 鼠标靠近只高亮当前候选，点选后加粗；进入挖槽不点亮全部边界。
- 铣内、铣外、混合表达加工侧意图，不用于伪造源拓扑内外环。不同工艺解释意图后仍须验证。
- 选择上次、撤销、结束串联、显示箭头、分支上一个/下一个/调整、设置起终点、反向、排序共用选链状态；反向与排序不能改变实体区域。
- 同一Z平面、斜面/圆角等快捷选择只负责寻找候选；搜索容差不等于加工容差，候选仍走相同确认流程。
- 挖槽、环形区域、铣平面、轮廓等入口传入各自能力需求，复用选择与区域解析。截图不能确认的名称暂不加入实施范围。
- 界面分别显示选择是否完整、区域是否已确定、工艺是否支持；失败指出当前原因，如不闭合、区域未判定、曲线能力未支持、深度越界或Setup不匹配，并给出可行下一步。

## 实施顺序

### 第一批：统一底层契约与参数应用

合并策略需求表和几何/参数应用入口；移除通用选链中的四边五面限制；源角色与加工角色分开；保留现有四边证明作为几何能力实现，禁止通过放宽检查伪造支持。先补工序深度编辑复现，验证新建和编辑一致。

### 第二批：区域证明与圆角闭环

用同一闭环表示承载直线与圆弧，不依赖边数。以真实face98和face113作为两个回归入口，先核对face113的源曲线、邻壁、底面和深度，再确定可加工范围。不得把face98的16.268 mm限制套到其他面。同步处理同面多环的准确映射和岛屿角色；不支持的岛屿加工可以明确拒绝，但必须正确识别角色。

### 第三批：工艺与完整流程接入

逐一接入本轮涉及的工艺入口、选择模式和参数编辑；清除已替换的重复分支，保留无关功能。每次集成通过相关回归后再进入下一批，最后统一构建和验收。代码修改由同一编码线程顺序集成，避免多线程同时改共享文件。

不将本轮扩展为通用三维斜底精加工、多轴或全部控制器指令支持。真实斜底的公共浅层与完整斜底加工分别说明，禁止把几何未知当成可以加工。

| 输入/场景 | 必须验证 |
| --- | --- |
| face98四边槽口 | 原先已通过的真实选边→参数→工序→最终NC保持有效；浅层深度限制保留 |
| face113八段圆角轮廓 | 无边数特判；从真实源模型证明区域，确认曲线偏置、深度和最终刀路；尚未验收 |

| 圆弧、凹边和岛屿 | 完整刀具运动范围受限；不能仅检查端点或用显示折线代替精度证明 |
| 开放槽、斜底 | 已支持策略保持；未验证组合给出具体限制，不扩写既有测试结论 |
| 新建/编辑深度及刀具余量 | 合法修改改变最终NC；超范围修改拒绝，不留下新参数配旧几何的工序 |
| 撤销/反向/换模式/重新选择 | 选区、证据、箭头、参数上下文一致，无旧区域残留 |
| 保存重载/模型或Setup变化 | 证据一致或明确失效；陈旧快照不能继续当有效程序 |
| 非法闭链/错误平面/超深 | 在一致入口阻止，并返回同一原因，不能前端过后端才换理由 |
| 外部NC两份归档 | 保留26段分段回放、全局行号、第11段差异、G28断开及G43未知偏置提示 |
