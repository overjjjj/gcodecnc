## 2. Ribbon 功能定义

### 2.1 文件&零件

| 动作 ID | 标题 | 打开对象 | 启用条件 |
|---|---|---|---|
| `project.cad` | 打开 CAD | 外部 CAD/区域拾取流程 | 已配置 CAD |
| `project.new` | 新建 | 保存确认框 | 始终 |
| `project.open` | 打开 | 工程文件选择器 | 始终 |
| `project.save` | 保存 | 无或另存路径框 | 有活动工程 |
| `project.saveAs` | 另存为 | 工程文件选择器 | 有活动工程 |
| `project.recent` | 历史记录 | 最近 10 项菜单 | 有历史记录 |
| `part.import` | 导入 | 模型文件选择器 | 有活动工程 |

### 2.2 孔类

动作：打点、孔倒角、钻 G81、钻 G83、钻 G73、镗 G76、镗 G86。

统一交互：点击动作 → 进入孔位选择 → 点/圆弧/内表面/直径分类选孔 → 调整顺序 → 参数窗口 → 预览 → 创建工序。

### 2.3 牙类

- 攻牙：孔位选择 + 攻牙参数。
- 铣牙：圆形/圆柱选择 + 铣牙参数。

### 2.4 铣面

- 铣平面：串联/面选择。
- 快捷选择能力在串联面板内提供：斜面、圆角、同 Z 平面、最小周长过滤。

### 2.5 槽类

- 挖槽
- 环形铣
- 铣孤岛
- 动态铣

### 2.6 外形类

- 铣形
- 外形倒角
- 3D 倒角
- 清内角
- 刻字
- 空间曲线

### 2.7 斜面&圆角

- 铣斜面
- 3D 铣斜面
- 铣圆角

### 2.8 模块

- 特征孔
- 智能倒角
- 自动孔
- 自动框（实验/待更新标记）

### 2.9 辅助

- 原点、摆正、夹钳、文字、标注、仿真。
- 刀具、模板、模块模板、加工设置。
- 测量、放弃、重做、孔分类。
- 便捷绘图和模型编辑可放入二级菜单或上下文工具页。

## 3. 串联选择面板

### 3.1 面板状态

```text
Idle
  → Picking
  → ChainBuilding
  → Ordered
  → Confirmed
  → OperationParameters
```

关闭面板返回 `Idle`；重选图形从参数页返回 `Picking`，但保留尚未确认的工艺参数。

### 3.2 控件清单

| 分组 | 控件 | 类型/取值 |
|---|---|---|
| 快捷 | 快捷动作 | 铣斜面、铣圆角、同一 Z 平面 |
| 快捷 | 最小值 | 非负小数，过滤外环周长 |
| 选择体 | 几何源 | 实体、线框、毛坯 |
| 铣方向 | 方向 | 铣内、铣外、混合 |
| 坐标系 | 当前坐标系 | 下拉选择 |
| 坐标系 | 管理 | 删除、编辑、新建 |
| 选择方式 | 模式 | 边缘、串联、实体面、局部串联 |
| 选择 | 历史操作 | 选择上次、撤销、结束串联、显示箭头 |
| 分支 | 导航 | 上一个、切换分支、下一个 |
| 起点/结束 | 路径控制 | 动态起点、反向 |
| 排序 | 排序方式 | 双向/单向 X/Y、斜向、点到点等 |
| 底部 | 提交 | 确定、取消 |

### 3.3 选择结果数据

SelectionChain

## 4. 工艺参数窗口

建议采用“字段定义驱动”的统一窗口，而不是每项工艺复制一套表单。

### 4.1 页签

| 页签 | 内容 |
|---|---|
| 共同参数 | 工艺、坐标系、刀号、刀径、速度、转速、冷却、步距 |
| 刀具库 | 刀号列表、刀名、直径、牙距、齿数、角度、半径、长度 |
| 刀具形状 | 刀具/刀柄示意及碰撞相关尺寸 |
| 切削参数 | 当前工艺专用参数 |
| 高度示意 | 安全高度、下刀高度、基准面、切削深度图示与拾取 |

### 4.2 公共字段规格

| 字段 | 类型 | 基本校验 |
|---|---|---|
| `operationType` | 枚举 | 必填 |
| `workOffset` | 枚举 | G54–G59 |
| `toolId` | 刀库引用 | 必须存在且可用 |
| `toolDiameter` | 只读/继承 | 大于 0 |
| `cutFeed` | 数值 | 大于 0；钻孔类可隐藏 |
| `plungeFeed` | 数值 | 大于 0 |
| `spindleSpeed` | 整数 | 大于或等于 0 |
| `coolant` | 枚举 | 无、外冷、内冷、吹气、内外冷 |
| `stepOver` | 数值 | 通常为 `(0, 刀径]` |
| `stepDown` | 数值 | 大于 0 |
| `safeHeight` | 数值 | 应高于下刀高度和加工区域 |
| `plungeHeight` | 数值 | 不高于安全高度 |
| `referenceZ` | 数值/拾取 | 绝对或增量 |
| `cutDepth` | 数值/几何绑定 | 负值表示基准面下方 |

### 4.3 参数来源与覆盖顺序

```text
系统默认值
  < 材料模板
  < 刀具类型模板
  < 模块/识别规则
  < 工序实例人工修改
```

界面必须显示每个字段的来源，并支持“恢复模板值”，否则自动孔等批量功能生成后很难追踪参数为何不同。

## 5. 工艺专用字段矩阵

| 工艺族 | 专用字段 |
|---|---|
| G83/G73 | 单次深度；G73 另有循环退刀量 |
| G76 | 镗孔偏移、退刀轴、退刀方向 |
| 孔/外形倒角 | 倒角宽度、刀角、刀尖半径/补偿 |
| 攻牙 | 牙距、旋向、攻丝模式、退刀量 |
| 铣牙 | 内/外牙、齿数、旋向、方向、锥角、进刀角、XY 粗精分层 |
| 铣平面 | 路径方式、加工线角度、连接方式、外接矩形 |
| 挖槽 | 保边外扩量、下刀方式、进刀角/半径、XY 投影长度 |
| 铣孤岛 | 内/外轮廓预留量 |
| 动态铣 | 空白区域直径、路径半径、铣削量百分比、深度步进百分比 |
| 铣形 | 平面/斜插、刀补侧、闭合过切、非闭合策略、XY 粗精分层 |
| 清内角 | 前刀直径、内角公差、安全距离 |
| 空间曲线 | 刀补侧、Z 加深；深度预留字段应禁用并注明版本限制 |
| 铣斜面 | 坡度、XY 宽度、分层、保边 |
| 3D 铣斜面 | 过滤非闭合切线、铣孔模式、上下方向、一刀过策略 |
| 铣圆角 | 凸/凹、半径、最小/最大角度、步进角度 |

## 6. 自动孔工作台

### 6.1 页面布局

```text
┌──────────────────────────── 孔分类列表 ────────────────────────────┐
│ 类型/备注 | 加工类型 | 数量 | 起点 | 终点 | 刀具 | 方案 | 参数… │
├──────────── 工序列表 ────────────┬──────────── 子孔列表 ───────────┤
│ 当前孔对应的加工步骤             │ 复合孔每一层的几何信息          │
├──────────────────────────────────┴─────────────────────────────────┤
│ 刀库/材料 | 选择体 | 选择面 | 破孔角 | 毛坯料钻孔 | 工艺表 | 生成 │
└────────────────────────────────────────────────────────────────────┘
```

### 6.2 识别规则模型

```text
HoleRule
  name
  layerKinds[]          cylinder | cone | sealGroove
  diameterRanges[]
  depthRules[]
  candidatePlans[]

MachiningPlan
  orderedSteps[]

MachiningStep
  operationType
  toolExpression        例如 D10、DH2-1
  startExpression       例如 H1、H1+1
  depthExpression       例如 H3-AT
  coolantCode
  parameterTemplateId
```

表达式解析必须使用受限语法树，不应通过脚本求值。允许层变量、刀夹长度、四则运算和多步骤分隔符即可。

### 6.3 生成规则

- 识别结果先作为草稿，不立即写入正式工序树。
- 有多套加工方案时必须由用户选择，默认方案应有明确标识。
- 生成前校验刀具存在、公式可求值、起点高于终点、深度不越界。
- 再次识别时以稳定的几何特征 ID 关联，避免模型顺序变化导致人工修改丢失。

## 7. 智能倒角工作台

| 区域 | 控件 |
|---|---|
| 识别模式 | 型腔框、针板 |
| 选择范围 | 体、面、边 |
| 过滤 | 深度限制、长度限制、直径限制、最大刀尖宽度 |
| 方法库 | 选择、保存、删除、新建并命名 |
| 工艺 | 刀具、宽度、刀尖补偿、转速、下刀/切削速度 |
| 安全 | 侧面间隙、安全高度、刀补开关 |
| 引线 | 进刀、退刀、切线/垂直、直线长度 |
| 操作 | 预览、清空所有边、生成工序、取消 |

识别边、过滤边、生成刀路应是三个独立阶段，视图区分别用不同颜色显示，便于判断是“没识别到”还是“被规则过滤”。

## 8. 属性面板

```text
PartProperties
  materialTemplateId
  modelBounds { length, width, height }
  stock
    shape = box
    dimensions { length, width, height }
    visible
    displayMode = wireframe | solid
    origin { x, y, z }
    boundsMode = allShapesBoundingBox | boundaryBox
```

编辑毛坯尺寸或原点后，应把所有依赖毛坯的刀路标记为“需要重新计算”，而不是静默保留旧路径。

## 9. 工序树规格

### 9.1 节点

```text
OperationGroup
  id, name, enabled, children[]

Operation
  id
  enabled
  type
  toolId
  selectionChains[]
  commonParameters
  specificParameters
  toolpathState         empty | calculating | valid | stale | error
  warnings[]
```

### 9.2 操作

- 启用/停用：组节点应支持三态勾选。
- 上移/下移：组内重排；跨刀具或坐标系移动时给出提示。
- 编辑：恢复几何选择和参数快照。
- 删除：支持撤销。
- 复制：复制参数，但几何引用需要明确选择“共享”或“重新选择”。
- 重算：仅重算过期或失败工序，也可强制全部重算。
- 仿真：选中节点仿真；组节点仿真全部已启用子项。

## 10. 视图区与右键菜单

### 10.1 显示层

从底到顶建议为：栅格 → 模型 → 毛坯 → 辅助几何 → 选择高亮 → 夹具 → 刀路 → 标注/测量 → 操作提示。

### 10.2 右键菜单

- 适应窗口。
- 等轴测、顶、前、左、后、底、右视图。
- 旋转模式。
- 增加外轮廓线。
- 鼠标手势设置。
- 图形选项：背景颜色、平面栅格。

### 10.3 选择反馈

- 悬停：轻量高亮并显示几何类型。
- 已选：固定颜色；闭合串联显示方向箭头和起点。
- 无效：红色闪示，并说明不满足当前选择模式的原因。
- 自动识别：区分候选、已接受、被忽略和发生冲突四种状态。

## 11. 撤销/重做边界

应进入撤销栈的操作：几何选择、起点/反向、坐标原点、摆正、毛坯、便捷绘图、删除特征、工序增删/排序、参数提交。

不进入撤销栈的操作：视角切换、适应窗口、透明度、面板开关、测量临时结果。

每次“确定创建工序”应作为一个事务；自动孔批量生成也应只占一个撤销步骤。

## 12. 关键校验与警告

- 安全高度低于模型、毛坯或夹具最高点：阻止生成或给高优先级警告。
- 切削步距大于刀径：阻止提交。
- 倒角刀角度、刀尖补偿与倒角宽度不匹配：提示计算后的实际 Z 深度。
- 刀补方向可能切入实体：刀路生成后做快速碰撞检查。
- 三维增量深度已经绑定几何时，用户再次输入负偏移应显示最终绝对深度。
- 环形铣/铣孤岛误启用“忽略孤岛”：提交前警告。
- 毛坯或坐标系变化：关联刀路统一转为 `stale`。
- 模板、材料或刀具修改：只影响新工序；已有工序提供显式“同步模板”操作。

## 14. 建议实现顺序

1. 主窗口、三维显示、工程导入和右侧属性/工序树。
2. 通用选择串联与统一参数窗口。
3. G81、铣平面、挖槽、铣形四个代表性工艺，验证统一工序模型。
4. 其余孔类、牙类和 2D 工艺。
5. 斜面、圆角、3D 倒角和空间曲线。
6. 刀具/材料/模板库。
7. 特征孔、智能倒角、自动孔。
8. 仿真、夹具避让、发送加工和恢复机制。

先打通“选几何—填参数—生成工序—重算刀路—仿真”的纵向链路，再扩充工艺类型，可减少界面完成但底层数据不能复用的返工。
