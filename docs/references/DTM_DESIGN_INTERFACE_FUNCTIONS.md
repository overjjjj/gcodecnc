# DTM 设计界面功能全整理

> 依据：《加工中心控制系统用户使用手册》第七章（PDF 第 77–126 页）及 `DTM.pdb` 中 `CatDesign` 类符号交叉核对。  
> 手册负责说明用户可见行为；程序符号用于确认功能入口。本文不把符号名等同于完整源码实现。

## 1. 界面总体结构

设计界面承担从模型导入到生成加工工序的完整 CAM 前端流程：

1. 新建、打开或导入零件模型；
2. 调整模型方向、原点、坐标系和毛坯；
3. 选择点、边、串联、面或实体；
4. 选择孔、牙、平面、槽、外形、斜面等加工工艺；
5. 设置刀具、速度、深度、余量、进退刀和分层参数；
6. 生成刀路并在右侧工序树中排序、启停和修改；
7. 仿真检查，再把加工任务发送到加工界面。

### 1.1 可见区域

| 区域 | 主要作用 |
|---|---|
| 顶部 Ribbon | 文件、孔类、牙类、铣面、槽类、外形、斜面/圆角、模块、辅助和发送入口 |
| 中央视图区 | 显示二维/三维模型、毛坯、坐标轴、选择高亮、方向箭头及加工刀路 |
| 选择串联面板 | 选择对象类型、铣内/铣外、坐标系、路径方向、起点、分支和排序 |
| 程序参数窗口 | 共同参数、刀具库、刀具形状、切削参数和高度示意 |
| 右侧属性面板 | 当前材料、毛坯尺寸/显示方式、毛坯原点和边界盒设置 |
| 右侧工序树 | 工序分组、启用状态、上移/下移、编辑及执行顺序 |

## 2. 通用选择与参数机制

### 2.1 几何选择

- 选择体：实体、线框或根据模型生成的毛坯线体。
- 选择方式：单边、闭合串联、实体面、局部串联。
- 铣削侧：铣内、铣外或由模型自动判断的混合模式。
- 快捷识别：斜面、圆角、同一 Z 平面以及按最小周长过滤平面。
- 路径编辑：选择上次、撤销选择、结束串联、显示方向箭头。
- 分支控制：上一个、切换分支、下一个。
- 起点/方向：动态改变起点、反向路径。
- 多路径排序：支持双向 X/Y、单向 X/Y、斜向和点到点等排序策略。

### 2.2 坐标系

- 默认使用模型导入坐标系和 G54，可选择 G55–G59。
- 可新建、编辑、删除命名坐标系，适配 3+1 或 3+2 加工。
- 新坐标系可设置原点、X 正方向、Z 正方向，并绕 Z 轴旋转 0°/90°/180°/270°。
- 高度支持绝对坐标和增量坐标。三维模型的面高、孔深可自动绑定到增量参数。

### 2.3 各工艺共享参数

- 工艺/坐标：加工方式、坐标系。
- 刀具：刀号、刀名、刀直径及刀径磨损补偿。
- 运动：切削速度、下刀速度、抬刀速度、主轴转速。
- 冷却：无冷却、外冷、内冷、吹气、内外冷。
- 高度：安全高度、下刀高度、基准面、切削深度。
- 分层：切削步距、深度步距、单次深度。
- 质量控制：平面预留量、深度预留量、粗/精铣次数与吃刀量。
- 进退刀：垂直或切线，直线长度、圆弧半径、圆弧角度及是否抬刀。
- 参数可根据“材料 + 刀具类型 + 刀径”从模板自动读取，再由用户修改。

## 3. 文件与零件（7.1）

| 功能 | 行为 | 程序入口 |
|---|---|---|
| 打开 CAD 应用程序 | 启动已安装 CAD；框选二维对象后送回设计界面 | `openAutoCAD` |
| 新建 | 新建工程；未保存时提示保存 | `newProjectFile` |
| 打开 | 打开包含模型和全部刀路工艺的工程文件 | `openProjectFile` |
| 保存/另存为 | 保存模型、工艺与工程状态 | `saveProjectFile` / `saveasProjectFile` |
| 最近文件 | 显示最近 10 个工程，支持再次编辑 | `openRecentFile` / `addToRecentFileList` / `clearRecentFile` |
| 导入 | 导入 DXF、STP/STEP、IGES/IGS 等模型 | `openDxfFile` / `import3rdPart` |

## 4. 孔类（7.2）

孔位置有四种选法：按直径批量选孔、选孔口圆弧、选孔内表面、选圆心点。三维孔面会提供孔深，增量坐标下可自动绑定切削深度；点位支持手动排序。

| 工艺 | 作用与关键差异 | 专用参数 | 程序入口 |
|---|---|---|---|
| 打点 | 深孔钻前打引导点，也可在面板中切换到其他孔工艺 | 通用钻孔参数 | 对应界面钻孔入口；符号中由钻孔流程统一调度 |
| 孔倒角 | 去毛刺、改善装配和外观 | 倒角宽度、倒角刀角度、刀尖半径 | `drillHoleChamfer` |
| 钻 G81 | 单孔固定循环，连续进给到底 | 深度与高度参数 | `straightDrill` |
| 钻 G83 | 深孔啄钻；每次钻后快速回到下刀高度 | 单次深度 | `deepHoleDrill` |
| 钻 G73 | 高速啄钻；每次仅短距离退屑 | 单次深度、循环退刀量 | `peckDrillG73` |
| 镗 G76 | 孔底主轴停止、定向偏移后退刀 | 镗孔偏移；退刀轴/方向在加工设置中配置 | `boreHoleG76` |
| 镗 G86 | 进给到孔底、主轴停止、返回 R 点后重启 | 通用镗孔参数 | `boreHoleG86` |

注：手册把 G76 与 G86 都编号为“7.2.6”，属于手册编号重复，不是功能合并。

## 5. 牙类（7.3）

### 5.1 攻牙

- 像钻孔一样先选择点位，再设置刀具和程序参数。
- 专用参数：牙距、左旋/右旋。
- 加工界面还可选择啄式攻丝或深孔攻丝；啄式需设置退刀量。
- 中断或报警后，可使用加工界面的攻丝回退功能恢复。
- 程序入口：`tap`。

### 5.2 铣牙

- 支持内牙/外牙、左旋/右旋、从上往下/从下往上。
- 参数包括牙距、齿数、进给高度、进刀角度、图形直径修正、锥度角和多齿换层抬刀。
- 支持 XY 粗精分层及独立精铣转速/进给。
- 进刀默认切线，可设置圆弧角度、直线长度和圆弧半径。
- 程序入口：`millWhorl`。

## 6. 铣平面（7.4）

- 先进入选择串联窗口选择加工区域，再进入参数窗口生成刀路。
- 路径方式：双向、单向、环形、一刀过。
- 双向连接可选圆弧或线性；单向每条结束后抬刀返回；环形由外向内；一刀过要求刀径大于区域宽度。
- 可启用“使用外接矩形”，以所选区域外接矩形作为加工边界。
- 可设置加工线角度、切削步距、深度步距、平面/深度余量。
- 进退刀支持垂直和切线，并设置长度、半径、角度。
- 重选图形可删除、编辑、反向、改起点、反转顺序或重新排序。
- 程序入口：`millPlane`。

## 7. 槽类（7.5）

| 工艺 | 用途 | 主要特有参数 | 程序入口 |
|---|---|---|---|
| 挖槽 | 对选线或选面区域进行型腔清除 | 双向/单向/环形/一刀过/螺旋铣；保边外扩量；螺旋/斜插/垂直下刀 | `millGroove` |
| 环形铣 | 加工环形槽；通常必须保留中间孤岛 | 环形边界、进退刀与深度参数 | `spiralMillRing` |
| 铣孤岛 | 保留中间凸柱，清除其周围材料 | 外轮廓预留量、内轮廓预留量 | `millIslandPlane` |
| 动态铣 | 当前用于圆槽，以连续绕行逐步扩到外边 | 空白区域直径、路径半径、进刀角度/半径、铣削量、深度步进 | `dynamicMilling` |

## 8. 外形铣（7.6）

### 8.1 铣形

- “万能铣”，孔、槽和外形均可使用。
- 平面铣形：每个 Z 平面加工完成后再下到下一层。
- 斜插铣形：XY 运动时 Z 同时变化。
- 支持左/右刀补、平面/深度余量、闭合过切、抬刀、长直边中点起刀。
- 非闭合路径可选单方向或弓字形；支持 XY 粗精分层。
- 程序入口：`millOutLine`。

### 8.2 外形倒角

- 用成型倒角刀加工外形或槽边。
- 参数：倒角刀角度、刀尖半径、刀尖补偿、刀补方向、倒角宽度、平面余量、闭合重叠量、侧面间隙。
- 支持平面分层和深度分层，系统按倒角宽度与刀具角度反算每层深度。
- 程序入口：`millChamfer`。

### 8.3 3D 倒角

- 选取三维斜面，斜面深度自动绑定，无需手填切削深度。
- 其他参数沿用外形倒角。
- 程序入口：`millChamfer3D`。

### 8.4 清内角

- 用比前工序更小的刀清除大刀在凹角留下的残料。
- 参数：前工序刀直径、清内角公差、安全距离、刀补方向、平面/深度余量、XY 粗精分层及进退刀。
- 程序入口：`millClearInnerCorner`。

### 8.5 刻字

- 设置文字、字体、方向、高度和位置，在模型上放置线框文字，再用选线框方式加工。
- 程序入口：设计侧文字创建为 `letter`；加工模板中对应“刻字”。

### 8.6 空间曲线

- 串联选择三维模型边缘，按空间路径加工。
- 参数：刀补方向、Z 轴加深、平面余量、起点、切线/垂直进退刀。
- 手册明确“深度预留量”当前不生效。
- 程序入口与符号对应：`millCurve`（另有 `millLine` 处理线类路径）。

## 9. 斜面与圆角（7.7）

| 工艺 | 行为 | 主要参数 | 程序入口 |
|---|---|---|---|
| 铣斜面 | 选斜面；三维图自动读取坡度和深度，二维图手动给坡度 | 刀补、平面余量、坡度、XY 宽度、分层、保边、进刀高度 | `millSlopePlane` |
| 3D 铣斜面 | 直接选择三维斜面加工 | 平面/深度余量、保边、过滤非闭合切线、铣孔模式、上下加工方向 | `millSlopePlane3D` |
| 铣圆角 | 加工凸/凹圆角；已有几何圆角时以模型为准 | 圆角半径、最小/最大角度、步进角度、分层、加工方向、保边 | `millFilletedCorner` |

程序中另有 `chamferSlopePlane`，表明斜面倒角存在独立处理入口，但第七章没有把它列为单独按钮说明。

## 10. 自动化模块（7.8）

### 10.1 特征孔

- 识别三维模型圆孔并生成 G81 钻孔工艺。
- 以最小/最大直径过滤孔；可设置预打点最大深度。
- “相近孔适配”按直径区间匹配刀径，规则可增删。
- 沉头孔默认内孔钻到底、外层钻至沉头深度；可取消沉头孔处理。
- 可选择毛坯料钻孔，并设置贯穿距离、安全/下刀高度、基准面和切削深度。
- 程序入口：`featuresHole`。

### 10.2 智能倒角

- 模式：型腔框、针板；针板模式忽略与 XY 平行的外边框。
- 选择范围：体、面、边；系统按规则自动识别可倒角边。
- 过滤规则：深度、最小长度、最小直径、最大倒角宽度。
- 方法可保存、删除和新建，绑定限制参数、刀具和切削参数。
- 刀路参数：倒角宽度、刀尖补偿、速度、侧面间隙、安全高度、刀补、进退刀。
- 程序入口：`intelligentChamfering`。

### 10.3 自动孔

工作流：选择刀库/材料 → 选择体或面 → 右键识别 → 生成孔分类列表 → 选择加工方案 → 生成工序。

- 工艺表按刀具类型/直径自动提供速度、转速、步距、单次深度、抬刀速度和精铣量。
- 识别表包括孔直径、孔深度、浇注孔和孔类型加工方案规则。
- 多层孔用类别串表示，例如 `1*1`；各层直径区间也可串联定义。
- 加工工序可写成 `1*3*5`，表示依次执行多个项目。
- 公式参数支持层引用：`H1`、`H2-0.2`、`H3-AT` 等；刀具可按层直径表达式匹配。
- 孔分类列表可人工改起止值、刀具、方案、步距、转速、进给和冷却，并可右键删除。
- 工序列表显示每孔工序；子孔列表显示复合孔各层明细。
- 程序入口：`autoHole`。

### 10.4 自动框

- 手册标记“待更新”，没有公开操作细节。
- 程序中已存在入口 `autoSlotFrame`，并另有 `rightAngleBox`，说明功能代码/界面已预留或实现了部分能力。

## 13. 属性与工序（7.11）

### 13.1 属性

- 当前材料来自刀具功能中的材料模板，并决定新建工艺的默认切削参数。
- 自动识别模型长、宽、高和立方体毛坯，也允许手工修改。
- 毛坯可隐藏/显示，并以线框或实体方式显示。
- 默认以毛坯中心为原点，允许修改 X/Y/Z。
- 多模型时，可按“全部图形外接盒”或“边界盒”重新计算毛坯。

### 13.2 工序树

- 按层级显示程序全部工序及刀具/加工方式信息。
- 勾选表示参与加工，取消勾选则跳过。
- 上移、下移改变执行顺序；修改后需同步刷新加工面板。
- 对应程序协作入口包括 `updateProcessPanel`、`setActionEnabled`、`checkStatus`。

## 14. 功能架构归纳

```text
CatDesign（设计界面控制器）
├─ 工程与导入
├─ 几何视图与坐标/毛坯
├─ 选择串联与几何分析
├─ CAM 工艺创建
│  ├─ 孔 / 牙
│  ├─ 平面 / 槽 / 外形
│  └─ 斜面 / 圆角 / 倒角
├─ 自动化模块
│  ├─ 特征孔
│  ├─ 智能倒角
│  └─ 自动孔 / 自动框
├─ 参数知识库
│  ├─ 刀具与刀类型
│  ├─ 材料参数
│  └─ 工艺模板 / 模块模板
└─ 工序树、仿真与发送加工
```

设计界面的核心不是单个几何算法，而是四层协作：几何识别层负责选点/边/面/孔；工艺层把选择转成加工策略；参数模板层补齐刀具和切削条件；工序层保存顺序、启用状态并把刀路交给仿真或加工模块。

## 15. 重构界面时的建议模块边界

1. `ProjectService`：工程、导入、最近文件和临时恢复。
2. `GeometryScene`：模型显示、拾取、视角、透明度和便捷绘图。
3. `SelectionChainController`：串联、方向、起点、分支和排序。
4. `CoordinateStockService`：坐标系、原点、摆正、毛坯和夹具。
5. `OperationFactory`：按工艺类型创建统一工序模型。
6. `ParameterSchema`：共享参数 + 各工艺专用参数，避免每个窗口复制字段。
7. `ToolMaterialRepository`：刀库、材料、模板和模块规则。
8. `FeatureRecognizer`：孔、破孔、斜面、圆角、倒角边、孤岛识别。
9. `ToolpathEngine`：平面、轮廓、槽、钻孔、螺纹及 3D 路径生成。
10. `OperationTree`：工序启停、排序、编辑、仿真和发送。

这样拆分后，手工工艺和自动孔/智能倒角可共用同一个 `OperationFactory + ParameterSchema + ToolpathEngine`，自动模块只负责“识别并批量创建工序”，不再复制一套加工算法。
