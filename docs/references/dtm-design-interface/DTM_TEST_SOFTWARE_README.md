# DTM 设计界面验证版

这是依据恢复的 `CatDesign` 函数、设计界面功能清单和 UI 重构规格编写的独立 Qt 测试软件。双击 `bin/DTMDesignTest.exe` 即可运行。

## 建议测试步骤

1. 检查顶部是否有“文件&零件、孔类、牙类、铣面、槽类、外形类、斜面&圆角、模块、辅助、发送”十个功能页。
2. 检查中间是否为三维模型区，左侧为串联选择，右侧含属性和工序树。
3. 在“孔类”点击“钻 G81”，然后切到右侧“工序树”，应出现一个待生成工序。
4. 在“模块”点击“自动孔”，右侧工序树应增加 Ø6、Ø8、Ø10 三个测试工序。
5. 点击左侧“确定选择”，应增加一个“铣形”工序，窗口标题区显示工程已修改。
6. 尝试“铣面、槽类、外形类、斜面&圆角”中的加工按钮，确认工序树能追加相应测试工序。

## 当前实现范围

- 已实现：设计页信息架构、Ribbon 功能分组、串联选择面板、三维测试视图、属性面板、工序树、手工工序追加、自动孔批量工序和参数校验模型。
- 使用模拟数据：模型、孔径、工序和刀路状态。
- 尚未接入：STEP/DXF 真实导入、OpenCascade 拾取、真实刀路计算、碰撞检查、仿真和控制器发送。

因此，这一版用于验证“界面结构和操作流程是否还原正确”，不能用于实际加工。你测试后指出哪一处布局、名称或流程不对，我可以按反馈继续迭代。

## 自动测试

`tests/test_acceptance.py` 覆盖：

- 十个 Ribbon 功能分组和四个主布局区域；
- 新建工序后的脏状态与工序树数据；
- 自动孔批量生成；
- 步距大于刀径时的参数拒绝；
- 主窗口 PNG 渲染。

当前结果：5/5 通过。
