# B2-U：槽操作反馈与真实模型覆盖完善

基于B2-M已集成主区，用户要求继续完善。主对话负责审核和最终验收；实现子线程只修正以下已证操作缺陷，不扩展槽算法或模型识别。

## 批准修正

1. 槽编辑的工艺校验在参数窗口关闭后执行，深度超限、刀具/入刀参数不适配等错误导致全部修改丢失。保留同一个编辑会话及输入值，允许纠错再确认；取消零写入，合法确认原ID原位替换一次。模型/Setup/源对象/刀具库变化及并发工序冲突继续终止，不降低校验。优先在槽控制器内实现小范围重试，不扩展通用参数编辑框API。
2. 工序列表把真实槽深标为Z加工深度。分别显示真实槽深和目标加工深度；缺少旧版depth参数时仅回退真实槽深。使用深度语义，避免把相对切深写成绝对Z位置；中英界面保持一致。
3. 取消槽几何重选后仍显示“已选槽”。几何草稿为空时明确提示尚未确认，与主按钮和禁用参数状态保持一致；有选择时保留原真实几何摘要。

限定生产范围：SlotOperationController.cpp、OperationListPanel.cpp、StrategyPanel.cpp。只在需要时扩展现有槽工作流、原位编辑、尺寸持久化及真实MainWindow测试；不更改策略、安全校验、冷却或通信。

## 验证

先建立失败回归，再修正。验证非法编辑保持字段和刀具、纠错只写一次、取消不写入；列表真实/目标深度及保存重开；重选取消提示、按钮、参数启用一致。保留项目变化和源几何失效门禁。

使用现有Qt控件和字体风格，先捕获失败/基线状态，修复后一次集中截图复核（明确是离屏控件渲染，不能冒充真实桌面或3D验收）。截图不得关闭安全校验来取得通过。测试输出放 outputs/slot-b2u，不覆盖B2-M交付。

并行模型探查只对真实既有STEP导入、记录模型SHA及识别出的槽类型/加工面/同组信息，不修改生产识别或伪造模型。已有槽.stp保存结果只有一个正面直槽；WH250852验收模型已有至少4个侧轴槽的断言；真实圆弧和多槽组仍须实际识别证据后才能纳入覆盖。

交付源码diff、前置备份、失败及通过记录、截图与模型摘要。每个子任务8分钟内收束、4分钟汇报，主审核再审代码和运行相关检查。修改沿用已授权主区本地集成，不提交或推送。
