# DTM 工艺规划证据追溯矩阵（2026-08-28）

## 1. 使用规则

- 本矩阵追溯《DTM 工艺规划洁净规格（2026-08-28）》的稳定规范 ID。
- “证据类型”严格使用 `说明书`、`Excel`、`截图`、`反编译入口`、`推断`；复合结论可列多种。
- `反编译入口`只证明入口或职责名称存在，不证明参数语义、算法正确性或安全性。矩阵不记录地址、伪代码、类型布局、局部变量或控制器拼接。
- `推断`不是事实；只有经领域负责人确认或独立黑盒测试后，才能提升为生产规则。
- CNEXT-CAM 头文件、ADR、文档和测试列在“现状校验”栏，只说明当前产品边界，不作为 DTM 原始事实。
- 本次没有可独立核验的原始截图文件，因此没有仅凭 `截图` 得出的结论；界面布局文字仍归 `说明书`。这避免把二手 UI 描述伪装成截图证据。
