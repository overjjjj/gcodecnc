## 一、选择显示状态（最高优先级）

| 状态/动作 | 必须呈现的结果 |
| --- | --- |
| 新进入挖槽/环形铣/铣平面范围选择 | 保留正常模型线，不自动选中候选、不全体高亮、不产生已确认选区 |
| 鼠标靠近可选边 | 单边模式只高亮最近的一条可见候选边；拾取距离按屏幕像素，兼顾缩放和高DPI |
| 鼠标移开边或离开视口 | 清除临时高亮；已选边保持 |
| 单击候选边 | 加入选区，以选中色并加粗持续显示；悬停与选中有明确区别 |
| 鼠标移动到另一边 | 只更新悬停对象，不改变已选集合、不自动扩展串联 |
| 单边模式再次点击已选边 | 取消该边选中；鼠标仍在附近时仅显示悬停效果 |
| 旋转/平移拖动、缩放 | 不误触点选；拖动结束不得补一次点击选中 |
| 取消选择会话 | 撤销本会话草稿，恢复进入前状态；不创建或修改工序 |

空白点击不清空已选集合。重叠候选优先屏幕最近且可见者，避免穿透选中背面边；距离近似相同时保持稳定，防止闪烁。不把业务几何容差改成鼠标像素阈值。

## 二、四种选择方式

1. 单边：点击真实模型边，显示方向箭头；可根据点击位置靠近的端点确定初始方向，提供反向。反向只修改选择意图，不谎称策略已采用尚不支持的刀路方向。
2. 完整串联：进入模式本身不高亮全模型。鼠标命中种子边后只强调该边；点击种子后显示该相连闭环候选，再由“采用此闭环”确认。不能一次默认选择所有环。
3. 实体面：悬停只临时显示当前候选面；点击后保留半透明区域及加粗边界。提取真实外环和内环，不填掉孔洞/孤岛。面与边模式应有清晰标签。
4. 局部串联：选起始边，再选终止边，显示真实相连区间预览，确认后加入；多条路线时让用户选分支，禁止猜测跨环或补直线。一段确认操作可一次撤销。

模式切换撤销未确认的悬停/区间预览，保留仍有效的已确认边链；若不能兼容，明确提示需要重选，不静默改选区。非闭合区域可以作为选择草稿，但不能被当成有效封闭挖槽工序。

## 三、串联面板与操作

常驻“撤销、反向、完成选择”，阶段内只有一个主确认按钮。起始/终止、分支选择等提示应告诉用户下一步点击哪里。边列表与全部模型面列表放在可展开区，不能挤占当前范围及操作提示。

支持上一段、下一段及分支切换；不存在分支时不显示无用分支操作。方向箭头可显示/隐藏。“沿用上次选择”须经模型、拓扑、Setup来源核对，再显式采用。Ctrl+Z在视口有焦点时也能撤销当前选择操作；Esc先取消未确认预览，没有预览时取消当前选择会话。不劫持文本编辑框本身的正常撤销输入。

## 四、加工区域、坐标与参数闭环

目标流程：进入加工功能 → 选择边/串联/面 → 确认范围和加工侧 → 确认Setup及深度 → 刀具/参数 → 刀路预览 → 明确确认工序。

- 内侧、外侧、混合应显示具体加工侧；仅在策略能消费时允许用于生成，不靠改标签放行。
- 环形区域必须保留外环和内环/孤岛，明确显示加工与保留区域。选择层保留真实拓扑；当前刀路不支持的区域应保留选择并明确说明限制，不能矩形化或把岛清除。
- 坐标流程复用现有Setup：选择/建立/编辑/删除、点取原点、X/Z方向、绕Z轴0/90/180/270度、原点显示和命名。存在工序引用时不静默删除或替换；Setup改变应使相关选区确认和旧程序失效。
- 参数按刀具与切削、高度与深度、分层与步距、余量、路径方式分组。明确安全高度、下刀高度、基准面、目标深度的绝对/增量基准。保留输入，错误可在原窗口修正。
- 示例：绝对底面Z=-5且底部余量0.2时目标底面Z=-4.8；侧壁留量在刀具半径偏置基础上计算，禁止二次补偿。
- 双向、单向、环形、一刀过、螺旋铣作为参考能力清单；不新增未经验证的刀路算法，不将参考截图中的参数作为现场默认值。
- 快捷同Z/斜面/圆角筛选必须显式触发并预览后确认；已有功能核对接线，缺失且需要新几何算法的列入未完成能力清单，不能用无效按钮冒充支持。最小筛选值须有对象与单位。
