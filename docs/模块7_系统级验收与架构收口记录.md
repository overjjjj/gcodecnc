## 最终交付、限制与下一期优先级

### 可演示交付

1. 选择孔或已验证二维边界，显示稳定几何引用与 schema 参数来源。
2. 经模板/人工覆盖创建正式工序，编辑参数后刀路自动失效。
3. 重算成功后生成最终 CQ8，并通过安全检查与最终输出仿真。
4. 在工序树启停、排序、更换刀具，再验证最终程序只追溯启用且有效工序。
5. 保存项目并重开，验证工序状态、参数快照、程序和来源追溯保持一致。
6. 自动孔只显示候选草稿，必须人工选择方案并确认后才形成正式工序。

### 明确限制

- G76、外螺纹、多齿换层、切线/圆弧螺纹进刀继续阻断。
- 动态铣、偏心/异形/多孤岛、一般清内角、刻字、空间曲线继续阻断；矩形清内角策略子集的 UI 仍禁用。
- 3D 斜面、圆角、3D 倒角和智能倒角刀路缺可靠 STEP 修剪/偏置基础，继续阻断。
- 自动框保持实验禁用；特征孔/自动孔只覆盖可审计的可靠子集。
- 七孤岛侧面型腔必须先建立工序级专用 Setup，当前不得生成。

### 下一期优先级

1. 建立工序级专用 Setup/坐标变换模型，先解除侧面型腔基线阻断。
2. 补齐几何、刀具资料与前序工序的显式依赖图和定向失效合同。
3. 在真实 STEP 修剪面、法向、半径和偏置可验证后，再推进 3D 曲面工艺。
4. 在连续绕行和残料模型有仿真证据后，再评估动态铣、清内角和自动框。
