## 当前操作闭环

确认模型、加工面、原点及毛坯 → 选择已识别槽并人工确认几何 → 配置刀具及目标深度 → 整批校验并加入工序 → 生成最终控制器代码 → 解析最终文本预览。编辑保留工序ID；参数错误可在同会话修正，模型/Setup变化必须重新打开；修改使旧程序失效，失效程序禁止导出或发送。

手册的挖槽、环形铣、孤岛和动态铣不能等同为当前三类槽策略已经全部实现。未验收能力仍按各阶段边界限制，不据此扩大加工范围。

## 本地验证入口

使用Windows PowerShell 5.1、Qt5.14.2 MinGW kit、MinGW7.3及项目配置的OCC运行库。先按项目qmake配置完成独立Debug构建，然后将其绝对目录传给测试入口：

```powershell
& ./untitled/scripts/run_tests.ps1 -BuildDir 'D:\your-build-directory' -TestNames @(
  'slot_workflow_ui_test', 'slot_dimensions_persistence_test',
  'slot_operation_edit_test', 'slot_b2v_startup_test',
  'slot_output_gate_mainwindow_test'
)
& ./untitled/tests/build_pipeline_test.ps1
```

工具链目录不同可通过QtDir、MinGwDir、OccPrefix参数指定；OCC与主窗口测试需要对应运行库。`build_and_test.ps1` 接受BuildDir并转发同一目录，但本次没有宣称它的全仓测试一条龙全部通过。

测试与离屏截图是软件证据，不能替代机床、夹具、刀具和控制器上的实际验证。最新已知限制见B2-U结论。
