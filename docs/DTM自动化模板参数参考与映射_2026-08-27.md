# DTM 自动化模板参数参考与映射（2026-08-27）

## 范围与来源

本文将以下五份 DTM Excel 的已提取内容固化为离线需求参考，不复制、提交或运行原始 `.xlsx`：

| 文件 | 工作表/结构 | 用途 |
| --- | --- | --- |
| `孔自动化模板.xlsx` | 刀库参数、孔工艺匹配、最多 11 个工序槽 | 圆柱孔、圆锥/沉头孔、密封槽候选规则。 |
| `框自动化模板.xlsx` | 框匹配条件、最多 8 个加工步骤 | 直身/斜面、开放/封闭、接底/通框等槽框候选规则。 |
| `深孔钻模板.xlsx` | 材料+刀具直径档位、正常/引导/慢速/破孔/回退/过渡/啄钻阶段 | 深孔钻受限阶段参数参考。 |
| `吊环孔工艺.xlsx` | 公制、英制、美制规格与孔工艺字段 | 旧版吊环孔规格参考。 |
| `吊环孔工艺2.xlsx` | 旧版字段加 XY 分层粗精字段 | 吊环孔规格和二维粗精分层参考。 |

所有表中“表达式”均为业务字符串；没有发现 Excel 公式。本项目不把单元格文本当作脚本、命令或可执行公式。

## 规范化参数字典

### 1. 孔自动化模板

| 字段 | 类型/单位 | 必填 | 建议默认或范围 | 安全校验 |
| --- | --- | --- | --- | --- |
| 刀名称、最小/最大直径 | string、mm | 是 | `min > 0`、`max >= min` | 所选刀具存在，目标层直径落入档位。 |
| 下刀速度、切削速度、抬刀速度 | number，mm/min | 是 | `> 0`，受机床上限约束 | 进给必须为正且与刀具/策略兼容。 |
| 主轴转速 | number，r/min | 是 | `> 0`，受机床和刀具上限约束 | 不能超过刀具/机床额定转速。 |
| 单次深度、深度步距 | number，mm | 是 | `> 0`，不超过有效刃长 | 不得越过盲孔底或层边界。 |
| 切削步距百分比 | number，% | 否 | `(0, 100]` | 由策略换算为实际步距后验证刀具中心包络。 |
| 精铣量 | number，mm | 否 | `>= 0` | 不得使剩余材料为负。 |
| 工艺、类型、孔类别 | enum | 是 | 圆柱/圆锥/密封槽 | 未识别或不支持类别只能产生拒绝原因。 |
| 各层直径区间 | list of range，mm | 是 | 每层 `min > 0` | 层序连续、同轴、无重叠，匹配稳定 `GeometryRef`。 |
| 工艺步骤（最多 11） | ordered list | 是 | 至少一个步骤 | 每步均须通过确认前的完整校验。 |
| 加工方式/刀具表达式/起点/深度 | strategy id、受限表达式、mm | 是 | `Hn`、`Dn`、`Tn`、`AT` 及四则运算 | 禁止未知变量、除零、负深度、层越界和缺失刀具。 |
| 冷却/切削液 | enum | 否 | 保留原值 | 当前仅兼容保存，不改变任何冷却行为。 |

### 2. 框自动化模板

| 字段 | 类型/单位 | 必填 | 建议默认或范围 | 安全校验 |
| --- | --- | --- | --- | --- |
| 工艺名称、框类别 | string、enum | 是 | 直身/斜面/开放/封闭/接底/通框/密封槽 | 仅映射至已验证的正面 Z 向平底直壁安全子集。 |
| 槽宽、框大小 | number/range，mm | 是 | `> 0` | 刀具直径、余量和双侧间隙必须可达。 |
| 通框加深、接底 R、R/BK 角 | number，mm/deg | 否 | `>= 0` | 不得凭模板开放斜面、R 角或三维路径。 |
| 工艺步骤（最多 8） | ordered list | 是 | 开粗、中粗、粗清角、光底、清角、精轮廓、倒角 | 每一步只能选择已验证策略；失败时原子拒绝全部工序。 |
| 加工方式、加工刀具 | strategy id、tool selector | 是 | 白名单策略/刀具选择器 | 刀具存在、类型、直径、刃长、总长均需校验。 |
| 是否插角、参考刀具 | bool、tool selector | 否 | 默认 `false` | 插角当前未开放，出现时必须拒绝候选确认。 |
| 加工起点、加工深度 | expression、mm | 是 | 深度 `> 0` | 安全高度、参考面、深度、stepOver、stepDown 必须有效。 |
| 冷却 | enum | 否 | 保留原值 | 当前不改变冷却行为。 |

### 3. 深孔钻模板

| 字段组 | 类型/单位 | 必填 | 建议默认或范围 | 安全校验 |
| --- | --- | --- | --- | --- |
| 主键：材料名称、刀名称、直径范围 | string、range mm | 是 | 直径范围有效 | 匹配仅产生候选；刀具与材料资料需明确存在。 |
| 正常：转速、进给、冷却 | r/min、mm/min、enum | 是 | 转速/进给 `> 0` | 不超机床/刀具范围；冷却保持兼容字段。 |
| 引导：起止位置、转速、进给、冷却 | mm、r/min、mm/min、enum | 否 | `start >= 0`、`end > start` | 区间位于确认孔深内。 |
| 慢速进刀/破孔减速 | 起止 mm、百分比 | 否 | 百分比 `(0, 100]` | 不得产生零/负转速或进给，破孔位置必须可证明。 |
| 回退 | 转速、进给、方向、冷却 | 否 | 转速/进给 `> 0` | 仅在后处理明确支持时使用；否则拒绝。 |
| 过渡 | 最小快移距离（刀径 %）、快移进给 | 否 | 距离 `>= 0`、进给 `> 0` | 快移仍须在安全高度；不允许跨孔低位 G0。 |
| 啄钻 | 最大/最小分段、变化值，mm | 是 | 均 `> 0`，`max >= min` | 每段不越盲孔底，Q 深度合法。 |
| 无极变速 | 最小距离、加减速步距，mm | 否 | 均 `> 0` | 当前后处理无可验证阶段算法时不开放。 |

冷却枚举 `0无、1外、2内、3吹气、4内外` 只作为未来资料枚举参考；本轮不改变冷却输出或逻辑。

### 4. 吊环孔工艺与工艺2

| 字段 | 类型/单位 | 必填 | 建议默认或范围 | 安全校验 |
| --- | --- | --- | --- | --- |
| 标准/规格、制式 | string、enum | 是 | 公制/英制/美制 | 规格键唯一，制式不得混用。 |
| 底孔、螺距、螺纹直径 | mm | 是 | 全部 `> 0` | 底孔、丝攻/铣牙刀直径与螺距一致。 |
| 钻孔/大牙钻/铣孔刀与深度 | tool selector、mm | 是 | 深度 `> 0` | 工具、刃长、总长、盲孔底、贯穿余量均合法。 |
| 铣孔直径、沉头/倒角刀与尺寸 | mm、tool selector | 否 | 直径/深度 `> 0` | 几何边界、刀具包络和倒角深度须可验证。 |
| 丝攻或铣牙刀、使用螺距 | tool selector、mm | 是 | 螺距 `> 0` | 仅已支持的攻丝/受限内螺纹铣允许确认。 |
| 开启 XY 分层 | bool | 否 | 默认 `false` | 当前仅作为未来二维口袋子集资料，不自动开放路径。 |
| 粗/精铣次数和量 | integer、mm | 否 | 次数 `>= 0`、量 `>= 0` | 不能替代刀具中心包络、stepOver/stepDown 校验。 |

## DTM 字段到现有模型映射

| DTM 原字段 | 现有 C++ 模型 | 状态 | 说明 |
| --- | --- | --- | --- |
| 模板名称/版本 | `ProcessTemplateDefinition::{name,version}`、`MachiningPlanDefinition::{name,version}` | 已支持 | 已持久化模板引用和版本。 |
| 模板参数值 | `ProcessTemplateDefinition::values` | 已支持 | 可走既有参数来源和人工覆盖。 |
| 工艺匹配/孔类别 | `MachiningPlanDefinition::shape`、`AutoHoleShape` | 部分支持 | 仅 `Any/Single/Counterbore/Countersink`，未表达密封槽和层直径条件。 |
| 加工方式 | `MachiningPlanStepDefinition::strategyId` | 已支持 | 策略仍受安全白名单和生成校验约束。 |
| 加工刀具/刀具表达式 | `toolId`、`toolExpression` | 部分支持 | 支持受限数值表达式；尚无材料+刀具类型+直径档位资料匹配。 |
| 加工起点/深度 | `startExpression`、`depthExpression`、`layerIndex` | 已支持 | `Hn/Dn/Tn/AT` 与四则运算受限解析。 |
| 工序序列 | `MachiningPlanDefinition::steps` | 已支持 | 现有计划可多步；模板最大槽数尚未作为显式限制。 |
| 沉头处理 | `countersinkStep`、`cancelCountersink` | 已支持 | 确认前可取消外层沉头步骤。 |
| 人工覆盖/重识别 | `AutoHoleCandidate::{manualOverrides,manuallyEdited,state}` | 已支持 | 保留人工覆盖并标记冲突/过期。 |
| 框类别/开闭/自由端 | `SlotFrameFeature::{kind,closed,freeEdges,complementType}` | 部分支持 | 有安全识别候选，尚无规则表匹配和多步骤计划。 |
| 框大小、槽宽、R/BK、通框加深 | `SlotFrameFeature` 几何及 `OperationParameterLayers` | 部分支持 | 可验证尺寸/深度；无完整规则字段模型。 |
| 参考刀具、插角 | 无等价字段 | 未支持 | 插角必须保持禁用。 |
| 深孔阶段参数 | `HighSpeedPeckDrillingStrategy` 的现有参数 | 部分支持 | 未形成版本化阶段资料表或后处理阶段合同。 |
| 吊环孔规格/XY 分层 | 无等价规格表 | 未支持 | 只能作为未来规则资料，不能自动生成路径。 |
| 每步骤冷却 | 无计划步骤语义字段 | 未支持 | 不新增行为；只保留未来兼容方向。 |

## 推荐模型边界

1. **刀具切削参数表：** 版本化 `ToolCuttingParameterSet`，键为材料、刀具类型/名称、直径区间；存放转速、进给、进退刀和步距建议，不直接写入已确认工序。
2. **特征匹配规则：** 版本化 `FeatureMatchingRule`，只表达孔层、框类别、尺寸区间和几何前提；输出 `Operation Proposal` 或拒绝原因，不创建工序。
3. **工艺步骤：** 版本化 `MachiningPlanStep`，使用策略白名单、受限刀具/几何表达式、可选参考刀具和显式禁用标志；人工确认后由 `OperationFactory` 原子落盘。
4. **深孔阶段参数：** 独立 `DeepHoleStageParameters`，表达可验证阶段区间和百分比，不把控制器专用循环文本放入规则层。
5. **螺纹规格表：** 版本化 `ThreadSpecification`，区分制式、底孔、螺距、螺纹直径和候选刀具；不自动突破现有攻丝/受限内螺纹铣边界。

策略只将已确认的规范化参数生成 controller-neutral `Toolpath Result`；后处理器才决定 Fanuc/CQ8/Siemens 输出，仿真只读取最终后处理代码。

## 离线参考与未来导入约束

- Excel 仅为离线参考，当前没有运行时 Excel 导入器。
- 未来导入必须先转换为版本化 JSON，再经 schema 白名单解析、类型/单位/范围校验和人工确认；禁止执行 Excel 公式、宏、脚本、命令或动态求值。
- 业务表达式只能进入 `RestrictedFormulaEvaluator` 的受限语法；未知变量、除零、越界深度、层越界、缺刀具均须拒绝。
- 修改资料库不能静默回写已确认 `MachiningOperation`；工序只保存确认时的模板快照和来源。

## 持续安全边界

- 自动识别只能产生候选，必须人工确认后经 `OperationFactory` 原子创建正式工序。
- 插角、动态铣、三维加工、不可验证的偏置/曲面能力不会因为模板字段存在而开放。
- 冷却字段仅作为兼容参考；当前不修改冷却代码或行为。
