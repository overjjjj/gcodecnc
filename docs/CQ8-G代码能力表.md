## 2. 已确认原则

1. CQ8 拥有自己的版本化 G 代码方言和解释器能力表。
2. 语法尽量符合现场操作员熟悉的 ISO/Fanuc 使用习惯，但不宣称与任一外部控制器完全兼容。
3. CNEXT-CAM 以 CQ8 为主后处理目标；Siemens 和 Fanuc 仅作为可选兼容、导出或回归目标。
4. CQ8 负责 G 代码解释、模态状态、轨迹规划和实时执行。
5. CNC_SYSTEM 负责程序接收、检查、完整下载或流式下发以及执行状态展示。
6. CNEXT-CAM 的仿真和执行预览必须以最终 CQ8 目标代码为权威来源。
7. 首期只生成绝对编程 `G90`；`G91` 输入和执行支持在全链路验证前保持禁用。
8. 不支持或不明确的指令必须明确拒绝，不能静默忽略后继续加工。
9. 程序头尾、G80 等安全复位代码和机床专用 M 代码通过受控 Machine Profile 模板配置并记录版本。
10. 重复加工逻辑允许使用固定循环和函数化子程序，执行预览必须能够确定性展开。
11. 首期只支持毫米单位 `G21`；`G20` 英制程序不得生成、加载或执行，也不得自动进行隐式单位换算。
12. CQ8 首期接受 I/J/K 圆心偏移和 R 半径两种圆弧格式，CNEXT-CAM 统一生成 I/J/K；整圆只允许 I/J/K，圆弧几何超过容差时拒绝执行。

推荐默认安全起始语义：

```gcode

```

具体排布和附加代码由 Machine Profile 模板确定。模板变化会使旧程序安全快照失效并要求重新校验。

## 6. 运动指令

| 指令/能力 | 状态 | 首期要求 |
|---|---|---|
| `G00` 快速移动 | 已确认 | 低位横移、越界和未退刀跨特征必须阻断 |
| `G01` 直线插补 | 已确认 | 切削移动受特征边界和深度校验 |
| `G02/G03` 圆弧插补 | 已确认 | CQ8 接受 I/J/K 和 R，CNEXT-CAM 只生成 I/J/K；整圆仅允许 I/J/K |
| 螺旋插补 | 已确认 | 用于圆插补铣孔和受控螺旋进刀 |
| 样条/NURBS | 后续阶段 | 首期拒绝 |
| 四五轴联动 | 后续阶段 | 首期拒绝 |
| RTCP | 不支持（首期） | 不生成、不执行 |
| 高速前瞻 | 待详细定义 | 属于 CQ8 轨迹规划能力，需台架性能验收 |

运动安全约束：

- XY 快移前必须位于安全高度或满足受控安全平面；
- 跨特征移动前必须退刀；
- `G01/G02/G03` 默认视为切削移动，除非明确属于验证过的引入、引出或退刀；
- 刀路显示、执行预览和安全校验均解析最终 CQ8 G 代码；
- 圆弧的平面、方向、圆心符号、半径和终点误差必须一致。

圆弧格式规则：

- I/J/K 表示相对圆弧起点的圆心偏移，并根据 `G17/G18/G19` 使用对应轴；
- `R > 0` 表示小于或等于 180° 的圆弧，`R < 0` 表示大于 180° 的圆弧；
- `R` 格式不得用于整圆；
- 同一程序块不得同时提供 I/J/K 和 R；
- CQ8 将两种输入规范化为同一内部圆弧对象后再进入轨迹规划；
- 起点、终点、圆心和半径不能在配置容差内闭合时，程序预检失败。

循环共同要求：

- 明确定义 `X/Y/Z/R/Q/P/F` 等参数的单位、默认值和允许范围；

- 盲孔不得超过确认深度；
- 深孔循环校验 `R`、`Q`、最终深度、退刀和安全高度；
- 循环展开结果必须进入仿真、执行预览、流式计量和断点恢复模型；
- `G80` 后不得残留循环模态。

## 11. 解析与错误处理

CQ8 解释器必须：

- 对未知 G/M 代码、非法参数、重复冲突模态和越界值明确报错；
- 报告程序块号、源行号、错误码和可读原因；
- 禁止把未知代码当作注释或空操作继续执行；
- 在启动前完成能够离线完成的语法和能力检查；
- 流式执行时保证未校验程序块不能进入轨迹规划；
- 对重复传输分块保持幂等，不重复执行；
- 将固定循环和子程序的执行位置映射回源程序块和 OperationId；
- 为安全暂停生成 CQ8 认可的恢复点，禁止 PC 从任意源行强制恢复。

## 12. 能力协商

CNC_SYSTEM 与 CQ8 建立连接后，CQ8 应返回：

- 控制器型号和固件版本；
- G 代码方言主/次版本；
- 支持的 G/M 代码及能力位；
- 固定循环和子程序能力；
- 最大程序块长度、最大子程序嵌套和数值精度；
- 支持的轴数、平面、坐标系和补偿能力；
- 当前机床配置包版本和 Machine Profile 哈希。

Job Package 所需能力超过 CQ8 实际能力时，CNC_SYSTEM 必须在 TASK_CREATE 前拒绝任务。
