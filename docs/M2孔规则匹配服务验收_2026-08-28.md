# M2 孔规则匹配服务验收（2026-08-28）

## 范围

本批实现 `AutoHoleRuleMatchingService` 及独立输入/输出 DTO。服务只读取
`AutomationTemplateDocument` 中已版本化的 `FeatureMatchingRule.holeRule` 与
`AutomationMachiningPlanStep.holePlanStep` 扩展，输出 `Draft`、`Conflict` 或
`Rejected` 及结构化解释；没有调用 `AutoHolePlanningService`、`OperationFactory`、
UI、策略、后处理、仿真或控制器。

为保持 M0 JSON v1 向后兼容，新增字段均为可选嵌套扩展。缺扩展的旧通用规则
仍可解析，但没有 M2 资格，不能被匹配器当作孔规划规则。

## 已冻结的匹配边界

- 请求带显式 `asOfDate` 和材料、机床、刀具、规则资料的 ID/catalog/version；
  缺失或规则资料版本与文档不一致时以 `CATALOG_VERSION_MISSING` 拒绝，不读取
  “当前最新”。
- 仅支持已确认 Front +Z 孔；层序从 1 连续，直径有限正值、平面形成正深度，
  非最深层不得标记贯穿。相邻层必须精确共享平面；不引入任何识别或制造容差，
  因而断层和重叠都以 `LAYER_SEQUENCE_INVALID` 拒绝。
- `geometryRevision`、`setupRef`、类别和每层 `sourceToleranceRef` 都是运行前
  必填项；分别复用既有最小错误码而非新造默认。上游 `rejectionEvidence` 非空时
  原文保留在 `GEOMETRY_UNSUPPORTED` 理由中并停止，不尝试修复几何。
- 规则目录的 `id`、`catalogId`、`catalogVersion` 都与当前 M0 文档身份精确核对；
  任一不符即 `CATALOG_VERSION_MISSING`，不会仅检查非空或忽略 `id`。
- 每条 M2 规则含显式版本、生效闭区间、整数优先级、材料/机床精确集合、类别、
  有序逐层种类和显式开闭直径区间、计划 ID/版本和步骤引用。
- 选择顺序固定为资格过滤、最大显式优先级、唯一 `Draft` 或同最高优先级
  `Conflict/RULE_AMBIGUOUS`。不会按文件顺序、名称或评分器静默选第一条。
- 计划只接受 1–11 个规范化步骤；`sourceSlot=1..11`、连续 `sequence`、
  存在的 `layerOrdinal` 和唯一源槽均严格验证。
- 任一 `Hn`/`AT` 表达式直接返回
  `SEMANTIC_VARIABLE_UNCONFIRMED`；没有把它们推测为层深、余量或默认值。
  通用 `startExpression` 也没有已批准的“绝对平面/相对深度/有符号坐标”结果
  语义。故只有表达式结果为 `0` 且目标层入口平面也精确为 `0` 的同值退化情况
  可证明安全；其他起点一律 `FORMULA_REJECTED`，不猜其解释。`depthExpression`
  仍以 `RestrictedFormulaEvaluator` 只读验证并检查越层深度。
- `coolantCompat` 仅作为步骤快照原样返回，未用于排序或冷却执行。

`HoleRuleMatchReason` 提供稳定错误码、字段路径和说明；解释保留考虑规则、
过滤规则/理由、顶级规则及逐层命中。无匹配也保留已收集的过滤解释。

## TDD 与覆盖

1. M0 规则 JSON 扩展测试先因未知 `holeRule` 字段失败；实现后 round-trip 与
   缺 `effectiveFrom` 拒绝通过。
2. M0 规范化步骤 JSON 测试先因未知 `holePlanStep` 失败；实现后 round-trip 与
   缺 `sourceSlot` 拒绝通过。
3. M2 服务测试先因头文件不存在失败；实现后覆盖下/上端开闭、生效日期闭区间、
   材料资格、逐层匹配、优先级胜出、同优先级冲突、步骤规范化、`Hn/AT`、深度
   越界、Front +Z 安全门、冷却兼容快照和只读输入。
4. 过滤解释测试先因 DTO 不存在失败；实现后验证非生效规则保持
   `RULE_NOT_EFFECTIVE` 与 `featureMatchingRules[0].holeRule` 路径。
5. 第二轮安全缺口测试先失败于缺失 `setupRef` 未拒绝；实现后覆盖缺少
   `geometryRevision`、类别、`sourceToleranceRef`、上游拒绝证据、层断层/重叠、
   规则目录 ID 和未证明安全的起点表达式。成功路径的二次 `ValidatePlan` 现在
   检查返回值；即使其前次验证已通过，也不会静默忽略后续失败。

## 明确阻断与未实现项

- 重识别状态迁移、人工覆盖保留、取消沉头和 `Stale` 需要与既有候选持久化模型
  的独立适配；本批没有猜测或修改该边界。
- 真实刀具选择器解析及 M1 刀具参数匹配的请求映射尚无已冻结的 selector→刀具
  快照合同，因此 M2-BB-015/016、029/030 保持阻断；服务不从名称或全局刀库猜刀。
- 三个原子确认合同（M2-BB-ATOMIC-001..003）不实现：当前服务未引用
  `OperationFactory`，故匹配阶段正式工序数结构上恒为零。确认适配器须在现有
  仓储事务边界获明确合同后另起 TDD 批次。
- `Hn/AT` 业务语义、生产容差、材料别名、单位换算、插值/外推仍未确认，继续
  拒绝或不提供行为。
