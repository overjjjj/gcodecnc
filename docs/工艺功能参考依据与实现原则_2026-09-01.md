# 工艺功能参考依据与实现原则（2026-09-01）

## 1. 目的与总原则

本文冻结第七章工艺功能的证据优先级和逐功能落地口径。以《加工中心控制系统用户使用手册》第七章为主，以用户提供的目标软件截图补充实际界面与状态，以已确认需求文档和当前代码/测试确认完成度；Mastercam 官方公开资料只辅助简化流程和用户心智。

本文不替代安全校验、自动化测试、业务确认或机床试切。自动识别与推荐只能产生候选；冷却行为冻结；正式工序只能在人工确认后经 `OperationFactory` 创建。

## 2. 证据层级与冲突处理

| 层级 | 证据 | 可决定内容 | 不可决定内容 |
| --- | --- | --- | --- |
| A（最高） | 说明书第七章明确功能、参数、状态、行为。 | 功能目的、入口、步骤、明确字段/选项和状态。 | 未说明的单位、默认值、算法、容差、控制器/机床语义。 |
| B | 用户目标软件截图。 | 可见入口、控件、选项、示例选择状态、页面组织。 | 图标精确名称、隐藏逻辑、算法、单位、默认值、工艺安全语义。 |
| C | 已确认需求文档、当前代码和自动化测试。 | 当前完成/半成品/未完成/阻断事实和回归边界。 | 改写说明书需求或把当前缺失解释为需求不存在。 |
| D | Mastercam 官方公开资料。 | 少步骤流程、用户心智、工序树、预览/仿真分层。 | 我方工艺语义、参数、刀路算法、控制器、兼容性或等价结论。 |
| E（最低） | 反编译/源码整理材料。 | clean-room 的行为存在性、入口/参数线索和待验证假设。 | 复制实现、伪代码、类型布局、私有数据或算法。 |

1. A 与任何其他层冲突时按 A；B 只能补充某版本的界面状态，不能推翻 A。
2. A 未说明时，B 只形成界面待确认项，C 只形成当前能力事实；不得用 D 猜测工艺语义。
3. 单位、精度、比较方向、默认值、容差、深孔参考面、控制器能力、刀路或安全含义缺少 A 证据时，必须标记 **待确认/阻断**，先写失败测试再实现。
4. D 只能改变“如何更少步骤、更易解释地呈现已确认能力”，不能改变“加工什么、用什么参数、何时可生成工序”。
5. E 只允许转写为无实现细节的 clean-room 合同；与 A–D 不一致时不作为实现依据。

## 3. 逐功能落地模板

每个功能（包括 7.4 公共选择项）必须填完下表；缺项不能宣称完成：

| 字段 | 必填内容 |
| --- | --- |
| 说明书编号 | 第七章章节/条目；精确编号未知时标“编号待确认”，不得编造。 |
| 功能目的 | A 层明确的用户任务和加工/选择目标。 |
| 入口与操作步骤 | A 为主、B 补充的入口、选择、确认/取消步骤。 |
| 输入参数 | 名称、类型、单位、范围、默认值及证据来源；未知项明确待确认。 |
| 选择状态 / 错误状态 | 会话、撤销、拒绝、过期、冲突和触发条件。 |
| 输出 DTO | `RecognizedFeature`、`RuleMatch`、`OperationProposal` 或明确拒绝；不能直接是正式工序。 |
| 服务 / 刀路边界 | 允许服务、确认边界、策略和后处理边界。 |
| 预览 / 仿真 | 路径预览、材料/碰撞验证、最终代码/机床仿真的输入和结论。 |
| 黑盒验收 | 正常、边界、保存重开/失效、最终代码安全和仿真证据。 |
| 当前状态 | 完成 / 半成品 / 未完成 / 阻断，并附 C 层证据。 |

## 4. 固定优先级

| 优先级 | 模块 | 当前范围 | 后续但不抢占本批 |
| --- | --- | --- |
| P0 | 孔 | 识别、规则匹配、人工覆盖、工艺链确认、刀路预览。 | 螺纹/牙类、未确认深孔、`Hn/AT`、侧孔/斜轴。 |
| P1 | 2D 平底型腔 | 7.4 公共选择、边界/岛、铣内外/混合候选、深度/层切/余量、进退刀、预览。 | 动态铣、一般斜面/圆角、曲面底、凹多解偏置、侧面/多轴。 |
| P2 | 简单槽 | 开/闭槽、中心线/边界选择、宽深、分层、进退刀、预览。 | T 槽、燕尾、复杂曲线槽、侧面/背面。 |
| 后续 | 螺纹/牙类、倒角、刻字 | 只维护现有安全子集/阻断记录。 | 不抢占 P0–P2 容量。 |

公共链固定为：`RecognizedFeature → OperationProposal/RuleMatch → 参数/刀具快照 → 人工确认 → OperationFactory → Strategy → PostProcessor → GCodeSafetyValidator → final-code Simulation`。

## 5. 7.4 截图证据处置

7.4 截图完整覆盖：快捷选择（铣斜面、铣圆角、最小值、同 Z 平面）；实体/线框/毛坯；铣内/铣外/混合；坐标系默认/删除/编辑/新建和 0/90/180/270、原点/X/Z 方向；边缘/串联/实体面/局部串联；上次/撤销/结束串联/显示箭头；分支上一个/调整/下一个；动态起点/反向；排序；确认/取消。

“最小值”、排序容差、图标模式名称/算法、混合方向分类、3+1/3+2 语义、开放槽自由端/补线持久化格式均没有足以决定单位或精确定义的 A 层证据；它们只可保留草稿/候选或阻断，不得进入刀路或正式工序。逐项 DTO、状态、拒绝和验收见 `docs/7_4铣平面选择与型腔槽公共交互需求_2026-08-31.md`。

## 6. Mastercam 辅助规则

Mastercam 公开资料只用于“少步骤、统一结构、可解释推荐、可视化提示和三层验证”的体验研究。它不提供我方说明书功能名、参数定义、默认值、单位、刀路、控制器或安全规则。工序树可参考状态、顺序、复制、编辑和重生成的用户心智，但正式工序仍须人工确认与 `OperationFactory`。

路径预览、材料/碰撞验证、机床/最终代码仿真必须分别显示，任一层的通过都不能替代下一层。完整映射见 `docs/Mastercam简化操作参考方案_2026-08-31.md`。
