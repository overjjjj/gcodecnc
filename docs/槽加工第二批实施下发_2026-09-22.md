# 槽加工第二批实施下发

授权：用户在第一批审核通过后明确“好的继续”。本批由现有实现任务执行，审核主对话仅下发和验收，不修改业务代码、不合并。基线是独立工作树8279内已经审核通过的第一批结果，不重新从主工作区覆盖源码。

## 目标与边界

依据手册7.4、7.5.1、7.11，完成现有三类槽的“选择几何→编辑参数→明确确认→工序→修改→重算→保存重开”闭环。沿用现有Qt Widgets风格和参数窗口，聚焦操作正确性，不做视觉重设计。缺少PRODUCT.md不阻碍这个已由手册和本方案确定的局部调整，不另行访谈或引入产品初始化工作。

本批仍使用已经识别的槽候选，不实现任意模型边/面拾取或分支串联，不扩展环岛、动态铣、控制器刀补及斜底算法。第一批所有门禁保留。

## B2-A：先几何后参数

1. 三类槽未确认几何时，主动作显示“选择槽几何”；槽参数编辑和最终加入动作不能绕过几何阶段。选择特征只更新候选，不自动弹窗。
2. 明确选择后打开第一批限制版SelectionChainDialog，每个槽保留独立feature与selectionEvidence。全部成功才进入参数阶段；任一取消/失败不新增工序、不保留半批可执行草稿。
3. 几何完成后显示已选槽数量/尺寸摘要，允许选择刀具、修改加工参数，提供“重新选择几何”及“确认并加入工序”。参数弹窗确定只更新草稿；最后明确确认才创建正式工序。
4. 本批槽几何长宽、位置、角度及完整识别深度作为只读几何摘要，不在加工参数编辑器中自由改写它们。加工目标深度可在既有合法范围内修改（正深度且不超过真实深度），不得因此把真实几何深度重写为目标深度。短期重选指重新确认当前已识别候选，不冒充任意边串联。
5. 重新选择先废弃旧草稿证据；取消后回到待选择状态。模型/source、Setup/加工面/WCS、策略、选中特征或勾选槽组变化使草稿失效；刀具/切削参数变化重新校验兼容性，不伪造几何证据。界面刷新、语言切换也不得重新解锁失效状态。
6. 最终确认消费同一份已选批次快照，复核当前source/setup/WCS及选择成员，没有“按最近中心重找槽”或重新读勾选列表偷偷换对象的路径。继续经过人工确认、Setup/槽约束与整批最终几何预生成，一次提交；非槽流程保持。

接入锚点（实现前核对当前行号）：StrategyPanel::onConfirmOperation 1021、onEditHoleParams 1069、updateProposalState 1014及retranslateUi；MainWindow轮廓提案4159、批次4260、选择4330、提交4470。checkedFeaturesChanged必须纳入失效链。

## B2-B：编辑已有槽工序

1. 工序列表新增“编辑参数”，仅对单个已选槽启用；从原工序读取当前参数、工具引用及最终几何，不从当前侧栏选中特征覆盖它。窗口标题应明确正在编辑的工序。
2. 使用局部副本编辑，取消、参数非法、工具失配、策略预生成失败或源版本失效时不修改原工序、列表顺序、项目modified状态或原快照。不得先删除再追加。
3. 明确确认后复核原ID仍存在及原内容未被其他操作更改，按ID原位原子替换一次；保留ID、启用状态、所在索引及无关工序。必要的阶段/描述随实际参数更新，不留下旧尺寸描述。
4. 提供“重新选择几何”：针对该工序原始对象重新建立当前版本的选择证据，不读取侧栏另一个槽。源对象无法可靠定位则明确要求重新创建，不猜最近槽。取消重选不写原工序；旧证据已失效时不能靠取消重选恢复可确认状态。
5. 复用现有参数对话框和operationsEdited→ProjectManager::setOperations链，不做工序状态系统重构。编辑预验证独立于现有重算写回，防止编辑失败把原工序标Error。
6. 成功变更后旧程序因真实工序指纹变化过期，禁止导出/发送，重新生成后才能恢复。不得重写旧快照指纹让旧代码假装新鲜。完全无变化的确认作为无操作，不触发无意义修改。重算使用最终feature及规范化加工参数，不能使用残留slotLength/slotWidth/angle覆盖几何。
7. 保存重开后保留编辑结果、ID、顺序、启用状态、最终几何和选择证据；不自动迁移无关历史工序。

接入锚点：OperationListPanel现有addConfirmedOperations只能追加；增加原位替换边界。MainWindow:3623写回链、:4598重算链；ProjectManager::setOperations:116；ProgramSnapshotFingerprint:124与ProgramSnapshotStatus:136。若复用MillingBatchCommit，提交失败/空ID不得报告成功。

## 必要验证

- 真实槽草稿状态：选择前不能编辑/提交；选择后可编辑；参数取消不提交；批量第二项取消零新增；换槽/勾选组/Setup/WCS/模型/策略后旧草稿不可确认；语言刷新不能绕门禁。
- 创建完成只新增一次；每个批次成员的几何证据与最终程序对象一致，不复制首槽证据。
- 编辑取消、非法参数和预生成失败：原工序与项目状态不变；成功原位更新一次，ID/顺序/enabled保留，其他工序不变；不存在ID和并发失效明确失败。
- 编辑后的旧程序Changed且输出受阻；新程序使用新进给/目标深度并可形成Fresh快照。修改目标深度不能修改真实槽几何深度。
- 保存重开并重算，编辑值与尺寸、证据一致。保持第一批槽安全/尺寸/选择回归和其他轮廓行为。
- 补第一批部分深度证据：真实槽深4、目标深2、非对称斜壁、旋转45°/90°，螺旋与斜插的最终包络按真实深度比例核验，并证明不会加工到-4。仅增测试；如暴露算法问题先报告再作本范围内最小修复。
- 此次涉及真实交互，需运行实际信号链/UI流程验证并记录步骤和结果；仅字符串接线检查不能代替行为测试。条件允许时以真实模型启动应用演示创建/取消/编辑/重算；不能完成的GUI部分明确列为未验收。

参数未变却重算失败时旧程序状态门属于已识别的独立风险；如新流程实际依赖此门禁，需先补失败用例并做最小修复，不能仅markStale后声称快照已失效。无关的全局状态改造不纳入本批。
