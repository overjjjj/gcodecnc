# 自动孔多层与沉头孔算法验收记录

日期：2026-08-25
范围：仅正面、Z 向、可验证同轴圆柱/圆锥复合孔；未修改冷却代码或行为。

## 状态

| 功能 | 状态 | 证据与限制 |
|---|---|---|
| 单层盲孔 | 已完成 | 现有自动孔链和 `auto_hole_planning_service_test` 继续覆盖；确认后才创建工序。 |
| 两层同轴台阶孔 | 已完成（安全子集） | `CompoundHoleFeature` 的连续圆柱层经 `ConfirmCompound` 原子创建有序 `hole_peck` 链；测试验证外层 2 mm、内层 14 mm。 |
| 锥形沉头孔 | 已完成（安全子集） | 圆锥层加内圆柱层只产出草稿；对话框要求选择方案并可勾选“取消沉头加工”。确认后创建钻孔与 `hole_chamfer` 工序。 |
| 通孔 | 已完成（安全子集） | 仅允许最深层贯穿；受控 `AT` 加到确认深度，仍经有效刃长、总长、R 平面、Q 深度与最终代码仿真检查。 |
| 多层规则与刀具表达式 | 已完成 | 受限 AST 仅允许已声明的 `Hn`、`Dn`、`Tn`、`AT`、正数与 `+ - * / ()`；脚本、未知变量、除零、负值及越界被拒绝。 |
| STEP 复合孔识别 | 半成品 | `CompoundHoleRecognizer` 可将现有识别出的单孔、已验证 `secondaryDepth` 的台阶孔、可推导深度的沉头孔转为候选；尚未以完整生产 STEP 模型覆盖所有圆锥/同轴组合。 |
| 密封槽、侧面/斜轴、相交/破孔 | 未完成 / 阻断 | 缺少稳定拓扑边界和刀具中心包络；保留带原因的拒绝候选，绝不生成刀路。 |

## DTM 参数映射

| DTM 意图 | 产品映射 |
|---|---|
| `H1/H2/...` 层深 | `HoleLayer::depth()` → 受限公式变量 |
| 沉头/沉孔状态 | `HoleLayerKind::ConicalCountersink` / 连续圆柱层；用户 `cancelCountersink` 只跳过锥层步骤 |
| `AT` 贯穿余量 | 仅最深贯穿层的受控正余量；不得使刀具越过已确认深度以外的边界 |
| 加工方案、刀具和排序 | `AutoHolePlan` / 有序 `AutoHolePlanStep`；确认时解析刀具表达式并保持步骤顺序 |

## 分层边界核对

| 架构边界 | 实际行为 | 状态 |
|---|---|---|
| 识别 → Recognized Feature | `CompoundHoleRecognizer` 只返回 `CompoundHoleFeature`、置信、警告或拒绝原因；不创建工序。 | 已完成 |
| 规则 → Operation Proposal | `AutoHolePlan` 的有序步骤是规则侧建议，且在候选中保持草稿；`OperationProposal` 实例仅在人工确认事务内构造。 | 半成品：建议数据尚未独立命名为持久化 `OperationProposal` 类型。 |
| 人工确认 → Machining Operation | `AutoHoleCandidateDialog` 显式选方案/确认后，`ConfirmCompound` 预校验所有步骤，再经 `OperationFactory` 一次性返回整链；任一步失败不返回部分工序。 | 已完成 |
| 策略 → controller-neutral Toolpath Result | 孔/倒角策略仍产生产品内部中立运动，再由 CQ8、Fanuc、Siemens 后处理表达；本批没有在策略中加入控制器分支。 | 已完成（复用既有路径结果模型） |
| 仿真 → 最终后处理代码 | 集成测试用最终 CQ8 展开代码、Fanuc、Siemens 文本经 `GCodeSafetyValidator` 后交给 `SimulationController`。 | 已完成 |

## 自动化证据

- `compound_hole_recognizer_test`：沉头层深、带已验证外层深度的台阶孔、缺少层深阻断。
- `compound_auto_hole_planning_test`：沉头确认、取消沉头、两层台阶孔、侧面/层重叠拒绝、非法公式、缺后续刀具原子失败、重识别保留人工覆盖。
- `restricted_formula_evaluator_test`：`Hn/Dn/Tn/AT`、未知变量、脚本、除零、负值与结果越界。
- `compound_auto_hole_cq8_integration_test`：CQ8、Fanuc、Siemens 差异，G-code 安全检查和最终代码仿真；覆盖沉头与通孔受控 `AT`。
- `project_manager_serialization_test` 与 `process_template_library_test`：层深识别字段和多步骤模板保存/重开。
- `auto_hole_candidate_dialog_test`：候选明确选方案才可确认，沉头候选的取消开关回传服务层。

## 风险与下一步

- 规则建议目前由 `AutoHolePlanStep` 表达；下一期可在不改变确认事务的前提下将其收敛为显式可持久化的 `OperationProposal` 草稿对象。
- 不支持的几何保持候选拒绝，不得降级为平面刀路。
- 下一批按架构方案进入“槽框识别基础”：建立面/边/点邻接、闭合/开放、底面/侧壁、孤岛与保护面证据；只生成 `Recognized Feature` 和加工几何，禁止越级进入 3D。
